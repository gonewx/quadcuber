# 工程内 3D 显示模型

全部使用 `${KIPRJMOD}/lib/3dmodels/…`，不需要另装系统模型库或设置 `KICAD9_3DMODEL_DIR`。板内模型与项目封装库同步；电气、孔铜、位置、网络及走线不变。171个装配器件均有模型；C26/C36保持DNP并默认隐藏。

## 可分发性和精度

- `kicad/`：25个实际使用的KiCad标准封装模型，原始文件、作者信息及CC-BY-SA4.0许可和设计例外完整保留。固定来源提交、URL、SHA-256见`kicad/sources.json`。库文件本身继续按该许可分发；通用封装外观不是每个BOM料号的精确原厂CAD。
- `project/`：5个独立生成的矩形显示模型，只使用公开尺寸事实，没有导入原厂CAD拓扑、标识或内部结构。项目将这5个STEP及生成脚本`electronics/display_models.py`按CC0-1.0提供，许可全文见`project/LICENSE.txt`。不把这项许可扩展到厂家资料、KiCad模型或其他仓库文件。
- Bourns原始STEP虽然已下载并核过几何，但未确认其公共仓库再分发许可；2026-10-14正常访问官方条款页返回HTTP403。按用户批准的备选方案，**F2/F3与L1/L2最终发布的是自制简化模型，不再分发此前的原厂对齐CAD**。两个原始STEP也从本提交工作树移出，原件保留在执行环境下载区，来源及历史哈希保留。此前Git提交仍含原件；本次没有重写历史，不声称历史副本已撤销。
