## 实际预算与本次测试范围

本项目暂定每个 5 V 支路 **≤1.5 A 持续为设计/首板验证预算**，不是已经验证的连续额定。芯片 3 A 标称不允许把本次负载改成 3 A。A 路的 1.5 A 包括逻辑负载。

整板入口预算≤5 A；项目已有估算显示四马达各0.75 A RMS、两路5 V各1.5 A并加泄放时约5.02 A，需要降低组合负载。禁止将所有电机/舵机堵转作为持续工作模式。热/短时峰值、EV3 PINMAP/MPN/CURRENT及机械条件仍 HOLD。单路 WEBENCH 不证明双路共母线耦合、入口保护、USB、回灌或整板温升合格。

测试 Vin 是**芯片 VM 节点**的理想源目标，不是对外部9 V适配器经过线束/保险/保护压降后的保证。电源/线束阻抗、真实负载边沿/启动波形、实际 DC 偏压有效电容、ESR/ESL随频率温度曲线、板级热参数均未从现有文件确认。
