## 1. BOOT：49.9Ω位置确实不符引用参考；历史动机不可证实

原厂依据为[TI TPS54302 Rev C / SLVSDG6C](https://www.ti.com/lit/ds/symlink/tps54302.pdf)：第14页图7-1中，C3=0.1µF直接跨BOOT–SW；49.9Ω的R1在Vout与反馈上臂/前馈节点之间。第15页7.2.3.3说明R1是反馈环路测试断点。第12页6.3.10及第15页7.2.3.2规定100nF陶瓷bootstrap电容，使用X7R/X5R。

源证据：当前 `electronics/circuit.py:94–95` 定义R20/R30从BOOT到BOOT_CAP、C22/C32从BOOT_CAP到SW；最早引入该电路的 `d591b0e` 第47–48行已经如此。故问题早于A1迁移、KiCad10及求解器适配。原参考相同49.9Ω被放到另一位置，支持“可能误读参考”的推断，但没有设计日志证明作者动机，不能写成已查明的历史事实。

**优先方案（尚未生产）**：删除R20/R30及其串联位置，用短铜线连接芯片BOOT引脚与100nF电容的一端；C22/C32靠近U2/U3，另一端短接至各自SW，使电容直接跨接BOOT–SW。这里“取消电阻”包含重新连通铜线，绝不是只拆件或设DNP后留下开路；也不是将BOOT与SW直接短路，二者之间仍是100nF电容。

**复用旧焊盘的备选**：仅在需要保留现有电阻焊盘/铜线时，将R20/R30换为0603的0Ω跳线；0Ω不是该功能必需器件，不是新板优先方案。备选确切料号 [Yageo RC0603JR-070RL](https://yageogroup.com/component-documentation/download/specsheet/RC0603JR-070RL)。其尺寸1.6×0.8mm与现有0603对应；按[RC系列数据表](https://yageogroup.com/content/datasheet/asset/file/PYU-RC_GROUP_51_ROHS_L)第5页，0603跳线电阻<50mΩ、额定1A/最大2A。不能把单料页的通用“5%”字段解释成理想零欧，亦未据此证明BOOT脉冲电流裕量。

只读PCB检查见 [boot-layout-inspection.json](boot-layout-inspection.json)：R20/R30焊盘中心间距1.65mm，C22/C32为0805；A的BOOT铜线段总长约8.400mm无过孔，B约9.037mm并有2个过孔，后续BOOT_CAP线段均2.725mm。加跳线焊盘间距后，到电容的路径量级约12.775/13.412mm（线段合计，不是寄生提取或严格最短路径）。因此0Ω**可复用现有焊盘并去掉有意串阻**，但并未缩短回路、消除B路过孔，不能声称全部布局建议已满足。板尚未生产，因此本提案优先取消串阻位置、移动电容并局部重布BOOT–电容–SW回路。最终坐标、线长和是否能全程无过孔须布局后核对，目前不预先宣称已实现；这不是本次已实施变更。

电容ESR是电容模型内部寄生，不能冒充49.9Ω外置电阻，也不能把WEBENCH的280mΩ假设当成实物数据。直接铜连方案和0Ω备选都仍需实测BOOT相对SW电压、充电/开关边沿、启动与温升；数据表2.1V是典型驱动条件，不是凭一条典型波形即可覆盖PVT的保证。

## 2. 反馈：可复算的区间与候选料号

TI第5页5.5给出VFB=0.581/0.596/0.611V（min/typ/max，服从该表测试条件）。令上臂Rt、下臂Rb，两只电阻初始容差均为t：

```
Vtyp = 0.596 × (1 + Rt/Rb)
Vmin = 0.581 × (1 + Rt(1−t) / [Rb(1+t)])
Vmax = 0.611 × (1 + Rt(1+t) / [Rb(1−t)])
```

当前1%上臂99–101kΩ，下臂13.167–13.433kΩ；高端计算是 `0.611×(1+101/13.167)=5.297792739V`。以下“全初始容差”仅指基准极限和两个独立初始电阻极限，**不包括电阻温漂/老化、FB偏置电流、线/负载调节、纹波和瞬态**。

| 上/下臂kΩ | 初始精度 | Vmin | Vtyp | Vmax | 初始静态结论 |
|---|---|---:|---:|---:|---|
|100/13.3（当前）|1%|4.862918|5.077203|5.297793|上限超47.793mV|
|100/13.3|0.1%|4.940693|5.077203|5.214182|上下限内，上端余35.818mV|
|100/13.7|1%|4.737898|4.946365|5.160952|低于下限12.102mV|

|100/13.5|0.1%|4.876105|5.010815|5.145987|算术比较，中心较均衡|

4.75–5.25V是项目现有验收要求，具体来自 `electronics/simulation/run_buck_vendor.py` 的 `assess()` 和 `thresholds`，并写入PSpice交接说明；不是TI对上述全部实际外围的保证，也不能据此推导所有外接负载均接受该范围。上限约束覆盖启动/负载瞬态全程，下限在10ms后适用，故仅静态合格不足以放行。

四者均为0.1W@70°C、75V，尺寸1.6×0.8×0.45mm（各±0.1mm）。这是原厂料号/封装核对，未查询现货或下单。13.5k/13.7k的0.1%方案此次未取得可核实的确切单料原厂页，故只列为数值比较，不把猜测编码当作已审核采购项。

**建议**：针对尚未生产的新板，优先删除R20/R30并局部缩短BOOT–100nF–SW回路；0Ω仅为复用旧焊盘的备选。反馈仍保留同阻值0.1%候选以维持典型工作点；EN与Cff暂不动。不要推荐100k/13.7k的1%替换，因为静态低端已失败。若目标是生产角点加动态余量，当前两个有确切MPN的方案都不能直接定版，需要围绕更接近5.0V的精密比值分配上下沿预算，再核准实际料号并验证。

温漂例子说明该区别：对于已核25ppm/°C的0.1%同阻值电阻，假设两只电阻相对25°C偏移100°C、TCR独立取相反最坏方向，以 `(1±0.001)(1±0.0025)` 组合，静态区间变为4.918949–5.237256V，上端只剩12.744mV。此例不是测得板温或完整温度资格。用户简化WEBENCH负载波形有约0.11V过冲，不能机械加到另一PVT角点作为精确预测，但已说明不能仅以35.8mV初始余量宣称全程5.25V必然满足。

## 3. Cout >25.1µF：只是带条件的初筛

TI第17页7.2.3.5.2式14采用低ESR近似 `f0≈5.1/(Vout×Cout)`，并要求加入Cff之前选择低于40kHz的交越频率。由此在5.077203V有 `Cout>25.112252µF`；若按输出4.75V计算则为 `>26.842105µF`。这里Cout是两颗并联陶瓷电容的**总有效容量**，必须考虑初始容差、DC偏压、温度、老化。C26/C36的470µF当前DNP，不能擅自计入；若装配它们应重做整个阻抗/环路分析。

44µF标称取0.4系数仅剩17.6µF，粗估57.07kHz；0.8系数35.2µF对应28.54kHz。这些系数不是Murata保证曲线，式14也不保证相位裕度、负载阶跃或稳定性，不能据此宣布17.6µF必然振荡。75pF前馈会改变环路，需结合实际C/ESR及式16或实测重新审查；未建议自动改值。实际Murata曲线仍因官方入口403未取得，阻塞量产验证。
