## 主体、焊盘和机械包络

侧视图给出前端到定位柱轴线 6、主体深 15，结合上述插口方向，主体名义范围可推导为 `X=−6.1…+6.1`、`Y=−6…+9`。这是相关视图推导，不是 PCB LAYOUT 直接画出的完整外形；主体深度有 ±0.2 公差。

定位柱在 X=±6，固定耳明显向主体外伸，图中没有完整标注其最大宽度和外廓。不能只按 12.2×15 主体矩形判断相邻器件、板边和机壳干涉。孔半径1.15加0.5装配余量得到 X=±7.65 的 courtyard **下限**，并不证明此界线包住所有固定耳。尚须核实实际插头、卡扣操作区和线缆进出空间。

如采用 Ø1.40 的圆形 THT 焊盘、图示 Ø0.79 钻孔，名义环宽为 `(1.40−0.79)/2=0.305`。同排孔距 2.04，圆焊盘间净距 0.64；相邻交错孔距约2.737，净距约1.337，不因 1.02 的横向投影节距而短接。钻孔/电镀/钻偏及实际针脚尺寸仍须核验，不能只凭名义环宽放行。
