# U1细间距与丝印独立复核

2026-10-12；只读 `jlc-preflight.md/json` 的原板测量结果并重新核对官网，不修改硬件、制造输出或提交。本文不覆盖并行实施的J5四槽扩盘。

**结论：保留U1的0.20×0.875 mm、0.40 mm节距焊盘；把公开工艺口径差异作为具体CAM待确认项，不归类为已证实的电气错误，也不无依据扩宽到0.25 mm。丝印问题属于信息图形与装配/使用可读性整改，不构成铜网电气拒收。**

- 原板JSON列出U1全部56个窄焊盘。这组尺寸直接对应[Raspberry Pi原厂RP2040数据表§5.1.2、图167、印刷页608](https://datasheets.raspberrypi.com/rp2040/rp2040-datasheet.pdf#page=609)：推荐宽0.20、长0.875、节距0.40 mm。它不是误把芯片引脚尺寸用作焊盘的结果。
- [JLCPCB裸板公开能力](https://jlcpcb.com/capabilities/pcb-capabilities)确写通用最小SMD焊盘0.25×0.25 mm；本次没有发现该条给QFN的明确豁免，因此不能声明当前0.20 mm宽已获该订单保证。但[官方PCBA能力](https://jlcpcb.com/capabilities/pcb-assembly-capabilities)又明确支持QFN，Standard最小节距0.35 mm、Economy 0.40 mm。装配支持不能自动豁免裸板尺寸，两者应提交为同一个明确工艺问题：四层、外层2 oz、ENIG，RP2040原厂0.20×0.875/0.40 mm焊盘是否按原图制造、是否保持脚间阻焊。
- 当前相邻铜边距0.20 mm，恰好达到官网2 oz阻焊桥所列的最小焊盘间距。强行扩宽至0.25 mm会把边距压成0.15 mm，失去此条件；不能用修复通用条目制造新的阻焊矛盾。若工厂明确不接当前组合，再评估有证据的工艺或封装修改。
- 原板1983个0.12 mm丝印笔画/图形、52条0.80 mm文字低于官网0.15 mm线宽、1.0 mm字高；73个距开窗不足0.15 mm是本地预筛，未证明实际Gerber或CAM拒收。建议优先把电源极性、引脚1、BOOT/RESET/SWD及连接器功能标签改到可辨认尺寸并移离开窗；拥挤的非关键外框/位号可删减并由装配图补充。只增粗可能产生新的碰撞，必须重查图形间距。不能默许裁掉重要操作标记；也不能因细字就断言电源或信号网络不合格。[官方Legend规则](https://jlcpcb.com/capabilities/pcb-capabilities)

归类：U1为订单工艺适配待确认；丝印为制造资料/可读性改善；两者均不是本轮授权外的自动改铜理由。本文未取得厂商CAM答复，不将官网PCBA能力当成当前订单已经批准。
