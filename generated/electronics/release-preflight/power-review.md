# A1 电源打样预检（da5fc42，2026-10-12）

结论：本轮独立复核没有发现必须先改电源铜板才能制造**受控工程样板**的新错误。direct BOOT、精密反馈、输入保护与泄放连接已在源定义、原生 PCB、KiCad 网表、BOM 四处核对，37个位号合同通过（实际清单见 JSON）。但现板不能被称为全 PVT / 全负载合格；特别是 5V 上沿余量、实际 MLCC、联合电流预算和热阻仍需首板测量。打样不需要“先有通过测试的样板”；带电负载测试必须按分级范围执行。此结论仅覆盖电源，不解除接口/机械/制造资料的独立门槛。

交付：[复算脚本](power_bounds.py)、[机器可读结果与源哈希](power-bounds.json)。执行 `python generated/electronics/release-preflight/power_bounds.py`；无设计写操作、无宏模型扫描。系统 pcbnew 为9.0.2，不能加载本工程10.0.7文件，因此脚本只读解析原生 S-expression 并逐引脚比较，不把旧版导入失败误报为设计失败；该合同检查不取代 DRC。

## 2. 实际电容：可以算需求，不能捏造曲线

实装输入 C20/C30 为 GRM32DR71E106KA12L，10µF/25V/X7R/±10%；每路并100nF。输出 C23/C24、C33/C34 为 GRM32ER71E226KE15L，22µF/25V/X7R/±10%，每路44µF标称。原厂PIM及SimSurfing此前代理403；本次原厂公开精确料号PDF入口仍403。没有换域名、镜像或绕过限制。官网搜索索引确认精确系列存在，但不提供可用DC-bias/ESR数表。

因此 **实际Cin@9V与12V、Cout@5.25V的Ceff/ESR仍未取得**；0.4/0.8/1.2容量系数和总ESR3mΩ只是敏感性假设。应保存原厂SimSurfing导出的两精确料号曲线/CSV，记明DC偏压、测量频率、AC激励、温度、老化时间与曲线典型/保证属性；输入至少覆盖8–12V，输出4.75–5.25V，ESR/阻抗覆盖290–510kHz及谐波。典型曲线也必须另加公差/温度/老化余量。

用原厂设计式进行需求筛查，fSW取290kHz下限，B路0.05→1.5A：

- 两周期供电、允许下降0.25V，需要**40.0µF有效输出电容**，尚未算ESR。若以静态低角4.918949V距4.75V的168.949mV为预算，需求**59.19µF**。两只22µF仅初始−10%即39.6µF；这说明现BOM无法凭标称值证明这个保守选型式，而不是断言必然不稳或实测必然失败。
- 不含75pF前馈的40kHz交越粗估需要Ceff>**25.92µF**（按静态低角）。35.2µF时名义输出点粗估28.54kHz，17.6µF则57.07kHz。前馈会改变环路，不能凭这个式子给出相位裕度或宣布振荡。
- 取L=8µH（10µH初始−20%的筛查值，不含额外偏流/热漂移），VIN9.18V、Vout5.25V，电感纹波约**0.969App**，1.5A时峰值约**1.984A**。这低于4A最小高侧限流，但不是短路保护协调或电感高温保证。
- 输入1.5A负载、400mV纹波预算、忽略ESR时Cin需求约**3.233µF**；输入电容RMS电流上界约0.75A。若Ceff仅4µF，容性纹波估计323mV，只余77mV供ESR/寄生；局部高频电容不能用远处2820µF完全替代。原厂另建议>10µF输入陶瓷，现10µF标称没有偏压裕量证明。

这些是**首板资格测试前的计算约束**。没有拿到曲线不应循环禁止制造验证用裸板；但不允许把1.5A快阶跃/全温动作写成打样后的默认安全工况。新增并联电容是否必要，先用曲线或首板测量定；C26/C36不能未经环路验证直接装上。

## 3. 输入、故障和联合预算

F1真实料号0407008.WR已核对：8A/24VDC时滞、60A分断（规定DC时间常数<0.8ms）、名义熔化I²t24.12A²s。它在16A允许1–120s才开断；**5A限流电源下短路不会依靠F1清除**。首板保护来自电源限流、有限储能和操作/仪器关断，不是这只保险。已有模拟入口47–200A窄脉冲及0.209–1.567A²s只适用于声明的源输出电容/线缆/模型，不能证明任意电源热插拔安全，也不能把60A分断值与瞬态通流峰值混同。

连续总输入≤5A是必要联合约束，不是四臂各0.75Arms及两路各1.5A可同时无条件使用。按四电机各0.75A平均母线电流、5.25V×3A输出、效率85%及泄放保守相加，VM8.82V约**5.160A**，VM8V约**5.370A**。电机绕组RMS不等于母线平均；必须测总输入并安排并发，不能把这个算例当真实耗流预测。现固件未有电流闭环保证。

43.2k±1%对应驱动电流调节门限约**1.352–1.613A**（原厂常数59–69kV，规定测试电流1A；PWM消隐期间可有额外峰值）。它不是0.75A热限流。禁止把堵转试验作为第一项测试。

## 4. 回灌：有限范围可分析支持

实际VM电解为六只470µF/25V，共2820µF；按初始−20%取2256µF（不是老化/低温保证）。两只300Ω±1%泄放并联，最大151.5Ω（初始值，尚未加TCR/老化）。忽略其他负载、输入只供电不吸收，整板一次回到VM **0.05J**、初值9.18V：

- 瞬时全储入电容的上界11.3401V；到12V总储能余量0.067373J，0.05J后余17.373mJ。
- 仅经泄放回到9.18V需约72.23ms；5Hz、最长100ms事件仍有100ms安静间隔。故规定**整板≤0.05J/事件、≤5Hz、5–100ms宽**可形成不累积的初始参数范围，四臂同时制动必须合并算一个事件。
- 12V下每只最小297Ω耗散0.48485W，11.34V下约0.433W，低于1W@70°C名义值。但Vishay要求电阻膜温≤155°C，真实PCB散热、温漂和重复长期漂移仍需测。

11.34V计算不含ESR/ESL电压尖峰和实际电解低温/寿命下降；用实测VM**含尖峰<12V**验收。正常动作不要周期性触发TVS。SMBJ12A的600W是指定非重复波形条件，不能当连续制动吸收能力；F1位于反向阻断之前，不能给负载侧TVS的回灌耗能提供保护。无依据需要增大本板TVS；超出此整板能量范围时，最小功能变更方向是专用制动吸收/动作限制，不能仅加电容宣称解决持续外力反拖。

## 5. 热边界及首板分级验收

TPS54302推荐TJ≤125°C，标准测试板θJA118.9°C/W，官方EVM57.2°C/W，均不是A1板实测。Ta40°C时以118.9筛查，IC耗散预算仅**0.715W**。5.25V/1.5A、假设90%效率，整个变换器损耗0.875W；若全部放在IC，估TJ144.0°C；95%时约89.3°C。此“所有损耗进IC”对损耗分配保守，但118.9并非本板热阻上界，故不是保证安全/失败判定。原3A器件标签不提供A1的持续3A资格。报告JSON列出0.25/0.75/1.5A、25/40°C与85/90/95%敏感性。

**制造前必须具备**：原生连接/封装/装配资料通过、确切极性和DNP说明、工程样板测试标识、限流电源及范围明确的首板计划；其他责任人必须关闭机械/接口制造门槛。电源暂无新增必改铜板项。**电源选型/上电前**必须明确电源输出电容/限流模式，不接受未知电池或低阻储能源；先接线后使能，避免已充电大输出电容热插拔。

建议可执行的首板顺序（范围是试验限制，不是预先保证安全）：

1. 无电机、无外接舵机/编码器负载，室温20–30°C；检查短路/极性后，9V电源起始限流0.5A、过压设≤9.18V。优先≥100ms受控上升：最大3384µF仅充电平均约0.311A，加已焊逻辑/泄放后可能触发0.5A限流，允许限流延长启动，**不要为启动失败直接提高至5A**。记录输入、VM、两路5V、3V3及电流；重复UVLO/热启动须停止排查。
2. 两路5V稳态4.75–5.25V后，使用可记录的电子负载，从A=总0.25A、B=0.05A基线开始（A负载包含板上逻辑）。先0.1A增量、到每路0.25A，再0.75A，再1.5A；每一级先稳态与短脉冲，再长驻留，始终保持总输入≤5A。温度先设**外壳80°C停止线**；这是保守操作止损线，不是结温合格证明。
3. 每一级记录稳态纹波、负载上/下阶跃、慢/快输入变化、启动/断电、USB组合供电。最终规定A0.25↔1.5A、B0.05↔1.5A，单路及双路同时；至少10µs边沿并记录实际边沿，随后加实际舵机电流波形。输入J1=8.82/9/9.18V，并记录U2/U3脚上实际VM，负载后应≥8V；两路所有瞬态4.75–5.25V、稳态纹波≤50mVpp为项目验收线。启动爬升期间不要求≥4.75V，但不得过冲>5.25V或反复启动。用短地弹簧/差分探头测纹波和BOOT−SW，不用长接地夹造成假尖峰；BOOT−SW不超推荐5.5V，2.1V仅典型刷新阈值而非保证最小值。
4. 再测试单臂低速空载、受控负载，最后多臂并发；逐步确认绕组RMS≤0.75A、总入口≤5A及上述回灌边界。回灌积分必须是流入VM的总功率/能量，不是机械名义能量或仅F1电流。VM峰值含尖峰<12V、无TVS周期耗散；接近边界即降低速度/并发，不靠电源限流吸收回灌。
5. 目标环境≤40°C热浸，持续至温度稳定（例如连续10分钟变化<1°C，记录总时长），测U2/U3、四DRV、F1、Q1、PTC、泄放与电解。估算/测量TJ目标<125°C、F1附近先限≤75°C、泄放膜温满足厂商降额。需记录铜面积/探头误差及IC实际耗散，不能直接用EVM热阻；尚未得到TJ证据前不批准1.5A长期运行。全温资格另测实际声明的温度范围，室温样板通过不等于−40～125°C产品合格。
