## 首板回来执行，合格后才扩大用途

1. AOI/极性/短路与焊接检查，在限流电源下先逻辑和两路空载5V，捕获冷启动、关断、热启动及输入跌落。5V目标4.75–5.25V；不要将模型未跑通视为实测失败或通过。
2. 锁定实际MLCC与温度，测两路负载阶跃、最小/最大输入、环路/纹波与电容有效值；按预定范围逐级升载。静态反馈上界余量小，需要波形和实物容差证据。
3. 按控制器报告验证BOOTSEL/指定UF2、Flash持久化、时钟、1V1/3V3及允许供电组合；host-off仅用受保护夹具专项测试，不先接电脑。
4. 单电机/单舵机到并发调度，测**总输入电流**、各轨波形、温升与故障恢复。四路电机各0.75A加两轨各1.5A不能同时当安全预算，估算已超过5A。保险丝是故障保护，不是5A电子限流器。
5. 回生按当前≤0.05J/次、≤5Hz的暂定受限计划逐步验证；监测VM尖峰、TVS及电解温度。该界限是计算支持的实验范围，不是实际电机回生已测定值。热/保险/PTC及铜温合格后才能扩大负载/环境范围。
6. 独立绝缘台架测试不依赖机器人托架完成；装机前另完成支脚/底部防护、B面绝缘、焊脚、USB插拔与线缆扫掠实物检查。之后再做集成运行与耐久，不称量产认证。
