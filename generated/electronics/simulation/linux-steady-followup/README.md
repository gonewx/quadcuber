## 结论与实际运行

A1双路实际BOM的9个VIN/电容组合，分别从轻载和1.5A工作负载初始化，**共18项实际求解**。完整完成0项，验收通过0项；终止分类 `{'NUMERICAL_FAILURE': 15, 'TIMEOUT_180S': 3}`。超时仅说明180秒预算内未完成，**不等于数值不收敛**。五毫秒计划包含负载和输入变化，未到的窗口明确缺失，未声称全部阶跃已测试完成。

原厂稳态参考延长到1.5ms、保存全程后成功积分，但**周期稳态及宏模型兼容性尚未验证**。原750–800us只有20个400kHz标称周期；实际SYSCLK出现81次完整逻辑上升，迟滞计数也相同。末1–1.5ms共810次，中位周期约0.608us（约1.65MHz），不是小幅阈值振铃假计数。TI公开规格为400kHz并有扩频，见[官方产品页](https://www.ti.com/product/TPS54302)。完整运行不能替代物理行为验证。

原参考700–800us与800–900us窗口均值差6.60mV；后来存在约5.14V尖峰。`reference-steady-extended/analysis.json`保存全部窗口数据与判断条件，`reference-check.png`给出波形。该结果修正上一阶段“稳态参考完成”的解释：时间覆盖完整，但不能据此宣称已经达到正确周期稳态。 扩频本来允许周期变化；这里不要求逐周期完全重复，也不把均值变化单独当作未稳态证明。原调制周期约1.024ms，1.5ms尚不足以比较多个完整调制周期；当前更直接的阻塞证据是异常时钟频率与最小振荡器事件失败。

- 轻载组A/B从0.25/0.05A在1ms升到1.5A，2ms返回；工作负载组从各1.5A在1ms降到上述轻载，2ms返回。低压负载按既有 `clamp(Vout/4,0,1)`缩放。移除原0V测流源并把B负载直接接输出，负载方程不变；B表达式外加大括号是Xyce语法要求。
- 3–3.01ms将输入变至9.18V，4–4.01ms降至8.82V。初始VIN=9.18V组的第一项是无变化控制，只有4ms才是输入变化；各case记录实际ΔVIN和到达状态。
- 运行到5ms、最大步长20ns，全部时刻保存。计划稳态窗口0.7–1、1.7–2、2.7–3、3.7–4、4.7–5ms，各300us（120个400kHz标称周期）。输出4.75–5.25V，电感绝对电流<6A，同一工作点窗口前后半段均值变化≤5mV，至少50个已确认的物理周期。这些是本次诊断判据，不是TI官方测试规范；不能跨负载/输入不同工作点直接比较均值。
- `window-assessment.json`实际计算已覆盖窗口，缺失窗口不插值补齐；异常SYSCLK上升数只作观测，不充当通过的物理周期数。全局部分波形极值也保留，但宏模型时钟兼容尚未成立，不据此认定硬件过压/失效。

## 冷启动与最小单元结论

`cold-differential/`保存三项单因素可逆对照：Startup只改S=1仍在108.133086us失败；只把VIN换DC12V在2.38699189us失败。两者均在首次SW上升采样后约0.748ns停止，排除了“仅VIN斜坡”或“仅S标志”的解释。预充电Steady仅S=0可完成800us，但输出末0.7495V，不是5V调节或冷启动通过。外部储能与负载类型仍有混杂，不声称已确定器件根因。

`oscillator-diagnostic/`原U3器件逐字提取，在明确SDWN/ULQ边界下比较默认、严格容差与Gear。独立振荡器正常OP无平衡；仅为该单元使用明确零初值UIC时，首段充电约2.363us符合7.14286pF/5.3uA/1.75V，但首次比较器转换处仍失败。单元UIC不代表完整宏模型可以采用UIC；不改变上一阶段的初值反例结论。全模型高频现象可能涉及复位/下游耦合/事件处理，尚未确定。
