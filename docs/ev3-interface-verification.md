# EV3 单臂接口复核（2026-09-27）

> 本文保留 2026-09-27 的接口选型和排障证据。当前接线入口见[电路总览](wiring/README.md)。2026-09-28 已更换驱动模块并通过[大马达空载闭环测试](single_arm-results.md)，v3 装机及整机供电仍待验证。下文“待完成”描述的是当时状态。

## 结论（最终方案，2026-09-27 更新）

**编码器改用电阻分压：每路 10kΩ 串联 + 20kΩ 下拉到地，不用任何电平转换模块。** 原 BSS138 接法撤回；下面第 3 节的 SN74LVC2G17 方案技术上可行，但已不需要，保留作记录。

| 部分 | 结论 |
| --- | --- |
| 白/黑 → DRV8833 AOUT1/AOUT2，VM 用 9V | 正确。马达不动时白黑之间为 0V、电阻几欧到十几欧，都正常 |
| 绿 +5V、红 GND 给编码器供电 | 正确 |
| 黄/蓝 → BSS138 模块 | **不能用**：马达内部串联电阻与模块上拉分压，低电平约 1.65V |
| 黄/蓝 → TXS0108E | **不能用**：要求信号源内阻很低 |
| 黄/蓝 → 10kΩ 串联 + 20kΩ 下拉 → GP4/GP5 | **采用**：高电平大马达约 3.0V、中马达黄线约 2.7V，低电平约 0V |

### 依据

1. **LEGO 官方电路**（固件文档 `LegoEv3TachoOutputDevice`、`DcmDriver` 页面，镜像 bjr2016.neocities.org）：两路编码器 T1/T2 都经施密特缓冲器推挽输出，6 脚串 3.3kΩ，5 脚串 R1；R1 兼作型号识别（大马达 3.3kΩ、中马达 6.8kΩ，EV3 主机在 5 脚上量到约 155mV / 299mV 来区分）。两路结构相同。
2. **EV3 主机的解码方式**（ev3dev `lms2012/d_pwm.c`）：6 脚双边沿中断，中断时读 5 脚判断方向，是标准的正交解码，所以两路都要接。
3. **万用表实测**（10kΩ 上拉到 3.3V）：蓝线在约 0V 和 4.9V 之间变化，说明能主动输出 5V（推挽），不能直连 Pico。理论值约 0.8V / 4.6V，差别在读数误差范围内。
4. **黄线故障排查**：黄线一直约 3.2V，换一个大马达后一样；断开所有连接后量通断，黄线不通。结论是黄线这一路在线缆/插头/转接处断开，马达本身没问题。换线或修好后按 [single_arm.md](single_arm.md) 第 3 节验收。

### 验收

分压点先不接 Pico：编码器通电，手转输出轴，每次转一点停下读数，两路都应在约 0V 和约 3V 之间变化、任何时候不超过 3.3V。然后接 GP4/GP5，用 `enc` 看正反转时计数方向相反，再做 `check`。

## 1. 两路电源

LEGO 官方主控原理图的 Output 定义：1/2 脚是马达驱动，3 脚 GND，4 脚 +5V，5/6 脚转速信号。[官方原理图，第 1 页](https://www.lego.com/cdn/cs/set/assets/blt86e79bb287a0d0b1/Appendix_LEGO_MINDSTORMS_EV3_programmable_brick_main_hardware_schematics.pdf)

常见配色：1 白、2 黑、3 红、4 绿、5 黄、6 蓝。白黑是电机的两个端点，由 H 桥交换极性和 PWM 调速；黑线不是公共地。绿红供编码器，不能接 9V。[实际接线记录](https://lechnology.com/2017/03/using-lego-mindstorms-motors-with-beaglebone-blue/)

EV3 大/中马达都有 9V 工作实测，低于 9V 也能转动，负载能力和速度随之变化；这里采用 9V 驱动，不把实测过的更高电压当额定推荐。[原始测量](https://www.philohome.com/motors/motorcomp.htm)

## 2. BSS138 接法为何失败

### 电路证据

LEGO 的 EV3 Tacho 图画出：编码器内部逻辑输出，经串联电阻后到插头。蓝线（6 脚）串 3.3kΩ；黄线（5 脚）的 R1 同时编码马达型号，大马达为 3.3kΩ、中马达为 6.8kΩ。[LEGO 电路图镜像](https://bjr2016.neocities.org/LegoEv3TachoOutputDevice)、[型号电阻定义](https://bjr2016.neocities.org/DcmDriver)

典型 BSS138 模块每一路分别经 10kΩ 上拉到 5V 和 3.3V。[SparkFun 模块原理图](https://cdn.sparkfun.com/datasheets/BreakoutBoards/Logic_Level_Bidirectional.pdf)

注意：这是有原理图支持的典型模块，不等于已确认用户板上的阻值。用户模块还没有独立核对电阻标记/原理图。

### 低电平计算

假设内部输出低电平近似 0V、MOSFET 导通压降忽略、两侧上拉各 10kΩ，蓝线输出串联 3.3kΩ：

```text
(5 - V)/10000 + (3.3 - V)/10000 = V/3300
V = 1.650 V
```

加上 Pico ADC 约 100kΩ 的输入负载，近似结果为 1.618V。用户采样最低 1.60～1.64V，与此模型吻合。ADC 输入阻抗只是简化负载模型，实际采样电路、MOSFET 压降和阻值公差也会影响结果。

黄线若为中马达的 6.8kΩ，同一简化模型为 2.392V；MOSFET 在该电压附近的导通程度会影响精确值，这不是对实物黄线电压的预测保证。

RP2040 在 3.3V IOVDD 下，保证低电平的上限为 0.8V，高电平下限为 2.0V。1.6V 落在未保证区间，不能可靠计数。[RP2040 数据手册，GPIO DC 参数及 ADC 输入阻抗](https://datasheets.raspberrypi.com/rp2040/rp2040-datasheet.pdf)

**结论：上述 BSS138 接法在设计上不合格；串联电阻与上拉相互作用是与实测高度吻合的原因，但还不是对实物唯一故障的证明。** 强制 HV1 接地能测到 0V，是因为跳过了马达内部串联电阻，不能证明接真实编码器也能正常工作。

已收到的实测：

- HV/LV 电源约 5V/3.3V；编码器绿对红约 5V。
- 蓝线经第一通道到 ADC：最低约 1.60～1.64V，最高约 3.30V。
- HV1 强制接地：ADC 约 0～0.07V。
- EV3 红线接点相对 Pico GND：ADC 约 0～0.06V。这个结果只检查该测量点，不能证明马达内部的地触点完好。
- 不据此宣称马达损坏，也不宣称整块转换器完好。

## 3. 备选接口（已不需要）：高输入阻抗施密特缓冲器

使用 **TI SN74LVC2G17** 双路非反相施密特缓冲器。用 3.3V 供电，输入允许到 5.5V，输出为 3.3V 逻辑。不经过 BSS138，不保留其信号上拉，也不叠加原来的分压电阻。[TI 数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc2g17.pdf)

```text
9V → DRV8833 VM；AO1/AO2 → EV3 白/黑
5V → EV3 绿；公共 GND → EV3 红

EV3 黄 → 1A [SN74LVC2G17] 1Y → Pico GP4
EV3 蓝 → 2A [SN74LVC2G17] 2Y → Pico GP5
                 VCC → Pico 3V3
                 GND → 公共 GND
```

| SN74LVC2G17 DBV/DCK 芯片针脚 | 信号 | 接到 |
| --- | --- | --- |
| 1 | 1A | EV3 5 脚（常见黄） |
| 2 | GND | 公共 GND |
| 3 | 2A | EV3 6 脚（常见蓝） |
| 4 | 2Y | GP5 |
| 5 | VCC | Pico 3V3 |
| 6 | 1Y | GP4 |

这是**芯片管脚表**，不是未知转接板排针顺序。型号必须明确带 LVC、输入容忍 5V；普通 74HC 型号或同名“电平转换板”不能直接代替。

- 输入漏电最大 ±5µA，经过 3.3kΩ/6.8kΩ 造成的静态偏移最多约 0.017V/0.034V，不再产生 1.6V 的双上拉分压。此预算仍要求马达内部逻辑输出正常。
- TI 列出的 3.0V 供电门限为 VT+ 1.3～2.0V、VT− 0.8～1.3V；这是 3.0V 的表值，不冒充 3.3V 精确保证值。正常接近 0/5V 的输入有明显裕量，实际验收仍检查输入与输出波形。
- 轻载 100µA 条件下，输出 VOH ≥ VCC−0.1V、VOL ≤ 0.1V；Pico 输入不开上拉/下拉，不连接其他负载，可满足其 2.0V/0.8V 门限。
- `ENC_PULLUP=False` 保留。两路均不反相，不改变原来的 GP4/GP5 与方向配置规则。
- 为满足可插拔要求，采用焊有排针、**自带 0.1µF 去耦电容**的转接模块，插排母；不给洞洞板添加外接电容。若只有裸芯片或无去耦转接板，不能省略数据手册要求后再宣称方案已验证。此处不替用户购买器件，也不假定用户已有该模块。
- 新模块只接 3V3 和 GND，没有 BSS138 的 HV/LV 双电源接口。不能直接插入原 BSS138 的孔位。

器件级结构已核对，但未拿到具体模块，不能提供可信的逐孔替换图，也不能宣称实物已通过。

## 4. 驱动与供电复核边界

[DRV8833 数据手册](https://www.ti.com/lit/ds/symlink/drv8833.pdf)给出 VM 工作范围 2.7～10.8V，9V 在范围内。3.3V 可驱动输入和 nSLEEP；用户板上的 STBY 按现有确认脚序接 3V3，但模块真实芯片/使能接法还没有原理图或芯片丝印佐证。

不能把所有 DRV8833 板都写成“持续 1.5A”：PWP/RTY 封装为每桥 1.5A RMS、2A 峰值；PW 封装为 0.5A RMS、2A 峰值，且实际还受 PCB 散热限制。原始马达测试中，9V 堵转电流约为大马达 1.8A、中马达 0.78A，属于样本数据。大马达堵转接近驱动峰值，不能按持续工作点设计。

软件堵转检测不替代硬件限流、散热与电源容量核算。当前驱动板封装、采样电阻/限流设置、Geekservo 型号及启动电流、电源能力都不完整，所以不能保证整机峰值电流裕量。

本版继续不新增外接电容、保留模块自带电容。TI 要求根据电源线、负载和制动回灌选择局部储能；未测 VM 瞬态前，只能说“尚未证明需要额外增加”，不能说“已证明不需要”。检查运行/制动时 VM 不超工作范围、5V/3V3 不掉压、接点和驱动不异常发热。

## 5. 最少实物验收

不再重复线缆导通和同一个静态试验。接好分压电阻后，先断开马达驱动负载或只手动转轴，做一次双路检查：

1. 两个输出都能达到低于 0.8V、高于 2.0V，并保持在 Pico 电源范围内；波形测量优于万用表平均读数。
2. 同时读取 GP4/GP5，单向转动出现相邻 Gray 状态，反转后顺序反向，累计计数正常改变；只有“变化次数非零”不能证明正交计数正确。
3. 编码器通过后才做低占空比空载驱动，再做短时实际负载；记录电流、VM/5V 瞬态、温升和故障状态。未完成前不做长时间堵转。
