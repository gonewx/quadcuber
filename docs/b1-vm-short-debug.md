## 结果（2026-10-19）

C31 换成 47µF/35V 贴片电解（DRV8871 典型应用的储能电容即 47µF），全部器件复装后 C1 VM 对 GND 爬到约 150Ω。F1 位置临时串 10Ω 电阻，插 9V PD 诱骗线上电正常。下一步：取下电阻、焊回 F1，按焊接指南第 6 节测各路电压。

**焊回 F1、去掉 10Ω 后直插 PD 仍一插就断电。** 串 10Ω 时 VM 8V 以上、电阻两端不到 1V，说明静态负载正常；直插断电的原因判断为**上电冲击电流**：VM 母线约 1.5mF，USB PD 规范要求受电端在电压切换时等效电容不超过约 100µF，本板超出十几倍，充电器的过流保护在充电瞬间动作。面包板方案只有模块自带的几十 µF，所以同一根线正常。这是 B1 设计时未考虑 PD 电源的问题；Q1 的体二极管在上电瞬间就导通，不能靠 Q1 做缓启动。

处理：① 直接改用普通 9V/2A 以上中心正 DC 适配器；② 继续用 PD 时在 F1 位置串 NTC 浪涌抑制热敏电阻（冷态约 5Ω，如 5D-9），F1 移到 NTC 前或另串；③ 下一版底板加缓启动/电子保险丝（如带 dV/dt 控制的 eFuse）。

**用现有材料的做法（淘宝已购记录中有 9V 电池扣 DC 插头线、DC 公母头线、船型开关）：**

- 立即可用：9V 方块电池 + 带 DC 插头的电池扣线直接插 J1。电池内阻天然限流，适合第 6 节空板上电测量，不能带电机。
- 长期方案：做一根预充电转接线。PD 诱骗线 → DC 母头线 → 10Ω 电阻（并联船型开关）→ DC 公头线 → J1。开关断开时插上，等 2 秒电容充满，再合上开关短接电阻。F1 保持原样。

### 预充电转接线制作

材料：DC 母头线 1 根、带 DC 插头的 9V 电池扣线 1 根（剪掉电池扣，只用插头一端）、船型开关 1 个、10Ω 电阻 1 个、胶带或热缩管。

```
DC 母头（接 PD 诱骗线）            DC 公头（插 J1）
   红 ──┬── 10Ω 电阻 ──┬── 红
        └── 船型开关 ──┘
   黑 ───────────────────── 黑
```

1. 母头线、公头线各留约 10cm 剪断，剥出红黑线头。Ω 档确认公头插头中心孔通的是红线，母头中心针通的是红线。
2. 黑线对黑线直接绞接焊好，包好绝缘。
3. 母头红线同时接开关一只脚和电阻一端；公头红线同时接开关另一只脚和电阻另一端。电阻与开关并联。
4. 所有裸露处包好绝缘，红黑线之间不能碰。电阻预充电时会微热，不要包得太紧。
5. 不接板子先验收：Ω 档量开关两脚，断开约 10Ω、合上接近 0Ω；插上 PD 诱骗线，量公头输出，红表笔伸进中心孔、黑表笔碰外筒，读约 +9V。

用法：开关断开 → 公头插 J1 → 母头插 PD 诱骗线 → 等 2 秒 → 合上开关。拔电前先断开开关。开关断开时板上若有短路，电阻约 8W，几秒就烫，马上拔掉。

## 复装顺序（短路排除后）

一次只装一个，每装一个就断电量 C1 VM 对 GND，读数仍能爬到约 150Ω 再装下一个。

1. D1：先单独用二极管档量，一向 0.4–0.8V、另一向 OL 才装；阴极标记端朝左，焊回右端。
2. U40：热风焊回，散热焊盘只点少量锡浆，不涂满到边缘。
3. C40：焊回，右焊盘锡要少。
4. C31：换新的 100µF/25V，负极色带朝右；烙铁只碰端子，不碰外壳。
5. C1、C2：装前单独用 Ω 档两向量，读数都应往上爬到很大或 OL；一向停在 0 的报废。

首次上电：PD 诱骗线和 J1 之间串 10Ω 电阻，插上后 1~2 秒内量 VM。VM 约 8V 以上、电阻两端不到 1V 为正常；电阻两端接近 9V 立即拔掉（短路复现，10Ω 会很快烧热）。通过后去掉电阻，按焊接指南第 6 节测各路电压。

## 第 2 步：注入电流，毫伏档找短路点

原理：电池经电阻往 VM 灌约 0.25A 电流，电流只沿着 VM 铜皮流向短路点。离注入点越远、越靠近短路点，铜皮压降越大。**压降最大的点就是短路所在。**

### 准备（一个人可做）

1. C1 的两个空焊盘各焊一段剪下的元件引脚，立起约 1cm。左边焊盘是 VM，右边是 GND。
2. 两节 AA 串联（约 3V），用胶带或橡皮筋把两根线固定在电池两头。
3. 电池正极 → 10Ω 电阻 → 鳄鱼夹夹 C1 左边引脚（VM）；电池负极 → 鳄鱼夹夹 C1 右边引脚（GND）。
4. 3V 下板上任何芯片都不会启动。10Ω 上约 0.6W，每次通电不超过 1 分钟，测完断开。

### 测量

万用表 **DC 200mV 档**。**黑表笔固定**在 C1 左边引脚（VM 注入点）的鳄鱼夹上，红表笔依次点下表各点，记录读数。读数带负号是正常的，只比较绝对值。

分不清某个两端器件哪端是 VM 时：断开电池，Ω 档量它两端对 C1 左边引脚，接近 0Ω 的那端就是 VM 端。

| 点位 | 位置说明 | 读数 (mV) |
| --- | --- | --- |
| 自检 | 红表笔点 C1 右边引脚（GND） | 这是地电位，所有 VM 点都不会超过它；实测约 11mV（一节 AA、10Ω） |
| R2 VM 端 | R2 与 R3 同侧那端 | |
| C3 正极焊盘 | C3 下端（正极朝下） | |
| U1 的 1 脚 | 五根脚朝右，最下面那根 | |
| C5 VM 端 | C5 非地那端 | |
| U2 的 3 脚 | 三根小脚朝左，左下那根 | |
| U10 的 5 脚 / C10 VM 端 | R 路 | |
| U20 的 5 脚 / C20 VM 端 | L 路 | |
| U30 的 5 脚 / C30 VM 端 | F 路 | |
| U40 的 5 脚 / C40 VM 端 | B 路 | |

### 读数怎么判断

- 各点读数介于 0 和自检值之间。读到几百 mV 或乱跳，说明接触不良。
- 绝对值**最大**、接近自检值的那个点就是短路所在。
- 实测（2026-10-19，黑表笔在注入点）：VM 焊盘 R2 0.6、C3 0.55、C5 0.7、C10–C40 约 1.1mV；地焊盘普遍 11.6–11.9mV，**C40 地端 10.7mV 最低**。
- 判读规则（更正）：短路器件本身约 0.07Ω，两端仍有约 10mV，所以短路点的 VM 焊盘**不会**被拉到 11mV。正确规则是：VM 焊盘中读数**最大**、地焊盘中读数**最小**的地方离短路最近；也可以直接测器件两端电压，**两端电压最小**的器件就是短路。实测 VM 最大在驱动区、地最小在 C40，指向 B 路 C40 附近。
- 复测（2026-10-19）：两端电压 C30 10.9、C40 9.6、C41 10.16mV，C40 两次都是最小，下一步拆 C40。
- 拆下 C40（单测 40MΩ，与新件相同，C40 本身正常）。拆后一度读 17.5Ω，清理焊盘后 C1 VM 对 GND 0.21Ω、C40 焊盘 0.19Ω，硬短路仍在，且对热敏感，像锡桥。
- B 路 VM 走线（PCB 数据）：主干过孔 (115.2, 108.0) → 顶层 0.8mm 线 → C40 左焊盘 → 向右下拐到 C40 下方横线 → U40 左下角 5 脚。C41 由另一个过孔 (134.9, 104.1) 单独供电。U40 引脚在上下两排：上排右起 1–4 脚，下排左起 5–8 脚；5 脚 VM，1、7 脚和中间散热焊盘为 GND。VM 没有铺铜，U40 的 5 脚只经这一根线接 VM。
- 已收敛到这一支线，剩两个嫌疑：U40 底下锡桥（5 脚连到散热焊盘），或这段板子本身（走线、过孔、C40 焊盘）。
- 下一步先做不拆件的区分：电池接着，黑表笔放 C40 左（VM）焊盘，红表笔放 U40 的 5 脚。约 0.2–0.5mV（有电流流向 U40）→ U40，热风取下；0.00–0.05mV（没有电流流向 U40）→ 板子本身，不拆 U40。
- 若取下 U40：取下后必须用吸锡带把 U40 全部焊盘吸平再测，否则留在板上的锡桥会造成“不是 U40”的误判。
- U40 取下并吸平焊盘后仍 0.24Ω；空板 C40、C1 焊盘均 OL（PCB 本身无短路）；正面清理黑斑后仍短；背面照片 B 路附近无可见锡桥。U40、C40 排除。
- B 路有两条独立 VM 支线：主干过孔 (115.2,108.0) → C40；主干末端过孔 (134.9,104.1) → C41。下一步同一时刻比较两条支线：红表笔 C40 左焊盘、黑表笔 C41 左端子。与“红 C40、黑注入点”的读数同号 → 短路在 C40 支线走线上；异号 → C41 一侧，拆 C41；接近 0 → 两条支线之前的主干上。
- 更正：主干过孔 (115.2,108.0) 引出的支线先到 **C31 正极 (116.3,110.5)**，再到 C40、U40。C31 是 F 路电解，但由这条支线供电，之前漏列。
- 实测 红 C40 左焊盘、黑 C41 左端子 = −0.12mV：C40 支线只有起点一小段有电流，约等于过孔到 C31 正极约 3mm 走线的压降（估算 0.25mV）。短路点在 C31 处。下一步拆 C31。
- 对调表笔复测（两节电池）：−0.36 / +0.40mV，确认电流流入 C31 支线。拆下 C31：单测一向 0Ω、另一向闪一下回 0，**C31 击穿**；方向与 3D 模型一致（负极朝右，正确）。拆后 C1 VM 对 GND 稳定 3.93Ω，还有一处较轻漏电。
- 下一轮（一次测完）：黑表笔固定注入点，红表笔逐个测各电容 VM 端。漏电 3.9Ω 时地焊盘读数约 800mV、VM 焊盘只有几 mV，不会认错；VM 端读数最大的就是漏电所在区域。
- 断开电池后 Ω 档复测：C1 VM 对 GND 恢复正常（约 150Ω）。前面 3.93/3.22Ω 是电池仍接在 C1 上时测的，不可信。**结论：短路源是 C31（F 路 100µF 电解）内部击穿**，方向正确，原因待查（焊接过热或器件质量）。C40、U40、D1 无故障，均为排查时拆下。
- IC 引脚读数（U1 11.7、U2 11.98、U10–U40 10.5–12mV）都像地电位，与相邻电容 VM 端 0.5–1mV 矛盾，判定为点到了 IC 的地脚或散热片，不采用。
- 某一路驱动的 U 和 C 两点读数明显比另外三路大：短路在这一路。
- C3 或 U1 的 1 脚最大：短路在降压区。
- C5 或 U2 的 3 脚最大：短路在逻辑电源区。
- 读数一路递增到 U40 都差不多：短路可能在 B 路或主干末端。
- 所有点几乎一样且都接近 0：短路就在注入点附近，查 R2/R3 焊盘和 C1 焊盘周边。

测完顺便摸一下 U1、U2 和四颗 DRV8871，有一颗明显温热也指向它。

## 第 4 步：修好后首次上电

PD 诱骗线不能限流，在诱骗线和 J1 之间串一个 10Ω/5W 电阻：

- 电阻两端电压 ÷ 10 = 电流。空板应小于 0.1A，VM 约 8V 多。
- 电阻两端接近 9V：仍有短路，立即拔掉。
- 通过后再去掉电阻，按焊接指南第 6 节测各路电压。

## 附：贴片电解的拆焊与重装

地焊盘是热焊盘连接（四根辐条），普通烙铁可做，不需要预热台。

**拆**：两端先加新焊锡；两把烙铁同时压两端，或一把烙铁交替快速加热两端，熔化后**水平转动**电容脱开。不要向上撬，会拉起焊盘铜皮。不要用热风整区吹。

**清理**：助焊剂加吸锡带清掉残锡，酒精清洗。Ω 档确认 VM 焊盘对 GND 焊盘不短。

**重装**：焊盘先上薄锡；负极色带对 pad2，C3 正极朝下，其余正极朝左；刀头烙铁 350~380°C 从侧面同时接触焊盘和端子，每端 2~3 秒。反装过、通过电的电容不复用。
