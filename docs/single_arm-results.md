## 已验证的范围

Pico 通过 DRV8833 驱动 EV3 大马达（未安装机械臂的空载状态），编码器两路经各自的10kΩ串联、20kΩ接地分压接入 GP4、GP5。当前使用[面包板与独立动力连线](wiring/direct-breadboard.html)，不经过 Bricktronics。

旧驱动模块在固定输入下无法正常输出；换用备用模块后，静态输出、`check 0.5` 和空载闭环动作均恢复。故障定位到旧模块，尚未进一步区分芯片与模块焊接问题。

供电使用原“9V”电源，排查期间 VM 实测约7.9V。以下参数对应当前电源和马达；不能把名义9V当作测速时精确测得的电压。

## 中马达装机测试

机械臂会增加惯量、摩擦，可能引入重力负载、齿轮比和回程间隙。带机构测得的是“中马达＋机械臂”的整体响应，适合实际控制调参，不等于中马达本体空载参数。

装机不改变编码器本身每个脉冲的分辨率；但齿轮比影响输出角度换算，回程间隙和结构变形会使编码器推算的角度与末端实际角度不同。不能把两种马达、两种负载条件的结果当作马达本体性能的直接对比。

已核对中马达版设计：马达直接带动转动座，外部传动比为1；舵机随转动座旋转，线缆会限制行程。模型没有线缆，允许角度需实物确认，详见[线缆评估](arm_concept.md#4-舵机线缆的问题)。确认行程并设置运动边界前，不运行 `speed`、整圈 `cal`、无角度保护的 `friction` 或大角度 `bench`。本轮舵机尚未接线。

## 以后复用大马达参数

下面命令只用于恢复这次大马达基线，当前准备使用中马达时不要执行。归档快照包含完整配置；引脚和机构变更时需先核对。供电、负载改变后也需验证，不能保证复用后得到完全相同的耗时与误差。


如果正在使用 `mpremote repl`，先按 Ctrl+X 退出，释放串口。在新 REPL 中按 Ctrl+D 软重启，再输入：

```python

```

在 `arm>` 输入 `show`，检查 `kfs=0.11`、`v_full=1180`、`tau≈0.091`。只有准备执行马达测试时才打开9V；重启前的临时 `set` 参数不会自动保留。

用户确认机械臂在线缆自然舒展的中位，9V开启。通过本机串口执行一次绝对角度0→90→0；无魔方，舵机未通电。两次均成功，无超调；正向最终误差1°，返回误差0°。这是单次往返结果，尚非批量可靠性验证。

### 自动重复测试：发生堵转，已停止

随后0→−90→0均通过，误差分别0°和1°；再次向+90°运动时，在约+72°触发stall，剩余误差18°。程序立即关闭输出并取消后续动作，没有自动返回或提高占空比。当前不能认定装机重复运行可靠，需检查该位置的机构与线缆情况。详见[重复测试结果](measurements/2026-09-28-ev3-medium-installed/auto-repeat-results.json)和[失败轨迹](measurements/2026-09-28-ev3-medium-installed/failed-positive-90-trace.log)。轨迹缓存最多800点，长动作可能不包含最后的故障瞬间。

### 输出上限85%的重复验证

用户确认现场无明显异常且未移动机构、未关闭9V后，仅将 `umax` 从0.75提高至0.85。从编码器71°补到90°，随后返回中位，再完成4组正负方向交替的90°往返，共10个动作全部成功。静止后最大误差2°，均无超调，部分结果已在2°容差边缘。结束返回中位、关闭马达输出；尚未验证舵机和魔方负载。这支持增加输出余量有效，但不能据此排除位置相关摩擦或供电瞬态。见[完整结果](measurements/2026-09-28-ev3-medium-installed/auto-085-results.json)。

### 加大驱动设置的对照

`umax=0.90, kfs=0.42`完成8次90°动作，全部成功，静止后最大误差2°，实际峰值输出65.4%，未触及上限。随后保持0.90上限，将kfs提高到0.46；4次30°动作与4次90°动作全部成功，静止后最大误差1°、最大超调1°，实际峰值输出75.5%。两组动作构成和样本数不同，不能据此证明统计优势或最优设置。当前暂选0.90/0.46，速度60°/s、加速度200°/s²，等待现场平顺性和温升反馈；未写入板上配置文件。结束位于编码器中位0°，输出已关闭。完整参数见[candidate-settings.json](measurements/2026-09-28-ev3-medium-installed/candidate-settings.json)，对照原始数据见同目录tuning-umax090.json与tuning-kfs046.json。

### 支撑装配修正

用户指出底部蓝色长销有挡肩，不能从一侧贯穿三层。撤回该安装方法；仅调整横竖销先后顺序不足以修复。当前第12步改为两根无挡肩4号轴＋四个半轴套，整套底座侧放后从下方穿轴，再从两侧套限位件。模型连接、旋转检查通过，另查轴沿轴线插入时不穿过非孔实体、半轴套最终位置无干涉；仍待实物安装验收。
