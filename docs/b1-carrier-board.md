# B1 底板方案（2026-10-14）

> 状态：**已出制板文件，未下单，未经实物验证**。工程在 [`electronics-b1/`](../electronics-b1/README.md)，输出在 `generated/electronics-b1/`。ERC 0 错误；DRC 0 错误、0 未连通；引脚映射测试通过。A1 集成板（`electronics/`）原样归档，本方案不改动它的任何文件。

## 1. 为什么改做 B1

A1 是 144×112mm 的四层集成板，上面直接焊裸 RP2040、USB-C、理想二极管和双降压，40 多种料要嘉立创双面贴片。光板加铜厚报价约 ¥553，贴片、换料和缺料代购还要另算。对个人兴趣项目来说太重了。

B1 的原则：
- **只有树莓派 Pico 是插上去的，其他元件全部焊在 PCB 上，并且尽量用贴片件**；
- 自己用热风枪和烙铁手焊，不用嘉立创贴片，也不用钢网；
- 贴片件选手焊友好的尺寸：电阻电容 0805 及以上，二极管 SOD-123/SMA/SMB，芯片 SOIC-8/SOT-223/TO-263/HSOP-8，所有元件都在顶面。只有排针、Pico 排母、DC 插座和 EV3 插座是通孔件。

| 项 | A1 集成板 | B1 底板 |
|---|---|---|
| 层数/尺寸 | 4 层 144×112mm | **2 层 99×99mm** |
| 装配 | 嘉立创双面 SMT 153 件 + 手焊 18 件 | **全部手焊，单面贴片 + 少量通孔插座** |
| 主控 | 裸 RP2040 + Flash + 晶振 + USB-C | 树莓派 Pico H 插排母（已有） |
| 电机驱动 | 4 颗 DRV8871 | 4 颗 DRV8871 |
| 舵机 5V | 两路 TPS54302 | LM2596S-5.0（TO-263-5） |
| 逻辑 5V | 同上 | AMS1117-5.0（SOT-223） |
| 估计费用 | 光板 ¥553，贴片另计 | 光板约 ¥20~50（以下单页为准），加散件 |

## 3. 电路

### 3.1 引脚（沿用 `wiring/spec.py` 的 `ARMS`，固件不用改）

| 用途 | R 臂 | L 臂 | F 臂 | B 臂 |
|---|---|---|---|---|
| 马达 IN1 / IN2 | GP2 / GP3 | GP6 / GP7 | GP10 / GP11 | GP14 / GP15 |
| 编码器 A / B | GP4 / GP5 | GP12 / GP13 | GP16 / GP17 | GP18 / GP19 |
| 舵机 | GP8 | GP9 | GP20 | GP21 |

- 接 Zero W 的 UART：GP0 / GP1 / GND，引出到 3 针排针 J2。
- 注意：`wiring/spec.py` 里的 `DRV_LEFT/DRV_RIGHT` 和 `docs/single_arm.md` 的驱动引脚表是 **DRV8833 模块**的，B1 不能照抄。
- DRV8871 没有 STBY 脚，真值表为：00 滑行，10 正转，01 反转，11 刹车。现有固件的慢衰减 PWM 和刹车逻辑与之一致。固件 `config.py` 注释里写的 DRV8833 以后再更新。

### 3.2 电源

```
DC 9V ─ 8A 慢断保险丝 ─ AO4407A 反接保护 ─┬─ VM 母线：SMBJ12A + 2×470µF + 2×300Ω 泄放 ─ 4 颗 DRV8871
                                          ├─ LM2596S-5.0 ─ SERVO_5V ─ 4 路舵机
                                          └─ AMS1117-5.0 ─ 5V_LOGIC ─┬─ 4 个 EV3 编码器电源（第 4 脚）
                                                                     └─ SS14 ─ Pico VSYS
```

| 部分 | 选择 | 理由 / 约束 |
|---|---|---|
| 输入 | 5.5/2.1mm DC 插座（DC-005，通孔），**中心正**，只接稳压 9V | DRV8871 工作电压 6.5~45V |
| 保险丝 | 1206 贴片慢断保险丝 8A | 只防短路起火，不限流；外部电源仍要能限流 |
| 反接保护 | AO4407A（P-MOS，-30V/12A，SOIC-8）串在正极：漏极(5~8)接电源侧，源极(1~3)接 VM；栅极经 10kΩ 接地；栅源之间并 BZT52C12 稳压管（阴极接源极） | 5A 时导通损耗约 0.3W。稳压管把 Vgs 限制在 12V 以内，回灌把 VM 推到 TVS 钳位约 19.9V 时也不会超过 ±20V 的栅极耐压 |
| 回灌吸收 | SMBJ12A（单向 TVS）+ 2×470µF/25V 贴片电解 + 2×300Ω/1W（2512）并联泄放（150Ω，约 0.54W） | P-MOS 导通后是双向导电的，刹车能量会倒灌回电源，而多数台式电源和充电宝都不能吸收反向电流，所以要在母线上用电容、泄放电阻和 TVS 吸收。参数沿用 A1 的分析：整板每次 ≤0.05J、≤5Hz |
| 舵机 5V | LM2596S-5.0（固定 5V/3A）+ 33µH/3A 贴片电感 12×12 + SS34 + 220µF 输入 / 470µF 输出贴片电解 | 遵守“舵机单独一路 5V，不和 Pico 共用”。散热片焊盘接两面地铜 |
| 逻辑 5V | AMS1117-5.0（SOT-223）+ 10µF 输入 / 22µF + 0.1µF 输出 | 负载约 0.1A，(9−5)×0.1 ≈ 0.4W，靠焊盘铜散热 |
| Pico 供电 | 5V_LOGIC 经 SS14 接 VSYS | 防止和 USB 供电互相倒灌（CLAUDE.md 原则），插着 USB 调试也安全 |

**大电流走线**：
- VM 主干在底层，宽 2mm：从电源区沿 x=36 下来，再横贯四颗 DRV8871 的上方；
- 舵机 5V 主干在顶层，宽 1.5mm：沿左边缘下来，再横贯舵机排针下方；
- 两条主干都由脚本锁定，各臂的支线 0.8mm（每臂 ≤1.5A），电机线 0.8mm；
- 两面都铺地铜，每个贴片接地脚就近打孔到底层，另加约 200 个缝合过孔。

### 3.3 DRV8871（每臂一颗）

- 封装：HSOP-8 带散热焊盘，复制 A1 已核对过的封装。KiCad 标准库里 HSOP-8 EP2.3 的尺寸不对，不能用。
- ILIM：43.2kΩ 1%，限流约 1.48A（I≈64/R，单位 kΩ）。EV3 大马达 9V 堵转电流约 1.8A，所以带载夹持要实测；力不够就换成 30kΩ（约 2.1A）。
- 去耦：0.1µF 0805，加 100µF/25V 贴片电解（6.3×7.7）。
- 输入不用加下拉电阻，芯片内部已有。
- 焊法：焊盘上薄涂锡膏，用热风枪吹，再用烙铁补焊引脚。散热焊盘有 6 个过孔通到两面地铜。

### 3.4 编码器、舵机、EV3

- 编码器：每路 10kΩ 串联 + 20kΩ 下拉（0805），面包板上验证过。固件保持 `ENC_PULLUP=False`。焊好后、插 Pico 之前，先用万用表量分压点，任何时候都不能超过 3.3V。
- 舵机：4 个 3 针排针，自下而上 G / + / S；信号经 220Ω 串阻直接接 GPIO。
- EV3：沿用 A1 封装（按用户提供的尺寸图），脚 1=M1、2=M2、3=GND、4=5V、5=编码器 A、6=编码器 B。针序还没用实物核实，接电机前要先做断电六路通断。封装是复制到 B1 自己库里的，没有改动 A1 的库。
