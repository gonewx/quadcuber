# B1 底板方案（草案，2026-10-14）

> 状态：**已出制板文件，未下单、未实物验证**（2026-10-14）。工程在 [`electronics-b1/`](../electronics-b1/README.md)，输出在 `generated/electronics-b1/`。ERC 0、DRC 0 错误、引脚映射测试通过。A1 集成板（`electronics/`）原样归档，本方案不改动它的任何文件。

## 1. 为什么改做 B1

A1 是 144×112mm 的四层集成板，上面直接焊裸 RP2040、USB-C、理想二极管和双降压，40 多种料要嘉立创双面贴片。光板加铜厚报价约 ¥553，贴片、换料和缺料代购还要另算。对个人兴趣项目来说太重了。

B1 的原则：**只有树莓派 Pico 是插上去的，其他元件全部焊在 PCB 上**。

- 能用通孔件的都用通孔件，自己手焊。
- 只有 DRV8871 没有通孔封装，是唯一的贴片芯片（HSOP-8，底部带散热焊盘）。
- 不用嘉立创贴片，也不用钢网。

| 项 | A1 集成板 | B1 底板 |
|---|---|---|
| 层数/尺寸 | 4 层 144×112mm | **2 层，≤99×99mm** |
| 装配 | 嘉立创双面 SMT 153 件 + 手焊 18 件 | **全部手焊**（4 颗 DRV8871 是贴片，其余通孔） |
| 主控 | 裸 RP2040 + Flash + 晶振 + USB-C | 树莓派 Pico 插排母（已有） |
| 电机驱动 | 4 颗 DRV8871 | 4 颗 DRV8871，直接焊在板上 |
| 舵机 5V | 两路 TPS54302 贴片降压 | **LM2596T-5.0 通孔降压**（TO-220-5） |
| 逻辑 5V | 同上 | 7805 通孔线性稳压 |
| 估计费用 | 光板 ¥553，贴片另计 | 光板约 ¥20~50，加散件 |

## 3. 电路

### 3.1 引脚（沿用 `wiring/spec.py` 的 `ARMS`，固件不用改）

| 用途 | R 臂 | L 臂 | F 臂 | B 臂 |
|---|---|---|---|---|
| 马达 IN1 / IN2 | GP2 / GP3 | GP6 / GP7 | GP10 / GP11 | GP14 / GP15 |
| 编码器 A / B | GP4 / GP5 | GP12 / GP13 | GP16 / GP17 | GP18 / GP19 |
| 舵机 | GP8 | GP9 | GP20 | GP21 |

- 接 Zero W 的 UART：GP0 / GP1 / GND，引出 3 针排针。
- `wiring/spec.py` 里的 `DRV_LEFT/DRV_RIGHT` 和 `docs/single_arm.md` 的驱动引脚表是 **DRV8833 模块**的，B1 不能照抄。
- DRV8871 没有 STBY 脚。真值表：00 滑行，10 正转，01 反转，11 刹车。现有固件的慢衰减 PWM 和刹车逻辑与它一致；固件 `config.py` 注释里的 DRV8833 以后再更新。

### 3.2 电源

```
DC 9V ─ 保险丝 ─ P-MOS 反接保护 ─┬─ VM 母线：TVS + 2×470µF + 泄放电阻 ─ 4 颗 DRV8871
                                 ├─ LM2596T-5.0 ─ SERVO_5V ─ 4 路舵机
                                 └─ 7805 ─ 5V_LOGIC ─┬─ 4 个 EV3 编码器电源（第 4 脚）
                                                     └─ 1N5819 ─ Pico VSYS
```

| 部分 | 选择 | 理由 / 约束 |
|---|---|---|
| 输入 | 5.5/2.1mm DC 插座，**中心正**，只接稳压 9V | DRV8871 工作范围 6.5~45V |
| 保险丝 | 通孔保险丝座 + 慢断保险丝，候选 6.3A，型号排版时定 | 只用来防短路起火，不起限流作用；外部电源仍要能限流 |
| 反接保护 | 通孔 P-MOS（IRF4905，TO-220）串在正极：漏极接电源侧，源极接 VM；栅极经 10kΩ 接地，栅-源之间并 12V 稳压管（1N4742A，阴极接源极） | 5A 时约 0.5W，串肖特基要约 2.5W。稳压管把 Vgs 限制在 12V 以内：回灌把 VM 推到 TVS 钳位约 21V 时，不会超过 IRF4905 ±20V 的栅极耐压 |
| 回灌吸收 | P6KE15A 通孔 TVS（工作电压 12.8V）+ 2×470µF/25V 电解 + 2×300Ω/1W 并联泄放（150Ω，约 0.54W） | 导通的 P-MOS 是双向导电的，刹车能量会回到电源，可多数台式电源和充电宝都不能吸收反向电流，所以母线上要靠电容、泄放电阻和 TVS 吸收。参数沿用 A1 的分析：整板每次 ≤0.05J、≤5Hz |
| 舵机 5V | **LM2596T-5.0**（固定 5V，3A，TO-220-5）+ 33µH 通孔电感 + 1N5822 + 电解电容 | 全通孔、固定输出，不用调电位器。遵守“舵机单独一路 5V，不和 Pico 共用”，避免舵机启动把 Pico 拉复位。4 个 Geekservo 同时堵转约 2.8A，接近上限；正常开合远小于此 |
| 逻辑 5V | 7805（TO-220） | 负载约 0.1A，功耗 (9−5)×0.1 ≈ 0.4W，不用散热片 |
| Pico 供电 | 5V_LOGIC 经 1N5819 接 VSYS | 防止和 USB 供电互相倒灌（CLAUDE.md 原则），插着 USB 调试也安全 |

**大电流走线**：板子是 1oz 双层。入口到 VM 母线约 5A，用正反两面并联的宽铺铜，不能走细线。电机线每路 ≤2A，线宽 ≥1.5mm。所有地共地。

### 3.3 DRV8871（每臂一颗）

| 元件 | 值 | 封装 |
|---|---|---|
| DRV8871DDAR | — | HSOP-8，带散热焊盘（贴片，手焊）。封装复制 A1 已核对的 `Texas_HTSOP-8-1EP_3.9x4.9mm_P1.27mm_EP2.95x4.9mm_Mask2.4x3.1mm_ThermalVias`；KiCad 标准库的 HSOP-8 EP2.3 尺寸不对 |
| ILIM 电阻 | 43.2kΩ 1%（约 1.48A，与 A1 相同）。可选 30kΩ，约 2.1A | 通孔 1/4W |
| VM 去耦 | 0.1µF 陶瓷 + 每臂 1 个 47~100µF/25V 电解（数据手册推荐） | 通孔 |

- 限流公式：I ≈ 64/R(kΩ)。EV3 大马达 9V 堵转约 1.8A，选 43.2kΩ 会让堵转扭矩略低，带载夹持要实测；嫌力不够就换 30kΩ。
- 输入不用加下拉电阻，芯片内部已有。
- **散热焊盘的焊法**：用户有热风枪，按常规方法焊：焊盘上薄涂锡膏，用热风枪吹，再用烙铁补 8 个引脚。散热焊盘接一圈散热过孔和两面大片地铜。
- 散热：2 层 1oz 地铜加过孔散热，按 A1 的估算，每路 ≤0.75A RMS 时没问题；长时间堵转会进入芯片的热保护。

### 3.4 编码器

- 每路 **10kΩ 串联 + 20kΩ 下拉**，共 8 组，用通孔 1/4W 电阻。大马达高电平约 3.0V，中马达黄线约 2.7V，这套已在面包板上验证过。
- 固件 `ENC_PULLUP=False`。
- 焊好后、插上 Pico 之前，先用万用表量每个分压点，任何时候都不能超过 3.3V。

### 3.5 舵机

- 4 个 3 针排针，顺序 G / + / S，与 A1 和现有 Geekservo 线序一致。
- 信号直接接 GPIO（单臂测试就是这样接的），串一个 220Ω 电阻保护。

### 3.6 EV3 插座

- 沿用 A1 的封装（来自用户的尺寸图）：脚 1=M1、2=M2、3=GND、4=5V、5=编码器 A、6=编码器 B。
- 封装要**复制**到 B1 自己的库，不要改 `electronics/lib`。A1 首板包会逐字节校验那里的文件。
- 针序还没用实物核实。接电机前，先做断电六路通断检查。
