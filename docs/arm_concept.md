# 机械手概念设计（乐高搭建参考）

> **已有完整搭建说明书**：[docs/lego/index.html](lego/index.html)（20 步，含零件清单），由 `tools/lego/` 按官方零件尺寸建模并自动检查。下面是它背后的设计思路和尺寸要求。

"机械手"指的就是**用乐高搭的夹持 + 旋转机构**，整机有 4 个，分别在魔方的 R / L / F / B 四个方向。按项目分工，乐高结构由你搭建和迭代；这份文档只给**思路、几何尺寸要求和验收标准**，不是零件清单。零件怎么选、怎么固定，请按手上的零件自由发挥，搭出来拍照给我，我帮你对照下面的要求检查。

> ⚠️ 下面的方案是按 `quadcuber/machine.py` 里的机器模型推出来的，**没有经过实物验证**。凡是标"待验证"的地方，都请以实物为准；实物和模型对不上时，改模型比硬凑结构更好。

## 1. 一个机械手由什么组成

```
           侧视（沿魔方的 R 方向看过去，魔方在左）

   魔方          叉子            滑块/滑轨          旋转马达
 ┌──────┐   ┌──┐
 │      │===│  │=============[ 滑 块 ]==========┐
 │ 中间 │   │  │   ← 舵机推拉，行程 ≥13mm →     ├──[ EV3 马达 ]── 固定在机架上
 │  一列 │===│  │=============[ 滑 轨 ]==========┘
 └──────┘   └──┘
           ↑ 两根叉齿卡住中间一列上下两个棱块
```

三个部分：

1. **旋转**：EV3 马达固定在机架上，输出轴与魔方的面中心**同轴**。整个夹持部分装在马达输出轴上，跟着转。**尽量直接驱动，不加齿轮**（EV3 马达自身已有回差，每多一级齿轮回差就更大）。
2. **叉子**（模型里的"夹条"）：一个 U 形叉，两根叉齿的内侧间距等于魔方边长。叉子推上去时，两根叉齿分别压在这一面**中间一列**的两个棱块的外侧（叉子竖直时，就是上面那个棱块的顶面和下面那个棱块的底面）。
3. **开合**：Geekservo 通过齿轮齿条（或曲柄连杆）推动滑块，让叉子沿旋转轴方向**前进（夹紧）/ 后退（松开）**。

为什么是"叉子前后移动"，而不是两根手指捏合：

- **靠形状传递扭矩，不靠摩擦**。叉齿卡在棱块外侧，马达一转，这一层就被拨着走，不怕打滑。
- **靠形状托住魔方**。左右两个叉子都竖直时，下面的叉齿直接托住魔方，不靠夹紧力。
- 舵机只负责推进和退出，需要的力很小。

## 2. 为什么这个结构符合规划器的约束

以 F 方向的机械手为例（魔方的前面）：

- 叉子**竖直**时，卡住的是前面中间一列：上棱、中心、下棱。这三块不属于 R 层也不属于 L 层，所以 R、L 可以照常转动 → 对应规则"拧面时，与它垂直的机械手夹条必须竖直"。
- 叉子**水平**时，卡住的是前面中间一行：左棱、中心、右棱，其中左棱属于 L 层、右棱属于 R 层，会挡住 R、L 转动 → 所以规划器不允许这种情况下拧 R、L。
- 竖直叉子卡住的上、下棱块属于中间层，所以它还能**固定中间层** → 对应规则"至少有一个垂直的机械手夹紧"。

## 3. 关键尺寸（最重要的部分）

下面以 **56mm 魔方**为例（每个小块约 18.7mm），括号里是 57mm 魔方的值。

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 魔方 | 建议选 56mm 的磁力速拧魔方 | 磁力能帮魔方自动归位，抵消几度的误差；手感调松一点。56mm 正好能配乐高尺寸，见下一行 |
| 叉齿内侧间距 | 魔方边长 + 0.5~1mm | 两根梁中心相距 8 个孔（64mm）时，内侧间距约 64 − 梁宽 ≈ 56.8mm，刚好适合 56mm 魔方（梁宽按 7.2mm 估算，**待实测**）。57mm 魔方放不进去（56.8mm < 57mm），必须加大开口（例如叉齿改成 9 个孔距 + 内侧垫片调回合适间距）或换叉齿结构；**不能**只在现有叉齿内侧垫片 |
| 叉齿宽度 | **≤ 16mm**，并且居中 | 叉齿只能碰中间一列，碰到旁边一列就会挡住相邻层的转动。1 个孔宽（约 7~8mm）的梁最好 |
| 叉齿插入深度 | 6~10mm | 太浅容易滑脱，太深需要更长的退出行程 |
| **退出行程** | **≥ 13mm**（插入 8mm 时） | 见下方计算。舵机经齿轮齿条推动：8 齿齿轮转 270° 约能推 19mm，够用 |
| 叉子"头部"的宽度 | 在魔方面前方 **14mm 以内**，除了叉齿，任何零件的宽度都不能超过 16mm | 否则会挡住相邻层（见下方计算）。宽的零件（滑轨、舵机）要放在离魔方面 14mm 以外 |
| 同轴度 | 旋转轴对准面中心，误差 ≤ 1mm；相对的两个机械手同轴 | 偏心时一转就会别住魔方 |
| 旋转到位精度 | ±3° 以内为目标 | 叉齿只有 8mm 宽，靠叉齿边缘压魔方表面传递扭矩，力臂只有 ±4mm。每侧 0.4mm 间隙时，叉子和这一层之间约有 **±4.5° 的空转**（叉齿 16mm 宽约 ±2.7°；间隙减到每侧 0.2mm 约 ±2.5°）。以前写的“±1°”错把接触点当成了魔方角上，不对。减小空转的办法：叉齿加宽到接近 16mm，或者给叉齿加弹性预紧消除间隙（同时解决下面“水平支撑”的问题）。编码器读数只代表马达角度，验收要看魔方面，见第 7 节 |
| 刚度 | 叉子、滑块、机架在拧面时不能明显变形 | 可以用手拧一拧魔方试试，叉子和机架不应该晃 |

### 退出行程是怎么算的

叉子松开后，另外一对机械手可能会带着整个魔方翻转。魔方翻转时，角块扫过的圆半径等于面对角线的一半：56mm 魔方约 39.6mm（57mm 魔方约 40.3mm）。再留 2mm 余量，叉齿尖端必须退到离魔方中心约 41.6mm 的圆以外。

叉齿内侧离魔方中心约 28.4mm，所以叉齿尖端要退到离中心至少 30.4mm 的位置。插入 8mm 时，叉齿尖端离中心 20mm，因此至少要后退 10.4mm。再加上搭建误差，**建议行程 ≥ 13mm**。插入 10mm 时，行程需要 ≥ 15mm。

### 头部宽度是怎么算的

F 方向的叉子夹着魔方时，R 层可能在转。R 层的角块同样扫过半径约 39.6mm 的圆。所以在 R 层所在的范围里（离中心 9.3~28mm），叉子的任何零件都必须离魔方中心 41.6mm 以上，也就是**离魔方前面至少约 14mm**。离魔方更近的地方，只有中间那根窄窄的叉齿（宽度 ≤ 16mm）不会碰到 R 层和 L 层。

## 4. 舵机线缆的问题

最简单的做法是把舵机装在滑块旁边，跟着马达一起转。这样线会缠绕，旋转角度就受限制。

- **单臂原型阶段这样做完全没问题**：测试程序的 `bench` 和 `cycle` 都是来回转，线不会越缠越多。转之前把线留够长，确认能正反各转 180° 就行。
- 整机阶段，规划器在**有角度限制时规划非常慢**（见 CLAUDE.md）。所以以后最好让机械手能无限旋转，大致有两种思路（都**待验证**）：
  - 舵机固定在机架上不转，通过旋转轴中心的推杆，或者套在轴外、可以相对转动的推环，去推动滑块；
  - 用滑环给舵机供电。
  这一点等单臂测试通过后再考虑。

## 5. 单臂测试时魔方怎么固定

单臂测试需要"只让一层转，其余部分不动"。最简单的办法：

- 另外搭一个**不能转的叉子**，竖直卡在 F 面上。它卡住的上、下棱块属于中间层，能把魔方的其余部分固定住。
- 魔方下面不要垫东西。垫了以后，被拧的那一层底部会有摩擦。可以让 F 面这个固定叉子的下叉齿托住魔方，必要时再用手轻轻扶着。
- 然后用测试程序的 `bench 1 20 load` 和 `cycle 20` 测拧面。

## 6. 建议的搭建顺序

1. 先只搭**旋转部分**：马达固定在底座上，输出轴上装一根梁当指针。接上电路，跑 `check`、`cal`、`speed`、`friction`、`bench`（见 [single_arm.md](single_arm.md)）。这一步只检验电路和马达控制，和机械结构无关。
2. 搭**叉子 + 滑块 + 舵机**，先不装到马达上。用 `servo <脉宽>` 命令找到前进和后退的位置，并检查行程是否 ≥ 13mm。
3. 把叉子部分装到马达上，搭固定用的 F 面叉子，开始测拧面。
4. 拍照、录像，连同 `arm.log` 一起发给我。

## 7. 请重点反馈

- 叉子、滑块、马达连接处的**特写照片**，最好旁边放一把尺子；
- 实测的叉齿内侧间距、叉齿宽度、退出行程；
- `cycle` 时的录像：有没有卡住，叉子退出时有没有把魔方带歪；
- 左右两个竖直叉子能不能**只靠叉齿托住魔方**（整机支撑的前提）。
- **水平支撑是整机最大的风险**：叉子只是前后移动，开口（约 56.8mm）并不会收紧，所以“推进去”不等于“夹紧”。叉子水平时下面没有叉齿，魔方只能靠摩擦力挂住，而现在的结构几乎没有压紧力。整体翻转时承重的一对叉子一定会经过水平姿态，所以这一点不解决，四臂整机就不成立。建议先做**一对相对的叉子**（第二个可以是不转的固定叉），慢速把魔方整体转 90°，看整个过程会不会下滑、脱出。托不住的话，优先试带少量弹性预紧、间距可调的叉齿（例如叉齿用软轴/细梁做成可以向内压的弹片），改完要重新检查相邻层转动的间隙。
- **转到位后的实际角度**：分别看马达（编码器）、叉子、魔方面三处的最终角度，重点看正反换向；用固定的手机拍摄，在叉子和魔方上贴对齐标记，记录松开夹爪前后的变化。最终标准是“下一次相邻面转动是否顺畅”。
