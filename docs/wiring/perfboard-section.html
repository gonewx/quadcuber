焊接顺序与检查

  1. 先只焊 J1/J4 端子底座、J5 排针、J6/J7 排母、U1 两排排母和 U2 四角排母；DRV8833 先不插。核对 A1、各接口正负和两排间距。
  2. 按 W01～W14 焊接绝缘导线。断电测各线首尾导通；DRV8833 和降压都拔下时，9V、5V、地和各信号网络之间不能短路。
  3. 先只插 U2 降压模块，按“电源与拔插结构”接 9V，空载调到 5.0V。确认 J5.2、J6.1 对各自 GND 约 5V，再断电放电。
  4. 插入 DRV8833，接 J6、J7 和编码器，Pico 仍用 USB。先按单臂步骤测马达，再断电接舵机测试。
  5. 大电流导线和接点按实际启动电流选型；带载检查压降、温升与 VM 瞬态，DRV8833 工作电压不超过 10.8V。用绝缘底板保护焊接面，线束留松弛并固定，插拔时扶住底座。

接面包板：J6.1 → 上排 +，J6.2 → 上排 −；J7.1 → j6（GP2），J7.2 → j7（GP3），J7.3 → j13（GP8），J7.4 → a7（3V3）。编码器分压电阻和跳线见④。完整说明见洞洞板设计文档。
