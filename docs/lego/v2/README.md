# 单臂原型 v2：专业评估与重新设计

v1（`docs/lego/`、`tools/lego/model.py`）保持不动。v2 放在独立目录：模型和检查在 `tools/lego/v2/`，说明书在 `docs/lego/v2/index.html`。

## 一、v1 评估结论：能用，但还是“功能原型”

以资深乐高 Technic 设计的标准来衡量，主要看四点：载荷路径是否清楚；每个连接是否至少有两点定位；子组件能否单独搭建；是否优先采用官方验证过的结构。

**v1 做得好的地方：**

- 叉子的偏置曲柄滑块、死点、插入深度和退让间隙都有推导。
- `check.py` 的体素干涉、销孔啮合和长销挡肩检查很扎实，v2 直接复用。
- 马达尾部的 TRACK3R 耳朵固定有官方出处。

**v1 没达到专业水准的地方：**

| 方面 | v1 的问题 | 后果 |
| --- | --- | --- |
| 承重 | 整个机械臂（从输出盘到叉尖约 150mm）只挂在马达输出盘上的 3 个销上。3 个销排成一条线，上下相距 16mm。 | 输出轴内部轴承的间隙会在叉尖放大十几倍。这是实物下垂的根本原因，前面几次补丁只是在马达外面加固。 |
| 马达固定 | 耳朵框架挂在长销短头上，再依次补了 3 层摩擦销垫块、底部垫梁和一根长销。 | 三次实物补丁叠在一起，每一处都是单点受力，传力路线说不清楚。 |
| 导轨 | 12 号轴只插在 1 孔厚（8mm）的圆孔里，向前悬伸 84mm。后来补了两片细梁。 | 根部夹持太短。 |
| 舵机 | 偏在转动座一侧，只靠长销短头挂着。 | 机械臂重心偏离转轴，转动时有偏心力矩。 |
| 测试架 | 单层梁墙，两根 15 孔梁搭接。 | 抗扭差。马达和固定叉都挂在这面墙上。 |
| 装配 | 多处要翻转整机、从缝里插销。 | 难搭，也难拆了重装。 |

**四臂问题（v1、v2 都有）：** 如果相邻两只机械手同时处于“叉齿水平”的角度，两副叉齿会在魔方棱边附近相撞（一只的叉齿在 z = ±80，另一只在 x = ±80，范围重叠）。四臂规划器需要加一条约束：相邻机械手不能同时水平。现有检查只查单臂，还缺四臂之间的干涉检查。

## 二、v2 的核心原则：承重和传扭分开

1. **转盘当主轴承。** 机械臂装在 60 齿转盘上（18938 上半 + 18939 下半），这是 LEGO 起重机回转台的标准件，专门承受倾覆力矩。
   - 固定方式照搬官方 42082 / 42100，已用 LDraw 官方模型库（OMR）里两套模型的几何核实：7x5 框架和转盘耳朵在同一平面，框架 5 孔长的开口正好套住耳朵，销沿径向穿过“框架短边—耳朵”。
   - 转盘只有两侧有耳朵，每侧 3 个径向孔。
   - 下半接竖立的支座框架，上半接机械臂的两块侧板。
2. **马达只传扭矩。** 输出盘的 4 个销孔不用，只在中间的十字孔插一根 7 号轴。
   - 这根轴穿过转盘中孔，前端插在舵机座的中孔里（圆孔，兼作轴承）。
   - 中间两片 3 孔细梁的十字孔卡住轴，一片朝上、一片朝下，各用一个销带动舵机座。
   - 马达和转盘的轴线即使稍有偏差，7 号轴也能弯一点吸收掉。
   - `run_check.py` 会检查确实没有销插在输出盘销孔上。
3. **机械臂是一个闭合盒子。** 由两块侧板、舵机座和两根 16 号导轨组成。
   - 导轨依次穿过侧板后边、舵机座端孔和侧板前边，3 个支点，跨度 80 LDU（32mm），两侧用轴套锁定。
   - 舵机座是一根竖放的 7 孔梁，7 个孔都有用途：中孔穿传动轴，±1 孔接传扭销，±2 孔装舵机长销，±3 孔穿导轨。
   - 舵机居中装在转轴上，左右对称。
4. **叉子也是盒子。** 叉子框架两侧各加一块同向框架，用 4 根 7 号轴加轴套连成盒子。
   - 两侧框架的短边套在导轨上滑动，前后支点相距 120 LDU（48mm）。
   - 叉齿和夹心梁沿用 v1，夹魔方的尺寸已经验证过。
5. **活动关节用无摩擦销（3673）。** 曲柄和连杆两端都换成无摩擦销，舵机负载更小；摩擦销只用在固定连接。
6. **底座只用 7x5 框架。**
   - 一种零件做到底，全部共面拼接：短边对短边、长边对长边，都是穿侧孔的销。
   - 上下两层用竖销互相压住。
   - 固定叉立在自己的 L 形竖板上（三块框架共面拼成），再用拉梁夹住。
   - 马达保留 TRACK3R 耳朵固定，固定板底边用 3 个竖销（其中 2 根蓝色长销贯穿三层）压到底板上，一步装好。

## 三、关键尺寸

- **坐标：** 马达在原点，输出盘端面 x = 30（与 v1 相同）；转盘中心 (60, 0, 0)；魔方中心 (520, 0, 0)；桌面 y = 150。
- **转盘占位：**
  - 下半（固定）占 x 30~65。支座框架在 x 30~50，与下半的耳朵共面。
  - 上半（转动）占 x 50~90。侧板从 x = 70 开始，销在 x = 80 穿过上半耳朵。
- **机械臂转动半径 ≤ 99 LDU**，侧板的角离轴线最远。所有固定件满足下面两条之一：在 x ≤ 50 范围内；或者到转轴的距离大于 105。
- **曲柄连杆：**
  - 舵机输出轴在 (x = 150, z = 10)，朝上。曲柄半径 20，连杆 120，连杆销在叉子框架上边的 (x_ff − 40, z = 0)，偏置 e = 10。
  - 行程 = √(140² − 10²) − √(100² − 10²) ≈ 40.1 LDU ≈ 16.1mm。
  - 夹紧时叉尖插入魔方 29.6 LDU（11.9mm）；松开后叉尖离魔方表面 10.5 LDU（4.2mm）。这时魔方整体翻转，角块扫过半径 99，叉尖最近处离魔方中心 106.7，碰不到（`run_check` 已验证 0~90°）。
- **曲柄要从下方（−Z 一侧）转过去。** 曲柄最外端离输出轴 50 LDU：从 −Z 一侧转最远到 z = −40，碰不到侧板（z ≥ 50）；从 +Z 一侧转会碰到侧板。程序只检查了两个死点，**舵机的转向要在实物上确认**。
- **为什么不用 36 齿齿轮当传扭盘：** 齿轮半径 47 LDU（19mm）。松开位置时，曲柄末端落在 x 101~119、离轴线 45 左右的地方，正好压在齿轮上。换成两片 3 孔细梁后，它们只在上下方向伸出，让开了曲柄平面。

## 四、要买的零件

EV3 套装里通常没有，或者数量不够：

- 60 齿转盘上半 + 下半（18938 + 18939）1 套：核心零件，必须买。
- 7x5 框架（64179）共 19 块：底座 8 块、转盘支座 2 块、固定叉 3 块、马达固定板 1 块、机械臂和叉子 5 块。手头不够时，可以先只搭机械臂、转盘支座和马达部分，放在桌上用手扶着做单臂测试。
- 16 号轴（50451）2 根、7 号轴（44294）5 根、灰色无摩擦销（3673）2 个、轴套（3713）18 个。

完整数量见说明书的零件清单。

## 五、检查

```bash
cd tools/lego/v2
python run_check.py      # 0 个问题才算通过
python ../render/server.py &   # 另开终端
python booklet.py        # 生成 docs/lego/v2/
```

`run_check.py` 复用上一级的 `check.py` 和 `ldraw.py`，没有修改它们，只在运行时补充新零件的长度，并豁免“转盘上下两半互相卡住”这一对零件。检查项包括：

- 夹紧和松开两种状态下的干涉、连接和长销挡肩；
- 机械臂每 15° 转一格，转满一圈的转动扫描；
- 松开时魔方整体翻转 0~90°；
- 马达输出盘上没有销。

## 六、待实物验证（模型保证不了）

- **转盘承载后的晃动：** 锁住马达，轻推叉尖，看位移是否明显小于 v1。转盘本身有齿隙和轴向间隙，需要实测。
- **7 号轴传扭：** 是否打滑、是否别劲。手转机械臂一圈应顺滑。
- **支座与底板的配合：** 底板前块要从支座下框的开口里穿过去，配合松紧需要实物确认。
- **舵机线缆：** 线缆随机械臂转动，不能无限旋转，规划器仍然要限制角度。
- **整体刚度：** 底座框架多，自重下的平整度和刚度都只能靠实物检验。
