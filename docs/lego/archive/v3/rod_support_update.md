# 推杆缩短与支承前移

**已将模型推杆从120mm缩短到104mm，夹紧时前悬伸从63.823mm降到47.823mm。承重问题尚未全部解决：前端仍有4处不足1mm的运动间隙，实物刚度、保持力和带载运行尚未验收。**

## 为什么需要改

原推杆有两个后部导向孔，不是全长悬空；但前导向孔到驱动铰点相距约64mm。公共接头增加Watt导向后，后部驱动布局仍值得缩短。

此前只强调平面内驱动竖向反力近零，容易漏掉偏心弯矩。100g由两臂理想均分、仅计重量增量、夹紧姿态时，两片驱动薄梁在正负Z侧的轴力分别约+0.441928N、−0.110482N，作用面距中面各6mm。它们向推杆前接头传入约0.331446N轴向合力，**同时传入3.314460N·mm绕Y弯矩**。该弯矩会使推杆沿轮轴方向弯曲，不能用竖向合力近零将它忽略。

这是同一空间二力杆算例的载荷合成，仍省略孔轴弯矩、接触弹性和实际分载。它说明需要检查推杆受弯，不等于已经预测实物下沉量。

## 为什么是2L＋11L

直接前移导向框并改用3L＋10L，原连接器在行程约79%后会碰到前导向框。2L前短轴使连接器前移一个孔距，避开该位置；11L后轴同时保留足够的导向孔覆盖。

短轴插入32013约一孔深，另一半插入59443；后轴插入连接器另一半。两根轴的名义端点在连接器中央相接，实际网格有端部倒角。连接器与32013端面自然贴合，不再保留一孔裸露短轴，不能靠拔出短轴少插一截来调尺寸。

32013网格端面比名义平面多出0.0005LDU（0.0002mm），FCL因此把固定端面贴合报为相交。检查只对同轴、中心距恰为50LDU的这一指定零件对作端面接触分类，并验证向后分离0.001LDU后确实分离。回归检查确认，额外过插0.01LDU也不会被豁免。这不是运动间隙放宽。

## 缩短能改善多少

以同一材料、截面和载荷的均匀梁作方向性比较，两个理想简支间距为a、前悬伸为b：

- 端部横向力引起的位移柔度为 `b²(a+b)/(3EI)`；当前约为原来的0.481倍。
- 端部弯矩引起的位移柔度为 `(b²/2+ab/3)/EI`；当前约为原来的0.624倍。

不能直接把这些比值当作整机刚度或实测下沉改善比例。实际轴连接器、十字孔、圆孔、塑料蠕变和支架都有额外柔度；尤其不能把本结构套成完全固支的单段悬臂，只按长度三次方给结论。
