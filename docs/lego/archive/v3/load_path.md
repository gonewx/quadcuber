# 公共接头承重结构与验证

当前模型采用两侧 Watt 近似直线导向，给公共接头增加横向支承。直推杆通过铰接薄梁驱动，开合轨迹按真实杆长求解。设计和刚体检查已完成；100g实物承重、间隙、回差及交接尚未验收。

## 为什么改这里

用户压下夹指时，观察到相连链路整体上翘。夹紧位置计算表明：公共接头竖移0.1mm，会使上下轮端同向反移约0.255mm。旧模型把公共接头高度直接固定为零，未验证实物如何提供这项约束。

本次让上翘反力经公共轴、Watt横梁、两根摆杆、32140根支架传到侧架，再经转盘和固定平台回到底座。驱动端保留铰接，允许Watt轨迹偏离严格直线；不要求推杆靠弯曲兼容两条轨迹。

这解决理想结构缺少明确横向支承的问题。塑料刚度、轴孔间隙及转盘摆动仍需通过实物测量判断。

## 结构与装配

- 每侧用11478五孔薄梁作横梁、两根32017五孔薄梁作摆杆，两个32140支架各有两个固定连接点。支架末端是十字孔，使用轴连接。
- 公共轴用32073五号轴。由中面向外依次为整轴套、32449驱动薄梁、32017输入薄梁、11478横梁、外半轴套；两侧镜像。驱动薄梁末端十字孔带动公共轴转动，其余活动圆孔保持自由。
- 直推杆前端32013铰接头与公共轴相距24mm，两片32449构成铰接驱动。推杆改为2L＋59443＋11L，舵机和导向框前移16mm，总长从120mm减至104mm，前悬伸由63.823mm减至47.823mm。全行程覆盖两个导向轴承，最小孔外名义余量8.177mm。见[推杆修订](rod_support_update.md)。
- 主臂输入点采用24316带止挡轴，肩部位于输入薄梁外表面，内侧轴套定位。按图保留附近摆杆的空间，不自行加长轴尾。
- 侧架前角用32526两点连接根架及7孔侧长梁。后部6632、41677通过3749十字轴段固定相对角度；87083带止挡轴连接外侧梁和间隔套。这里必须保持十字孔配合，换成全圆孔铰链会引入侧架活动。
- 转盘、马达、舵机和固定平台后移32mm，底座相应外扩，四个后端增加落地梁。先装前角和侧梁，再接Watt支架和根架，按步骤留出连接销的插入方向。

完整装配：[24步说明与可旋转模型](index.html)；整机1040件，不含展示魔方。准确零件数和库存扣除见[BOM](bom.csv)。

约束矩阵用横梁半长缩放转角项。三条独立杆长约束限制公共接头的平面内位置和横梁转角；满秩表示该刚体模型没有自由上翘模式，不表示实物没有弹性位移。

防翻折限位仍独立保留：正常开端留隙，约29.775°挡止，上下分支分别按实际公共接头轨迹验证。见[防翻折报告](open_stops.md)。

## 100g重量的增量静力

取重力0.980665N；下表为两臂理想均分、夹紧姿态、仅重量增量，不包含轮胎预载、机械头自重、线缆和动态冲击。

| 量 | 单臂结果 |
|---|---:|
| 下轮端附加载荷 | 0.490333N |
| 输入杆轴力增量幅值 | 1.291348N |
| 输入杆传给公共接头的竖向力（上翘） | 1.248088N |
| 正Z侧各Watt摆杆轴力幅值（空间二力杆算例） | 约0.485375N |
| 负Z侧各Watt摆杆轴力幅值（同一算例） | 约0.138679N |
| 铰接驱动轴力 | 0.331446N |
| 铰接驱动竖向反力 | 理想值约0 |
| 推杆前接头横向弯矩 | 3.314460N·mm |
| 转盘附加俯仰矩 | 0.054873N·m |

上下输入杆位于轴向±10mm，重量增量由下输入杆传入，因此公共接头另受Mx=12.480881N·mm、My=−3.314460N·mm，不能把摆杆反力左右均分。空间算例按摆杆轴向中心面±18mm、驱动薄梁±6mm施力，分别平衡两根横梁的Mz，并检查全部六个力／力矩分量。正、负Z侧驱动力分别约+0.441928N、−0.110482N，一侧会反向受力。

两侧驱动力在轴向±6mm处传入推杆前接头，合力之外还产生约3.314460N·mm绕Y弯矩。不能因为竖向合力近零，就把推杆视为不受弯。缩短后的尺寸和相对柔度估算见[推杆支承报告](rod_support_update.md)。

此算例将摆杆及驱动薄梁视为二力杆，省略孔轴弯矩和轴向接触力；实际连接可传递这些反力，分配与刚度有关，不能把算例当作唯一实物结果。计算另检查主臂平面力矩平衡，并用轮端位移雅可比核对虚功；1、2、4臂分载及每轮1N预载示例保存在[原始计算](load_path_checks.json)。1臂算例仅检查局部载荷，不表示单臂可以稳定夹持整个魔方。

轮端到转盘平面距离由79.91mm增至111.91mm，俯仰力矩约增加40%。0.1°整头俯仰对应约0.195mm轮端竖移，所以转盘和侧架的实物刚度是本版关键验收项。

## 避让证据与未满足指标

- 连接、插深、孔型及装配方向检查：0问题。
- 81个开度三角网格检查：0非配合相交。
- 前端整套对竖直邻臂和本臂固定件：288状态、4472次精细查询，全部检查零件对间隙下界≥2mm。
- 侧架对齿轮外轴套：连续整圈包络下界4.4mm。
- 四臂离散运动筛查：576状态通过；相邻机械手仍不能同时水平。

**活动轴对驱动组件的连续开合保守下界为1.9999mm，约2.0mm**；后部旋转轴套对连杆的下界增至2.577mm。横梁端孔改为十字孔后，活动轴外移2mm、取消内半轴套，保留外半轴套及完整孔内插深。轴向保持仍依赖十字配合摩擦，必须实测迁移与拉脱。

导向内部仍存在约0.800～0.977mm运动间隙，邻臂对转动单层为1.333mm，不能据本轮两处改进判定整机带载间隙合格。完整对照及剩余部位见[间隙修订报告](motion_clearance_update.md)。

导向内部相邻零件与“前端对邻臂／固定件”是不同检查集合，不能把后者的≥2mm套用到导向内部。

## 自由滚轮的定位限制

允许轮毂自由滚动、只考虑接触法向和轮轴方向力时，相对两臂接触约束矩阵秩为5，四臂为6。两臂沿共同夹持轴方向依赖未测滚阻、接触状态和交接定位。满秩也不证明单向接触、摩擦锥内能抵抗任意扰动，因此不能据此宣称全姿态力封闭或承重稳定。

## 验收与设计取舍

执行[100g加载、下沉与交接测试](gravity_test.md)，在[记录表](gravity_test.csv)填写公共接头、Watt支架、根轴、轮端和魔方中心位移。实测栏保持未执行，固件脉宽必须重新标定。

本版接受三项设计取舍：铰接驱动增加接头游隙来源；转盘后移增加32mm悬伸及俯仰矩；固定角部的侧架增加零件和装配步骤。三项分别由轴套保持／回差、转盘刚度及装配检查验收。现有证据支持制作并测试样机，尚不支持“实物承重已通过”或“全球最佳”的结论。
