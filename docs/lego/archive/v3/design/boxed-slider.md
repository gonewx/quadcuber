## 结构选择

采用三块64179整体框、左右根部立梁、T形接口梁组成空间骨架。前导轨座收窄，避免松开回转时碰到相邻机械头。夹指根轴在左右内立梁支承，中心距32mm；增加外侧骨架没有扩大这段跨距。

- **导向：**两根23948十一号轴，中心距16mm；39793厚连接块作滑块，另一块作前端固定座。后座使用两只32184。轴穿圆孔滑动，顺滑程度和磨损须试装确认。
- **输入：**每个夹指用两根左右对称的32316五孔粗梁。上下夹指的杆件处于不同层，但每个夹指自身对称，避免单侧输入把夹紧力变成滚转力偶。
- **根部：**内外立梁分担支承，粗梁延长段连接中间承重梁与根部。T形整体梁同时连接转盘两个孔及中梁两个孔，消除两根短连杆可能形成的四杆自由度。
- **驱动：**50451十六号轴作一体推杆，通过32013和两片41677连接公共输入轴。后部舵机、曲柄滑块、导向框及底座位置沿用现方案。舵机终点须按新行程重新标定。
- **零件限制：**不使用3×5 L形粗梁；全圆孔薄梁为零。保留的41677、32449和32056均含十字孔，不能换成外观相似的全圆孔薄梁。

## 几何验证结果

| 检查 | 结果与范围 |
| --- | --- |
| 单臂开合 | 81个位置、2532次网格距离查询，无未解释相交 |
| 连接 | 闭合／松开端孔型、销插深、长销检查无报错 |
| 固定骨架 | 31个刚体，180个自由坐标，约束秩180；理想铰接模型未发现自由铰链 |
| 回转与邻臂 | 288种组合、3256次查询，无相交；采样最小间隙1.589mm |
| 魔方与硬件 | 81个开合位置＋72个松开回转角，无相交；非轮胎最小间隙1.093mm |
| 松开轮胎回转 | 每5°采样，距56mm魔方最小2.314mm |

回转组合为本臂闭合／松开、本臂每5°回转、前后邻臂同时闭合／松开且保持竖直。没有证明所有机械头同时任意旋转时的连续空间包络。保留转盘上半的既有啮合／安装界面不计入新增前端回转查询；单臂开合仍检查它与新结构的关系。轴销入孔及轮毂轮胎配合单列；指定的固定框架贴合面通过微量分离复查，未用这一规则豁免活动件穿入。

约束秩以理想接头、轴向保持成立为前提，不证明塑料刚度。轮胎使用已有50945名义尺寸网格，舵机使用已有自定义外形，尚无实物尺寸校准。网格无碰撞也不证明装配工具可达、销能按任意顺序插入或实物轴套不会迁移。

## 承重计算与限制

算例取100g魔方全部由一个轮端承担，每个轮端另有2N夹紧预载；两侧输入杆理想均分，暂不计头部自重、加速度与摩擦。此分载用于比较内部载荷，不代表实际接触力分配。

| 机械头回转角 | 推杆轴向力幅值 | 导轨横向合力幅值 | 较大单根输入杆轴力幅值 |
| --- | ---: | ---: | ---: |
| 0° | 3.367N | 2.496N | 3.925N |
| 45° | 3.173N | 1.765N | 3.547N |
| 90° | 2.704N | 0N | 2.634N |

90°行的导轨横向合力为零，仅指本算例中输入杆传来的平面内合力；重力仍由夹指根轴、轴向定位和骨架承担。此时轮端对根部产生约39.2N·mm面外弯矩，在32mm支承跨距上对应约1.226N的附加反力幅值，尚需叠加合力分配。

0°时较大的根轴合力分量约为X＝2.015N、Y＝10.568N，明显大于魔方重力0.981N。夹紧预载与杠杆作用不能忽略。

两侧杆均分时，公共轴处输入力矩三分量均为零。实物装配间隙和刚度差异会打破均分；例如某夹指左右杆承担55%／45%，其残余偏心力矩为 `0.1 × 杆层位偏距 × 该夹指输入合力`，仍应检查导轨侧压与摩擦。不能据理想零力矩宣称实物不会卡滞。

[计算数据](../../../../artifacts/head-frame-prototype/boxed-load.json)与[复算脚本](../../../../artifacts/head-frame-prototype/validate_candidate.py)。根轴反力采用简化支承模型，未模拟多点孔接触及材料弹性。

**目前不能认定此方案承重更好。** 它改善了名义传力对称性并消除了理想骨架自由铰链，但增加框架也增加自重。必须称量头部并测质心；每增加100g质量且质心距转盘60mm，会增加约0.059N·m静态弯矩。导轨启动阻力、根轴弯曲、转盘间隙、轮胎变形都需要分别量测。

### 单臂试装顺序与记录

1. 先组后导轨座、两根导轨、活动厚块及前固定块，暂不装夹指和舵机连杆。前后座未锁紧前对齐，确认全行程手动滑动；轴套贴近限位面，勿压紧运动件。
2. 预装根轴、夹指、输入双杆与公共轴。公共轴从中间向外为：厚滑块、两侧短接片、上夹指输入杆、下夹指输入杆、半轴套。两侧严格镜像；上下夹指关节的轴长和隔套不同，按模型核对。
3. 在合拢左右骨架之前穿入根轴、导向端座轴和开限位挡轴。固定骨架分侧连接；三层长销需确认挡肩与短端朝向，禁止强压对孔。
4. 插入一体推杆，接后部十字块及两侧半轴套。舵机曲柄先断开，手动开合、松开后回转整圈，记录阻力峰值位置与轴套位置。
5. 用约2.50N横向力作用于滑块，量测启动和往返阻力、侧向摆量；另测空载值作对照。驱动力阈值由舵机实际余量确定。
6. 称量头部并测质心。在0°、45°、90°分别施加预载及100g试重，测轮胎端、根轴、骨架和转盘位移。0.5mm轮端静态偏移仅作首轮比较目标，最终标准需结合净空与夹持容差确定。
7. 卸载检查是否复位，检查轴套迁移，再重复开合。静态验证后再加入预期转速和加速度。保留无载／有载视频及测量记录。

以上是小样试装顺序，尚不是经过实物验证的逐件说明书。正式模型、正式BOM与装配说明未迁移；本候选的采用取决于实测结果。
