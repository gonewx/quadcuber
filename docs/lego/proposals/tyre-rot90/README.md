# 轮胎转 90° 压头：核算报告（2026-10-14，未并入发布模型）

结论：**按“42610 轮毂＋50945 轮胎套在十字轴上锁死”的前提，这个方案做不成**。42610 的中心是圆孔，
轮胎转 90° 以后，转面所需的切向力正好落在轮胎的滚动方向上，轮胎不锁死就传不了扭矩。
几何上的余量改善是真实的（见下表），但锁死这一前提不成立，所以按用户决定先停在核算阶段，
没有改发布模型、零件清单、手册和 3D 页面（`candidate.module()` 默认仍是现方案）。

核算全部用仓库里的真实 LDraw 网格（`mechanical/review/`），原型几何在 `mechanical/tyre_rot90.py`，
用 `candidate.module(..., front='rot90')` 取得。

| 夹指第 6 孔 | 3 号轴＋两侧半轴套 | L 梁端孔十字 / 夹指圆孔 / L 梁端孔十字 |
| 夹指第 7 孔 | 3 号轴＋两侧半轴套 | L 梁中孔圆 / 夹指圆 / L 梁中孔圆 |

L 梁和 42003 都由两处连接定位，相对夹指不能转动；夹指根轴、连杆关节不受影响。
每臂比现方案多 18 件（整机 +72）。轮胎中心与现方案相同（夹指第 4 孔前 5 孔距），
因此 `CLAMP_BETA` = 3.8417°、张开 25°、推杆行程 12.92mm、舵机曲柄 149.3°→39.0° 均不变。

## 2. 锁死为什么不成立

* LDraw 官方 42610 名为 “Wheel Rim 8 x 11.2 with Centre Groove **and Peghole**”，中心孔为半径 6 LDU 的光滑圆孔；
  现方案说明（`baseline_model.py` 压头步骤）也写着“轮毂……仍可绕固定十字轴转动”。
* 转 L 层时，轮胎与 U/D 面接触点的切向力沿 ±z，正是轴线沿 x 的轮胎的滚动方向。
  现方案轮胎轴沿 z，同一个力沿轮轴方向，由薄梁直接承受，所以不需要锁死。
* 查过的 11mm 级小轮毂：93593/93594/93595/30838/50944（50944＋50951 即 50945 的同款胎可配）在 LDraw 里都没有十字孔；
  50944 中心孔半径 1.6mm（轮架细销用），连乐高销/轴都装不进去。
* 用摩擦轴销（43093）或轴向压紧止转都只是靠摩擦，需要拿实物试，不符合“不靠实物试错”的要求，也不应靠加大夹紧力弥补。

附带问题：即使能锁死，轮胎还有沿轴向（+x，朝魔方中心）的受力。拧 F 时，四个轮胎要固定中间层，
其中两个轮胎的受力朝 +x，只能靠十字孔摩擦挡住。

**现有发布模型本身的问题（与本次改动无关）**：直接读冻结的 `generated/mechanical/models/FB0-open.mpd`，
FB 在 0° 张开 25°、托座上位时，F、B 两个下侧轮胎（50945）都与杠杆内臂 32278 穿模；

原型外伸的 42003/半轴套让这一段延长到 40°。这一项需要单独处理，不论压头是否改型。

## 4. 换思路的方向（待选）

1. **保持轮胎轴沿 z，收紧误差预算**：按 3.1 现方案表，零位误差 ≤1° 时装料偏移须 ≤0.5mm（余量 0.24mm），
   零误差时 ≤1.0mm（0.33mm）。提高托座定位和归零精度可以达到，不改结构。
2. **保持轮胎轴沿 z、只把支承件移出 ρ<39.6mm 区域**：真正吃余量的只是薄梁前端孔周围（轮轴下方约 3.6mm 半径那一圈）。
   让支承件在 32449 前端孔以外的部分抬到 ρ≥39.6mm 以外，需要另找带十字孔、外缘半径 ≤3.2mm 的支点件。
   这个方向尚未找到成熟零件，需要再调研。
3. **继续转 90°，但换成能锁死的接触件**：需要一个带十字孔、外径约 14mm 的橡胶接触件，同时解决轴向（+x）止挡。
   目前没有找到可核实的标准件。

请在以上方向中选择，或提出其他约束后我再展开。
