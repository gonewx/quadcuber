# 验证方法与边界

本文件解释[64件独立提案](README.md)已有检查的含义，不把名义几何结果写成实物试验结论。图解没有改变标准机械模型。

## 48处连接轴

从原生LDraw的圆孔原语递归提取孔中心及轴向，变换到世界坐标；对重复原语去重，处理端面孔原语的中心偏移。随后核对销轴、16／8 mm两段及每个宿主孔中心。

| 连接组 | 数量 | 每根销的宿主层数 |
|---|---:|---:|
| A：四角替换销 | 16 | 3 |
| B：各翼内端孔2 | 8 | 3 |
| C：各翼孔10、14 | 16 | 3 |
| 四脚短销：梁孔13、15 | 8 | 2 |
| 合计 | **48** | 40根三层长销＋8根两层短销 |

新增非销件两两之间、新销与保留旧销之间未发现正体积轴对齐包围盒交叠。闭头、托盘下位姿态下，新销与非宿主原固定件无包围盒交叠；有意的销孔配合排除。

## 连续运动包络

托盘按完整40.8 mm平移求包络。杠杆以每个原生网格顶点的三角函数旋转表达式，检查区间端点和内部驻点；另以两处内部角度核对表达式，最大残差约4.3×10⁻¹⁴ mm。

全部72个装入件，包括伸入原层的销，与托盘／杠杆逐件连续扫掠包围盒无交叠。这个保守分离检查不是整机所有自由度的完整碰撞认证。

| 名义结果 | 数值 |
|---|---:|
| 托盘最低点Y | 108.4 mm |
| 杠杆最低点Y | 107.0123 mm |
| 新增非销结构最小Y | 116 mm |
| 托盘对新增结构竖向分离量 | 7.6 mm |
| 杠杆对新增结构竖向分离量 | 8.9877 mm |
| 外柄对新桌面Y140净空 | 32.9877 mm |

不能说全部新增件都在Y116以下：部分蓝销进入原层。没有将桌面净空增大解释为夹手风险消失。

## 尚未验证

真实零件公差、销摩擦及滑移、插入力、操作可达性、弹性挠度、承载效果、重心和按压时抗倾覆均未验证。四脚需要实际补齐接触；不具有自动适应不共面桌面的能力。不得把图解发布或几何检查通过表述为实物下陷已经解决。
