# 56 mm托盘重复定位：四件可撤出角推杆

推荐保留原托盘，L/R夹头预置水平，以可撤出的低位直角推杆把魔方轻靠现有正X、正Z基准边。托盘承重，推杆只提供人工推靠；不增加夹紧力、不要求F/B、不改手臂和重力杠杆。本地名义几何检查通过，尚未完成实物重复定位或重量交接验收，不能据此降盘或自动翻转。

[四视图 PNG](candidate.png) · [PDF](candidate.pdf) · [可复查数据](geometry.json) · [复现脚本](probe.py)

## 为什么选择水平装料

原竖直姿态已在原生网格中找到左右下轮胎与H座、中央托梁、固定销的真实表面相交（六个见证点见数据）。仅拆中央梁不能消除这些干涉。此前双5L梁替代H座的尝试还与杠杆隔套相交，因此竖直方案需要进一步结构改动，不是本次最小修改。

水平夹头避开上位托盘，保留整套支承。原托盘已有两个单向定位边，但没有持续推靠；人工角推杆补足这个动作。它不是自动定心夹具，也不能证明缺少F/B时可以完成单面转动或整机解算。

## 零件和装配

| 零件 | 数量 | 用途 |
|---|---:|---|
| 32526 厚3×5直角梁 | 1 | 两个内侧面分别推靠魔方负X、负Z面 |
| 32524 厚7L梁 | 1 | 下层伸出手柄 |
| 2780 摩擦销 | 2 | 两孔连接，约束手柄相对转动 |

未使用全圆孔薄梁。上述型号常见，但备用数量尚未确认，不能把它们当作已确认库存。工具独立组装，不固定在托盘上。

坐标为毫米，魔方中心为原点，Y向下，名义托面Y=28：

| 部件 | LDraw原点位置 | 旋转 |
|---|---|---|
| 32526 | (-31.6,24,0.4) | diag(1,-1,-1) |
| 32524 | (-31.6,32,-47.6) | 单位矩阵 |
| 两销中心 | (-31.6,28,-31.6)、(-31.6,28,-23.6) | 销轴沿Y |

推靠内侧面为X=-28、Z=-28，接触高度带Y=20…28；手柄在下层Y=28…36。两孔间距8mm，四个梁孔的中心及轴向均从原生孔型递归核对通过。坐标完整旋转矩阵另见geometry.json。

## 支承承重下的操作

1. 托盘在上位，夹头张开。用实际接触面确认左右夹头各自处于水平，不沿用右臂参数假定左臂相同。
2. 魔方各层对齐后平放托面。从负X/负Z角用工具轻推，使魔方靠住原正X、正Z两边。避免压扭底层；工具不需要承担重量。
3. 在托盘始终承重的条件下，让水平夹指接触预定棱块位置，核查接触点和魔方是否移动。不得用加大夹紧力掩盖定位偏差。
4. 工具先沿(-X,-Z)各退出2mm，再沿-Z直退80mm；不要向左臂方向大幅斜抽。确认工具完全离开后结束本阶段测试，保持托盘支承。

工具是人工保持的推靠件，没有锁止或回位弹簧。真实电缆、手和积木公差未包含在模型中。假设的30×30×40mm手部区域只用于初步空间检查，不代表人的手一定能舒适操作。

## 几何证据及边界

- 工具在定位位置与原托盘、全部L/R零件无正体积包围盒重叠。
- 两段撤出动作的连续扫掠与托盘、L/R及保留底座无包围盒重叠。
- 工具整体高度±2mm时，整件L形梁包围盒出现8个候选；改用每个原生三角形的连续扫掠包围盒后候选为零。这是保守几何排除，不是仅检查路径端点。
- 工具三角形包围盒与名义魔方严格内部无重叠；接触面允许相切。
- 水平张开过程65个姿态样本无工具/夹头或原托盘/夹头包围盒重叠。该项是采样结果，不宣称连续运动证明。
- 原托盘移动件整个40.8mm下降的平移包络与静止水平L/R无重叠；杠杆65姿态样本与水平夹头无重叠。这不证明重量交接、同步控制或整机所有内部接触已通过。
- 原托盘与固定臂的既有包围盒候选单独保存在数据中，包括连接处；没有借本次检查宣称整机重新验收。

工具为凹形零件，正包围盒重叠只能作为候选，不能直接判碰撞。原竖直轮胎问题则有原生三角形交叉点，属于已确认相交。所有检查采用名义LDraw网格，未测量弹性、销间隙、摩擦、魔方倒角和伺服回差。

## 最少实测与验收门槛

下列数值是本候选的建议验收门槛，不是已经取得的测量结果。

1. **实际基准和重复性**：确认56mm实际尺寸、倒角、托盘两边直角与备用零件；完成20次支承承重下的装料/撤工具。中心X/Z极差各不超过0.25mm，偏航极差不超过0.5°；撤工具瞬间中心漂移不超过0.25mm。核查四处接触均落在预定棱块平面上，距接缝/倒角至少1mm，底层无被推转。任一项失败，先修正基准接触或工具操作，不靠增大夹紧力补偿。
2. **左右夹头实际姿态**：分别测水平零位和接触后的挠曲，初始水平偏差目标≤0.5°，以四接触区是否仍满足平面余量为最终判据。理论上1°角误差在28mm半径产生约0.49mm位置偏移；软件角度不能代替实际姿态。
3. **以后重量交接的独立门槛**：实际摩擦、法向力、回驱和断电保持尚未验证。只有另行完成有独立接住措施的承重验证，才能讨论下降或翻转；本候选只交付支承承重下的定位方案。不存在从名义接触压缩量或PWM直接推出安全保持力的结论。
