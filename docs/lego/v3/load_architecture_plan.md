# 承重结构修订：设计与实施计划

状态：承重结构及后续短推杆已实现，相关模型检查与图文已交付；前端4处不足1mm运动间隙尚未解决，实物承重尚未验收。空间静力保留两侧不等分载及推杆前接头弯矩。

## 目标和依据

用户观察到：压下夹指时，相连链路整体上翘。旧计算把前端公共接头的高度固定为零，未覆盖推杆弯曲、接头松动和支架变形。

夹紧位置的运动学表明，公共接头竖移0.1mm，会使上下轮端同向移动约0.255mm。因此只检查舵机保持力和推杆轴向退让，不能证明承重稳定。这识别出需要约束的运动，不能单独判定实物唯一的故障部位。

原侧架的L梁有两点连接，不能误判为自由四连杆。本次新侧架也必须固定角部，不能在延长过程中引入剪切自由度。后部曲柄死点不能代替前端横向支承。

## 已实现结构

- 公共接头两侧各增加一组Watt近似直线导向。摆杆用32017五孔薄梁，横梁后续改用端孔为十字孔的11478（见motion_clearance_update.md）。
- 32140支架用两个固定点连接侧架。其末端是十字孔，根部使用轴和两侧限位，不能插圆销。
- 公共接头与直推杆之间增加两片32449铰接薄梁。它们允许导向的微小横移，避免依靠推杆弹性弯曲补偿不同轨迹。
- 上下输入杆改为32017圆孔薄梁，分别按真实接头位置求解。主臂输入关节用24316带止挡轴，给附近摆杆留隙。
- 转盘、平台和固定支座后移32mm。前端轮轴、根轴、轮胎压缩量和防翻折挡轴位置保留。
- 侧架前角用32526两点连接根架及7孔侧长梁。后接架由6632、41677及3749的十字轴段固定相对角度，避免可活动的四连杆。
- 宽侧梁从转盘安装耳前方一孔处开始；后连接采用87083带止挡轴，避开齿轮外半轴套。
- 推杆后续改为2L＋59443＋11L，舵机和导向框前移16mm；总长104mm、前悬伸47.823mm。两个导向孔保持完整覆盖，见[推杆修订](rod_support_update.md)。
- 底座大框随支座后移，各后端增加11孔落地梁；角桥保持两点连接。

正常开端由外张较大的夹指限定为25°，另一夹指约24.65°；直推杆行程约9.960mm。公共接头最大横移约0.0284mm，铰接驱动按真实杆长闭合。

## 设计取舍

1. 使用铰接驱动兼容Watt轨迹，不把两条不同轨迹当成同一条严格直线。代价是增加两个驱动铰点，需实测间隙和轴向保持。
2. 后移转盘获得导向空间。轮端到转盘平面的悬伸增加32mm，100g由两臂均分时，单臂附加俯仰矩约从0.0392增加到0.0549N·m；转盘和侧架刚度必须重新验收。
3. 使用有固定角部的侧架及较短的外侧长梁。增加零件和装配步骤，以避免剪切活动及齿轮回转干涉；不能仅按两端静态照片验收。

## 实物边界

名义几何不能给出塑料刚度、铰链游隙、轴套保持力或轮胎摩擦。必须记录负载、姿态、位移、回差、滑移及重复次数。

两臂夹持时，自由滚轮沿共同夹持轴方向的定位依赖未测滚阻和交接；仅计算接触约束矩阵的秩，不能证明任意扰动下的力封闭。此限制须进入承重报告，不能声称六个自由度全部锁定。
