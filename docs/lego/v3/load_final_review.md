# 承重结构终审与修正记录

日期：2026-10-01。独立审查覆盖承重源码、孔轴配合、固定侧架、约束／静力计算、验证脚本及报告。生成产物由主执行者另行核对。

## 发现与修正

独立审查发现1项Important问题，无Critical和单列Minor：原计算只检查平面平衡，并把两侧摆杆力均分，遗漏输入杆轴向±10mm偏心引入的Mx、My。

修正后按正式模型的力作用平面建立公共接头组合体空间算例，检查六分量平衡，分别计算两侧摆杆和驱动薄梁载荷。对100g两臂均分，偏心力矩为Mx=12.480881N·mm、My=−3.314460N·mm；两侧摆杆轴力幅值分别约0.485375N、0.138679N。省略孔轴弯矩与轴向接触力的二力杆假设已写入报告，实物反力仍取决于刚度。

新增 `test_load_report_balances_axial_eccentricity`：修正前缺少空间平衡结果而失败；修正后在夹紧、中间、全开及有／无预载6种组合下通过。最终机械回归15项、全仓测试68项通过。源码几何未因这项报告修正改变。

| 本次结构以外的旧固件、接线和历史改动 | 全仓68项回归通过；本次机械复核不构成全部硬件产品验收。 |

没有另派复审。以新增测试的先失败后通过及最终全套测试确认修正，保留独立审查意见和上述限制。

## 设计取舍

1. 铰接驱动兼容Watt微小横移，增加两个驱动铰点；游隙和轴向保持需实测。
2. 转盘及平台后移32mm，提供导向空间；100g两臂均分时单臂俯仰矩增加约40%。
3. 固定角部侧架与短外侧梁避免剪切活动及齿轮回转碰撞；增加零件与装配步骤。

当前可作为待实物验收的样机方案交付。详见[承重报告](load_path.md)及[原始验证日志](validation.txt)。
