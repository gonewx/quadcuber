## 结论

**采用 Watt 承重导向、铰接驱动和双侧轮胎支承，模型、连接件、后部避让、BOM 和装配图均已更新。名义 CAD 检查通过；实物受力验收未执行。**

- 每个轮毂两侧各一片 4mm 薄梁，二号轴穿过两端十字孔，轮毂在中间圆孔转动。三号固定轴加两只半轴套，32054 挡套长销固定相邻孔。法向夹紧力可由两片分担，减少单侧 6mm 偏心。
- 舵机后移 8mm，曲柄改走远离推杆的圆弧，配七孔粗连杆第 2、7 孔。曲柄二号轴内端增加半轴套。旧版约 0.52mm 的推杆包络侵入已消除，现有曲柄轴／内限位到推杆包络最小余量约 5.333mm。
- **最小运动间隙仍需实测：**后部旋转半轴套对连杆的连续回转包络下界约 0.878mm（81 个开度）；邻臂到转动单层端面为 1.333mm。前者低于原建议带载 1mm，不能判为已满足该验收指标。
- 拧层沿轮轴方向的力仍可能主要压向一片薄梁，不能把面外柔度写成减半。轮轴、固定轴、轴套、根轴、转盘与底座都须参加受力测试。

### 承重链路修正

[完整承重报告](load_path.md)给出约束与静力交叉验证。公共接头两侧增加Watt导向，铰接驱动兼容其微小横移；转盘和固定支座后移32mm，前后侧架连接固定相对角度。100g两臂均分时，单臂转盘附加俯仰矩增至0.0549N·m。

**新增小间隙：导向活动轴对驱动薄梁全开约0.265mm，夹紧约1.149mm。** 81个开度网格未相交，但尚未达到建议带载1mm目标。不得把刚体约束满秩写成实际刚度或抗扰动验收通过。

## 2. 避让验证

### 方法与覆盖范围

旧体素检查使用 0.8mm 网格并侵蚀实体，会漏掉浅穿入，因此保留作装配及姿态筛查，同时补充原始三角网格检查：

1. `mesh_clearance.py` 使用 FCL，检查新增前端和后部零件与附近零件的 81 个开度，头部角度固定为 0°。不侵蚀网格；轴孔配合、轮胎配合和名义共面接触单列。开合检查共17389次距离查询，0 相交。另查新前端回转对竖直邻臂和本臂固定件的 288 个姿态，先用网格外包盒筛选，再执行4496次精细网格查询，全部零件对间隙下界≥2mm。它不是整机任意状态的连续证明。
2. `mechanical_audit.py` 使用有限圆柱包络和三角形细分，距离上下界差不超过 0.01mm。完整方形截面连续转动的并集为圆柱，魔方半径为 `sqrt(28²+28²)=39.598mm`；正下界证明相应名义网格与扫掠体分离。
3. 推杆直段的完整回转包络半径为 2.4mm。曲柄轴及内限位检查 81 个开度并加入曲柄 0°、90° 极值；同时用曲柄角区间和零件最大径向尺寸建立连续开度保守下界。
4. 旋转半轴套取整个网格的最大半径建立外包圆柱，对舵机连杆检查 81 个开度，每个开度覆盖连续 360°。半轴套真实轮廓在该包络内，因此下界比固定角 FCL 距离更小。
5. 四臂 576 个状态（每 5°）及单臂 168 个中间开度回转姿态仍用体素筛查。正面魔方距离另有每 1° 表面采样及连续包络检查。

## 3. 双侧支承的受力与刚度

沿薄梁长度，后、前固定点为 `x=0、8mm`，轮端为 `x=24mm`。一片薄梁分到的轮端力为 F 时，理想支点反力分别为 `−2F、+3F`。因此两个固定点仍会放大载荷，双片不消除这一杠杆关系。

- **夹紧法向 N：**两片薄梁在轮毂两侧各距中面 6mm，理想均分时每片 N/2，合成偏心距为 0；各片支点反力为 −N、+1.5N。孔隙与刚度差会使分载不均。
- **轮轴方向切向 Ft：**轮毂端面压向一片薄梁；保守按该片承受整个 Ft。载荷换向时接触另一片，轴向游隙形成回差。不能把原单片面外柔度直接除以二。

以理想两点支承、无孔矩形 `7.2×4mm` 为参考，面外惯性矩 `I=38.4mm⁴`，单位载荷弯矩平方积分为 `2048mm³`，所以单片轴向受力的参考柔度为 `δ/Ft=2048/(E×38.4)`：

| 假设 E | 轴向 Ft 单片参考柔度 | 5N 参考挠度 | 法向 N 双片理想均分参考柔度 |
|---:|---:|---:|---:|
| 1GPa | 0.0533mm/N | 0.267mm | 0.00823mm/N |
| 2GPa | 0.0267mm/N | 0.133mm | 0.00412mm/N |
| 3GPa | 0.0178mm/N | 0.089mm | 0.00274mm/N |

法向列使用面内惯性矩 `4×7.2³/12=124.416mm⁴` 并均分到两片。**E 值仅为参数示例，未经材料测试；孔洞、接头间隙、扭转、主臂与转盘变形均未计入。** 结果不是有限元认证或整个压头变形的严格下界。

单臂两轮按 28mm 半径、均匀分载：`Ft=T_arm/(2×0.028)`；0.10N·m 对应每轮 1.79N，0.20N·m 对应每轮 3.57N。摩擦保持需要 `μN≥Ft`，但实际 μ、N 未知，名义压缩量和舵机标称扭矩不能直接给出可靠夹紧力。

## 4. 建议验收指标

以下是针对本样机的**初始工程建议，尚不是经过验证的规格**。先测工作载荷，再以该载荷验收；不要把任意 5N 当作全机能力证明。

| 项目 | 建议指标 | 测量要求 |
|---|---|---|
| 非配合运动件间隙 | 空载目标 ≥2mm；实际工作载荷下 ≥1mm | 覆盖完整行程和回转，避开有意配合孔／齿轮接触 |
| 轮轴中心相对固定底座位移 | 工作切向载荷下 ≤0.20mm | 量刚性轮轴／支架基准，不把轮胎局部压缩混进去 |
| 换向回差／空行程 | 轮端折算 ≤0.10mm | 正负载荷循环，分别记录机械空行程与弹性斜率 |
| 卸载残余变形 | 卸载 60 秒后 ≤0.05mm | 位移分辨率 ≤0.02mm；超出仪器能力则写“无法判定” |
| 夹持抗滑扭矩 | ≥实测工作峰值的 1.5 倍 | 拧层、翻转分别测；出现变形或滑移即停，不为达到倍率继续加力 |
| 推杆半轴套、曲柄轴、轮轴保持 | 工作载荷及 1.5 倍验证载荷下无脱出；轴向迁移 ≤0.10mm | 在轴／轴套上作相对位置标记，加载前后测量 |
| 转角重复性 | 低速正反向落位误差 ≤0.5° | 在魔方／转盘标记处测，包含齿隙与轮胎滑移 |
| 保持与初步耐久 | 保持 60 秒无连续滑移；100 次筛查后再做 1000 次 | 完成后仍满足位移、回差和保持指标；不能据此宣称寿命合格 |

0.20mm 单点切向位移在 28mm 半径处约折合 0.41°，这使位移与转角指标大致一致，但整机误差还包含其他传动环节。当前邻臂单层间隙仅 1.333mm，应把受力位移和装配误差一起计入余量，不能直接按表判合格。

## 5. 可执行的单臂测试流程

**CAD 中已消除旧后部干涉。先完成阶段 A 的实物手动避让及阶段 B 的低载检查，再进行整臂动力测试；后部 0.878mm 名义余量尚未满足建议带载目标。**

### A. 尺寸、连接和运动

1. 清点实际零件；测轮胎外径、宽度、薄梁厚度、轮毂轴向游隙，并记录零件磨损情况。
2. 检查 32449 两端十字孔、三号固定轴、32054 挡套长销和齐平二号轮轴；给轮轴、曲柄轴及推杆两侧半轴套作位置标记。
3. 断开动力并脱开舵机连杆，逐段手动检查开合与回转。按 0%、25%、50%、75%、97.5%、100% 开度检查；开端和夹紧端各转完整一圈。
4. 测最紧间隙；同时核对线缆、舵机凸台、齿轮、转盘和底座。记录刚性接触点及相应角度。

### B. 分离薄梁弯曲与整机松动

1. 把模块底座固定到刚性台面，用表头或相机分别观察：轮轴中心相对主臂、主臂根部相对侧架、侧架相对底座。至少有一个测量通道记录轮轴相对底座总位移。
2. 用拉力计和细线在轮轴中心附近施力；测面外正／负方向（拧层切向）、夹紧法向、推杆轴向三种方向，保持力臂一致。两只轮端分别测，再按工作工况同时加载。
3. 先用 0.5、1、2N 逐级加载／卸载，每级保持 10 秒，做三次。只有前级无异常且实际工作载荷需要时，才加到 5N 或更高；10N 不作为默认要求。
4. 拟合工作区间的斜率 `k=ΔF/Δδ`；记录正反向回差、卸载 60 秒后的残余位移、各销和轴套迁移。弯曲与松动必须分别解释。
5. 出现持续滑移、明显弯曲、发白、异响或连接件退出时停止，该级记失败。表格中未执行项保持“未执行”，不填 0。

### C. 获取实际工作载荷

1. 用长度已测量的小力臂和拉力计测魔方单层起动、持续转动的力，`T=F×力臂`。覆盖正反方向、不同层和多个角度，每种至少三次；记录实际润滑和松紧设置。
2. 单独测整块翻转的低速需求；随后在修正后的单臂／双臂夹持夹具上逐步增加速度，记录目标速度和加速度下的峰值需求。低速静态读数不能代表动态峰值。
3. 夹紧力可用薄型力传感器或带测力元件的刚性假魔方测量。记录传感器改变夹口厚度带来的影响；没有传感器时，至少直接测抗滑扭矩，不由脉宽猜测夹紧力。
4. 用实测最大工作需求确定阶段 B 的验收载荷和 1.5 倍验证载荷；加载能力不足时记录“未达到验证载荷”。不使用电机堵转作为默认加载方式。

### D. 夹紧、拧层与翻转三个工况

1. **夹紧保持：**按新的单臂标定流程空载定中后连接，逐步收紧。保持 60 秒，检查夹口漂移、轴套滑移、轮胎爬出和主臂张开。
2. **拧层：**邻臂夹紧且竖直，逐步从低速到目标速度；测层端面最小带载间隙、轮端位移、落位误差以及轮胎是否沿轮轴方向滑动。
3. **整块翻转：**相对两臂夹持，另两臂松开且竖直；正反各做 90°／180°，检查交接稳定性与回位避让。记录两臂分载不均、重心偏置和线缆影响。
4. 先做 100 次功能筛查，检查紧固位置后再做 1000 次初步耐久；记录失败次数、回差变化和重新夹紧次数。

### E. 双侧版对比与验收

结构选型已确定并落实。用相同轮胎、夹紧力、加载位置和测量基准与旧单侧试件比较，分别测法向变形、正反轴向切向变形和接触换向回差。若变形主要来自轴套、根轴或底座，应修正对应连接。双侧的价值是减少法向偏心并双向限制轮毂；切向刚度改善幅度以实测为准。
