# 机械头系统改型：粗梁连杆与双侧承重导向

日期：2026-10-01。状态：**设计候选，已做几何与刚体分析；尚未替换正式装配说明，未做实物刚度验收。**

> 本候选现作为兼容改型对照。用户已要求放开3×5 L梁限制、重点考虑承重，并禁止任何长度的全圆孔薄梁。新的结构路线评审见[承重优先的整体选型](architecture-reset.md)；下文的“推荐”仅记录本候选当时的选择，不代表当前最终方案。

## 设计结论

优先采用“保留承重导向，重排活动件层位”的方案。后接架、输入杆、摆杆、驱动铰接和压头支架一起调整；全部去掉32017全圆孔薄梁。

## 已确认的要求与设计基准

用户反馈后连接处实物晃动，要求减少薄梁和短接头；希望用竖向3×5 L粗梁。用户没有32017等全圆孔薄梁，已有薄梁带十字端孔。库存记录见[库存约束](../../inventory.md)。

本候选以现有底座、马达、24齿齿轮、转盘、夹指根轴孔位、轮胎接触位置和104mm推杆为基准。维持25°最大夹指开角和已有实体开限位。允许重新安排机械头内部零件及其装配顺序。

“名义网格不相交”“没有自由铰链”和“实物不晃”是不同验收项。本设计分别检查，不用前两项替代第三项。

## 比较过的路线

| 路线 | 当前证据 | 决定 |
| --- | --- | --- |
| 竖L梁直接原位替换 | 保持原侧梁高度时用长边第3、5孔接转盘，L上端在38°～51°扫到原齿轮外半轴套。用第2、4孔居中则对该轴套整圈不碰，但短边与侧梁相差8mm。 | 不能当作原位换件方案发布。 |
| 双导轨滑块承重 | 初步布局需要新增横梁和导轨座；横梁与现有侧长梁交叉。尚无通过检查的完整布局。 | 暂不采用。不是判定原理不可行，而是当前改装量和验证工作更大。 |
| 承重导向保留，输入杆／摆杆改粗梁 | 已建立新的闭环，完成81点开合筛查、288个回转／邻臂状态检查及243组刚体静力算例。 | 本文推荐候选。 |

## 1. 后接架：竖L向前让一孔

每侧使用一根32526竖L、下方一根32523三孔粗梁、上方一根43857两孔粗梁。

- 两根短粗梁连接转盘上下安装孔，仍使用原孔位。
- 竖L的长边向前让一孔，短边朝前。L梁在较外一层，短粗梁在较内一层。
- 下三孔梁与L短边共用两个连接点；L梁再连接原侧长梁。
- 每侧用两个黑销连接转盘；三根蓝色长销连接内短梁、L梁和侧梁；下侧前端另用一个黑销连接L梁与侧梁。
- 移除原后架的薄梁、3749轴销、87083连接轴及其整轴套。

这与用户最初提出的“原位直接换L梁”有一孔的位置差，属于此次系统改型。它使外层竖L避开齿轮轴套的轴向范围，同时保留原侧架位置。

蓝色长销须先把长段插入L梁和侧梁，再把内侧短粗梁压到露出的短段上。最后整个侧架组件沿销轴方向接到转盘，不能先封闭内侧后硬穿长销挡肩。

## 2. 输入粗梁与公共轴

每臂两根32316五孔粗梁作为输入杆，两根杆各自转动。

公共轴采用4号轴。从负Z侧到正Z侧的名义层位如下。Z是沿公共轴的左右方向，不是图中的上下方向。

| 零件 | 中面Z（LDU） | 说明 |
| --- | ---: | --- |
| 半轴套 | -35 | 外侧限位 |
| 11478薄横梁 | -25 | 中间圆孔套公共轴 |
| 输入粗梁 | -10 | 端部圆孔 |
| 另一根输入粗梁 | +10 | 与前一根分别转动 |
| 11478薄横梁 | +25 | 中间圆孔套公共轴 |
| 半轴套 | +35 | 外侧限位 |

删除原公共轴中间的整轴套。输入杆另一端与夹指主梁直接相邻，用3673灰色无摩擦销连接，不再用长轴和两只半轴套。

为给相邻粗梁让出厚度，上下夹指主梁分别向相反侧移动4mm；夹指根轴和固定根架的位置不变。轮胎通过下面的支架保持在原中心面，不能跟着主梁一起偏移。

## 3. 承重摆杆

四根原32017摆杆改为32316五孔粗梁，杆长和固定根点不变。

- 薄横梁中面在Z=±25，粗摆杆中面在Z=±40，原固定支架中面仍在Z=±60。
- 固定根部使用24316三号带止挡轴，止挡头靠粗摆杆内面；外侧用半轴套。去掉内侧半轴套，避免贴着偏移后的夹指主梁。
- 前侧活动端用2号轴通过薄横梁十字孔和粗摆杆圆孔，外侧半轴套限位。
- 后侧活动端使用一根6号公共轴，同时连接左右两侧的薄横梁、粗摆杆及两根驱动薄梁；中间整轴套填满两根驱动薄梁之间的间隔。

轴的十字方向必须与横梁端孔一致。粗摆杆通过圆孔转动，不以压紧轴套增加阻力来承重。

## 4. 推杆改接横梁后端

推杆不再驱动横梁中间公共轴，改为驱动其后端。

仍用两片32449四孔薄梁，**使用中间两个圆孔**，铰点间距为一孔，即8mm。端部十字孔留空。这样驱动薄梁能相对横梁后端的十字轴转动，不会锁住闭环。

原推杆、32013前接头及后部导向孔保留。新的驱动连接改变行程与夹指角的对应关系，因此舵机端点须重新标定：计算推杆行程从约9.960mm变为9.709mm，不能照搬旧行程数值。

## 5. 压头保持居中

上下夹指的轮毂和轮胎仍在原中心面。

- 两片32449压头支承薄梁放在Z=±25。
- 夹指主梁偏移后，在另一侧用一根43857两孔粗梁补满支架厚度；覆盖原两个固定点。
- 两个固定点均使用4号轴与外侧半轴套。两点共同固定主梁、补厚梁和薄梁。
- 轮毂用3号轴，轮毂两侧各一只半轴套；轴两端与薄梁外面齐平。

这使压头支架比旧版宽8mm。轮胎接触点没有横移；加宽后的支架已纳入本次邻臂筛查。

## 单臂试装顺序

1. 先完成两侧新的粗梁后架和原固定侧架，检查每个蓝色长销的挡肩与插入方向；再接转盘。
2. 调整夹指主梁的左右层位，完成居中的轮胎压头。先检查轮毂自由转动及轴端保持。
3. 用4号轴装好公共轴两侧的输入粗梁、薄横梁和半轴套。夹指保持闭合姿态，用灰色无摩擦销连接两个输入关节。
4. 安装粗摆杆、根部止挡轴和外半轴套；装前侧活动轴。不能把旧内侧半轴套加回来。
5. 对齐后侧横梁、摆杆和驱动薄梁，穿入6号公共轴及中间整轴套，最后装外半轴套。两片驱动薄梁中间圆孔分别接横梁后端及推杆接头。
6. 先断开舵机，手动检查整个开合范围和整圈回转；重点观察输入杆与驱动薄梁约0.81mm的间隙。
7. 单臂通过后再标定舵机端点，并进行带魔方承重、反向轻推、重复开合和轴套窜动检查。单臂未通过前不复制四套。

以上为设计级顺序，不是逐件爆炸图。正式说明书需要按最终库存和试装结果重新生成，旧版第16、19、20步不能与本候选混搭。

## 库存与数量变化

单臂（不含接底座的附加销）总数由239件变为238件。数量下降不大，主要收益是去掉后接架的长悬空间隔套、让输入和承重杆使用粗梁，并明确固定连接与活动关节。

关键新增／补充库存：5孔粗梁32316每臂新增6根；灰色无摩擦销3673新增2个；4号轴3705新增5根；6号轴3706新增1根；3号带止挡轴24316总共需要4根，可复用原输入关节的2根。完整差额见[零件差额清单](../../../../artifacts/head-redesign/bom-delta.json)。数量是否齐全仍待用户确认。
