## 结构与传力

推杆推动 32013 十字接头，两根 5 孔连杆把力传到主臂后端。主臂绕支点转动，由前端固定的橡胶压头夹住魔方。无摩擦销能通过孔壁传递横向力；它允许转动，不会切断这条传力路径。

主臂夹紧时外张约 **4.40°**。接触点通过橡胶胎的圆弧形状随角度变化，橡胶受压形成接触面。本版采用固定圆弧压头，**没有独立铰接的平面压块**。轮胎轴芯被短薄梁固定，避免压头像车轮一样自由滚动。

此前的平行夹指和自由摆块方案未采用：有的限位方式实际上锁死了转轴，有的压块太宽，会越过层界或碰邻臂。原尺寸下的圆弧压头也不能完成松开回转，因此四个模块各向外移 **16mm**，主臂换成 9 孔粗梁，底座四角用 7×5 框架连接。

## 主臂孔位

孔号统一从主臂后端（靠转盘的一端）数。

| 孔位 | 连接 |
|---|---|
| 第 2 孔 | 无摩擦销连接 5 孔输入连杆 |
| 第 4 孔 | 6 号主转轴，穿两侧夹指架 |
| 第 7、9 孔 | 两根 2 号轴连接 6632 薄梁 |
| 第 9 孔轴的半轴套 | 外套 3139b 小橡胶胎 |

6632 的**两端是十字孔，中孔是圆孔**。必须由两个端孔同时固定两根轴；只固定一根轴不能阻止轮芯转动。

每个压头使用：6632 ×1、32062 ×2、32123a ×2、3139b ×1。单模块两个压头，四臂共八个。

沿前轴从一端到另一端依次是：4mm 薄梁、8mm 主臂、4mm 半轴套；橡胶胎套在半轴套外，总宽估算约 16.4mm。后轴叠放相同，但不套轮胎。**上下轮胎装在主臂同一侧**，使两个法向接触力沿夹紧方向对齐。

## 名义尺寸

以下以 56mm 魔方和模型中的轮胎形状为准，不能直接当作舵机标定值。

| 项目 | 数值 |
|---|---:|
| 输入销到主转轴 | 16mm |
| 主转轴到压头轴 | 40mm |
| 夹紧主臂角 | 4.40° |
| 松开主臂角 | 25° |
| 推杆开合行程 | 9.45mm |
| 舵机曲柄转角 | 94.42° |
| 估算自由夹口 | 55.36mm |
| 56mm 魔方对应的每侧名义压缩 | 0.32mm |
| 压头接触中心距魔方中心，沿夹持面法线 | 24.12mm |
| 轮胎装后估算外径 | 14.77mm |

理想刚体、无摩擦条件下，夹紧参考姿态中每侧法向力约为推杆总轴向力的 **0.686 倍**。这是由连杆运动的虚功关系计算的前端传力比，未计入舵机、曲柄、轴套滑移、孔隙和结构弯曲，不能据此宣称实物夹紧力。

`grip_tyre.dat` 是真实 3139b 轮胎套在半轴套后的名义变形示意，不是需要打印的新零件。它按内唇由半径 3.2mm 扩至约 3.6mm 估算，轴向宽度保持不变。**这一装配配合尚未经过实物验证**；可靠性取决于实际轮胎和轴套。先试一只，不能可靠保持时不要继续复制整机。

## CAD 检查

当前模型已完成以下检查：

| 检查 | 结果 |
|---|---|
| 单模块夹紧、松开，七个开合中间位置，整机夹紧 | 0 项问题 |
| 四臂 576 个组合，回转 0°～355°，每 5° 一档 | 邻臂保持竖直时，0 个意外干涉状态 |
| 松开臂回位，对完整魔方，每 1° 一档 | 最小表面采样间隙约 2.27mm |
| 夹紧臂拧层，对静止的另外两层，每 1° 一档 | 最小表面采样间隙约 7.42mm |
| 整块翻转，对松开且竖直的邻臂 | 扫掠检查余量约 9.3mm |
| 前端两轴与薄梁端孔；主臂实际孔位；推杆覆盖两个导向轴承 | 25 个开合位置通过 |
| 七个中间行程，各取 24 个回转角，对本臂固定件 | 168 个姿态，0 个干涉 |

扫描包含转动件与本臂固定件的干涉，并把轴、销和轴套计入四臂检查。使用 56mm 尖角立方体和正确的一层厚度 `56/3 mm` 检查层界。

这些是离散角度和离散表面采样检查。它们不能证明连续运动的最小间隙，也不能代替轮胎配合、公差、受力变形和夹紧保持的实测。

**运动限制：相邻机械手不能同时处于水平附近。** 保留规划器的 `--no-adjacent-horizontal` 约束。整块翻转时，L/R 夹持回转，F/B 松开且保持竖直；松开回位应先达到开端。模型没有要求开合与回转同步变角。

## 先搭一臂的验收顺序

1. **轮胎试配。** 将一只 3139b 套到半轴套，检查是否能保持、是否会相对轴套打滑，并量装后外径。不能保持时，该方案尚不能用于整机。
2. **压头固定。** 用 6632 两端十字孔连接主臂第 7、9 孔。检查轴芯不能转、轴不能窜出；上下轮胎在同一侧。
3. **断电装配。** 按 [单臂标定流程](../../single_arm.md#servo-calibration)先脱开曲柄，空载定位，再在行程中间连接。曲柄端采用 2 号轴和一个内侧半轴套，舵机连杆为 32017 薄梁。
4. **标定夹紧端。** 小步推进到轮胎接触且略受压。检查主臂仍有外张角，推杆十字块两侧半轴套没有滑移；不要沿用旧版夹紧脉宽。
5. **标定开端。** 以约 9.45mm 推杆行程、25° 主臂角为参考，手动走完整个回位和翻转范围，核对最窄处。
6. **低速实测。** 检查横向与轴向滑动、拧层阻力、轮胎保持和魔方表面接触情况。记录装后外径、开合脉宽和保持情况，验收后再复制四臂。

## 重新生成

在仓库根目录，使用装有 `numpy`、`scipy`、`Pillow` 的 Python 环境：

```bash
python tools/lego/v3/tyre_geometry.py
python tools/lego/v3/run_check.py module travel all
python tools/lego/v3/four_arm.py
python tools/lego/v3/verify_pressure_pads.py
LDRAW_SOFTWARE_RENDER=1 python tools/lego/v3/booklet.py
```

需要本地 LDraw 2026-01 或更新的零件缓存（32556a 使用官方定义，移除会递归引用的旧别名）；普通渲染方式还需要 Playwright、Three.js 和 `tools/lego/render/server.py`。软件渲染直接读取同一套零件网格，不需要浏览器服务。

交互模型通过 HTTP 打开：

```bash
python -m http.server 8000
```

访问 `http://localhost:8000/docs/lego/v3/`。静态装配图可直接打开 `index.html` 查看。
