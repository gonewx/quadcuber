## 结构与传力

推杆推动 32013 十字接头，两根 5 孔输入连杆驱动上下主臂。两根主臂均为 7 孔粗梁，各用一根 **11478 五孔薄梁（两端十字孔，中间三个圆孔）**承载轮胎。轮毂仍位于支点前 40mm；薄梁以一个 3749 轴销和一个黑色摩擦销固定。整机不再需要 32017 圆孔薄梁。

每个轮毂都用 **32002 的短段连接 4mm 薄梁，长段插入 8mm 轮毂**。上下薄梁安装在各自主臂的同一侧，两个轮胎中心都与主臂中面对齐；短销不会伸到相邻层的回转区域。整机前端不再使用 42003 和 6587 硬压头组件。

42610 中心是圆销孔，轮毂可以滚动。魔方绕机械手轴转动时，需要轮胎沿轮轴方向的摩擦力。两侧均靠轮胎圆弧和橡胶变形形成接触面，实际保持力、轮胎与轮毂配合仍需单臂实测。

四个模块沿用向外移动 16mm 的位置，底座四角用 7×5 框架连接。

## 舵机粗连杆装配

舵机侧同样取消 32017，改用 **32316 五孔粗梁**，孔距保持不变：

- 十字块端：3 号轴穿过十字块和粗连杆，两端各一个半轴套。粗连杆直接贴十字块，中间不加轴套；外侧半轴套把连杆定位在该平面。
- 曲柄端：保留 2 号轴，外端与曲柄外侧齐平，穿过粗连杆后内端露半孔。该端不装半轴套，以免蹭旋转推杆。
- 连杆的轴向位置由十字块端限定。2 号轴依靠曲柄十字孔的配合保持，单臂试装需检查窜轴和松脱。

以 56mm 魔方为准，不能直接作为舵机脉宽标定值。

| 项目 | 数值 |
|---|---:|
| 输入销到主转轴 | 16mm |

| 推杆行程 | 10.00mm |
| 舵机曲柄转角 | 98.57° |
| 自由夹口 | 55.36mm |
| 每侧轮胎名义压缩 | 0.32mm |
| 压头轴中心 X 坐标 | −24.09mm |
| 50945 外包络 | 直径 14mm、宽 6mm |
| 42610 标称尺寸 | 直径 11mm、宽 8mm |

`50945_nominal.dat` 是真实 50945 的名义几何示意，不是打印件。官方 LDraw 的 50945/50951 网格外径约 15.2mm、宽约 6.4mm；此处按用户指定的 14×6mm 调整外包络，同时保留半径 5.6mm 以内的安装内槽。轮毂 CAD 外缘约 11.2mm，采用原网格做避让检查。上述处理不代表实际橡胶变形或公差测量。

夹紧端以每侧 0.32mm 的名义压缩确定。实际夹紧力取决于橡胶硬度、结构弯曲和装配间隙，CAD 不能给出保持力。

## CAD 检查

旧离散检查日志见 [历史检查日志及更正](validation.txt) 和 [旧补充检查数据](pressure_pad_checks.json)。邻臂保持竖直时，576 个组合未检出深度干涉，但该算法会漏掉浅穿入。新增连续检查已检出曲柄轴与推杆相碰；`run_check.py` 现在会因此报错。以下为原检查覆盖范围，不能视为全面通过：

- 单模块夹紧／松开、七个中间行程、整机夹紧的连接、干涉、插深、挡肩和同孔占用。
- 四臂 576 个状态组合，每 5° 扫描回转；相邻机械手必须保持竖直。
- 松开臂对完整魔方、夹紧臂对静止另外两层，每 1° 扫描。
- 邻臂夹紧／松开竖直时的魔方扫掠。
- 25 个开合位置的主臂孔位、轴销两段的孔型匹配、轮毂短销插深、粗连杆叠放和推杆导向覆盖。
- 七个中间行程、各 24 个回转角，对本臂固定件检查，共 168 个姿态。
- 整机用量：42610、50945、32002、11478、3749 各 8 件；32017 和前端硬压头件均为 0。

检查包含销、轴和轴套，并以 56mm 尖角立方体、`56/3 mm` 层厚进行筛查。对同心同轴的轮胎与轮毂配合、轮胎与魔方的名义压缩作有意接触处理。短销原点偏置已计入插深与同孔占用检查。

这些是离散角度和表面采样结果，不能证明连续运动的精确最小间隙，也不能代替受力与公差实测。

新增三角网格连续回转计算：松开头对完整魔方间隙 ≥2.313mm，夹紧头对另外两层 ≥3.182mm，邻臂对转动单层 ≥1.333mm，邻臂对整块翻转 ≥9.655mm。原来的单层 10.1mm 只算轴向切片内的径向余量，遗漏了薄梁靠近层端面的方向；完整三维最小距离应采用 1.333mm。详见完整审查。

**相邻机械手不能同时处于水平附近。** 保留规划器 `--no-adjacent-horizontal` 约束。整块翻转时，L/R 夹持回转，F/B 松开且竖直；松开回位先达到开端。

## 单臂试装

以下为待后部干涉修正后执行的步骤。当前可做断电检查和独立前端加载，不执行整臂动力回转。

1. 将两只 50945 分别套入 42610，以 32002 连接薄梁，确认轮毂轴向保持和轮胎配合。
2. 核对上下薄梁第 1 十字孔用轴销、第 2 圆孔用黑销固定，第 4 圆孔安装轮毂；手动检查轮毂与薄梁避让。轮毂可以转动，但不能脱出。
3. 按[单臂标定流程](../../single_arm.md#servo-calibration)脱开曲柄，空载定位，再于行程中间断电连接。舵机连杆使用 32316，按本页粗连杆装配说明安装 2 号轴，曲柄端不加半轴套。
4. 小步推进到上下轮胎均接触且轻微受压，检查推杆十字块两侧半轴套是否滑移。旧版夹紧脉宽不能直接使用。
5. 开端参考 10.00mm 推杆行程、25° 主臂角，先手动检查整个回位与翻转范围。
6. 低速检查沿轮轴方向的滑移、拧层阻力和轮胎保持，记录实测脉宽与保持能力后再复制四臂。

在仓库根目录，使用装有 `numpy`、`scipy`、`Pillow` 的 Python 环境和本地 LDraw 2026-01 或更新的零件缓存：

```bash
python tools/lego/v3/tyre_geometry.py
python tools/lego/v3/run_check.py module travel all
python tools/lego/v3/four_arm.py
python tools/lego/v3/verify_pressure_pads.py
python tools/lego/v3/mechanical_audit.py  # 当前预期退出 1：发现后部干涉
LDRAW_SOFTWARE_RENDER=1 python tools/lego/v3/booklet.py
python -m http.server 8000
```

浏览器访问 `http://localhost:8000/docs/lego/v3/` 可旋转模型；静态装配图可直接打开 `index.html` 查看。
