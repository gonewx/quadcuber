# 四组轮胎压头：搭建与验证

分支：`design/swivel-pressure-pads`。每臂使用一组 **42610 轮毂＋50945 轮胎**，对侧使用 **42003＋6587 硬压头**；四臂各用四件，均按用户确认的库存安排。新增结构使用乐高件，沿用 EV3 马达和 Geekservo 舵机。

## 结构与传力

推杆推动 32013 十字接头，两根 5 孔输入连杆驱动主臂。上侧主臂用 7 孔粗梁，下侧用 5 孔粗梁，两侧各用 32017 五孔薄梁延伸到支点前 40mm。每根薄梁用两个销固定，承受前端弯矩。

上侧轮毂用 **32002 的短段连接 4mm 薄梁，长段插入 8mm 轮毂**。轮胎和主臂中面对齐，短销不会伸到相邻层的回转区域。42610 的中心是圆销孔，轮毂可以滚动；魔方绕机械手轴转动时，需要轮胎沿轮轴方向的摩擦力。单侧橡胶的保持能力必须实测。

下侧 42003 的两个圆孔通过两个黑销固定在薄梁上，十字孔朝夹紧方向。6587 从魔方侧穿入，凸点朝魔方，**轴肩抵住连接块内面承受推力**，外侧半轴套防脱，保留完整轴尾。主臂夹紧角约 3.64°，凸点端面也随之倾斜，模型以端面边缘接触魔方；没有独立铰接的平面压块。

四个模块沿用向外移动 16mm 的位置，底座四角用 7×5 框架连接。下侧不可直接换成 7 孔主臂，其前端会占用 42003 所需空间。

## 孔位与清单

主臂孔号从后端（靠转盘）数，薄梁孔号也从后端数。

| 位置 | 输入连杆 | 主转轴 | 薄梁固定 |
|---|---|---|---|
| 上侧 7 孔主臂 | 第 2 孔 | 第 4 孔 | 主臂第 5、7 孔，对薄梁第 1、3 孔 |
| 下侧 5 孔主臂 | 第 1 孔 | 第 3 孔 | 主臂第 4、5 孔，对薄梁第 1、2 孔 |

上侧薄梁第 5 孔装轮毂；下侧薄梁第 3、4 孔装 42003，硬压头轴线对应薄梁第 5 孔的位置。两个压头轴中心到主转轴均为 40mm。

每臂前端组件：42610 ×1、50945 ×1、32002 ×1、42003 ×1、6587 ×1、32123a ×1、32017 ×2、2780 ×6。主臂和主转轴另计，完整清单见 CSV。轮毂、轮胎、连接块和带凸点轴各按已有 4 件计，不要求额外轮胎。

## 名义尺寸

以 56mm 魔方为准，不能直接作为舵机脉宽标定值。

| 项目 | 数值 |
|---|---:|
| 输入销到主转轴 | 16mm |
| 主转轴到压头轴 | 40mm |
| 夹紧／松开主臂角 | 3.64°／25° |
| 推杆行程 | 10.21mm |
| 舵机曲柄转角 | 100.18° |
| 自由夹口 | 55.54mm |
| 橡胶侧名义压缩 | 0.46mm |
| 压头轴中心 X 坐标 | −24.08mm |
| 50945 外包络 | 直径 14mm、宽 6mm |
| 42610 标称尺寸 | 直径 11mm、宽 8mm |

`50945_nominal.dat` 是真实 50945 的名义几何示意，不是打印件。官方 LDraw 的 50945/50951 网格外径约 15.2mm、宽约 6.4mm；此处按用户指定的 14×6mm 调整外包络，同时保留半径 5.6mm 以内的安装内槽。轮毂 CAD 外缘约 11.2mm，采用原网格做避让检查。上述处理不代表实际橡胶变形或公差测量。

夹紧端按硬凸点边缘接触确定：以 LDU 表示，`80 + 94 sin(β) − 16 cos(β) = 70`。上侧轮胎在该位置名义压缩 0.46mm。实际夹紧力取决于橡胶硬度、结构弯曲和装配间隙，CAD 不能给出保持力。

## CAD 检查

| 检查 | 结果 |
|---|---|
| 单模块夹紧／松开、七个中间行程、整机夹紧：连接、干涉、插深、挡肩、同孔占用 | 0 项问题 |
| 四臂 576 个组合，每 5° 扫描回转 | 邻臂竖直时 0 个干涉状态 |
| 松开臂对完整魔方，每 1° 扫描 | 最小表面采样间隙 2.32mm |
| 夹紧臂对静止的另外两层，每 1° 扫描 | 最小表面采样间隙 7.76mm |
| 邻臂夹紧竖直时，魔方单层扫掠 | 余量 4.6mm |
| 邻臂松开竖直时，魔方整块翻转扫掠 | 余量 9.7mm |
| 主臂孔位、短销插深、硬压头轴肩、两销固定、推杆导向覆盖 | 25 个开合位置通过 |
| 七个中间行程，各取 24 个回转角，对本臂固定件 | 168 个姿态，0 个干涉 |
| 整机轮毂、轮胎、42003、6587 数量 | 各 4 件 |

检查包含销、轴和轴套，并以 56mm 尖角立方体、`56/3 mm` 层厚进行筛查。仅对同心同轴的轮胎与轮毂配合、轮胎与魔方的名义压缩作有意接触处理。短销原点偏置已计入插深与同孔占用检查。

这些是离散角度和表面采样结果，不能证明连续运动的精确最小间隙，也不能代替受力与公差实测。

**相邻机械手不能同时处于水平附近。** 保留规划器 `--no-adjacent-horizontal` 约束。整块翻转时，L/R 夹持回转，F/B 松开且竖直；松开回位先达到开端。

## 单臂试装

1. 将 50945 套入 42610，以 32002 连接薄梁，确认轮毂轴向保持和轮胎配合。
2. 核对两根薄梁各有两个固定销，42003 也有两个固定销；6587 轴肩贴块体，外侧半轴套贴紧。手动检查轴尾、轮毂和薄梁避让。
3. 按[单臂标定流程](../../single_arm.md#servo-calibration)脱开曲柄，空载定位，再于行程中间断电连接。舵机连杆使用 32017，曲柄端用 2 号轴和一个内侧半轴套。
4. 小步推进到硬凸点接触、轮胎轻微受压，检查推杆十字块两侧半轴套是否滑移。旧版夹紧脉宽不能直接使用。
5. 开端参考 10.21mm 推杆行程、25° 主臂角，先手动检查整个回位与翻转范围。
6. 低速检查沿轮轴方向的滑移、拧层阻力、轮胎保持和凸点对魔方表面的接触情况，记录实测脉宽与保持能力后再复制四臂。

## 重新生成

在仓库根目录，使用装有 `numpy`、`scipy`、`Pillow` 的 Python 环境和本地 LDraw 2026-01 或更新的零件缓存：

```bash
python tools/lego/v3/tyre_geometry.py
python tools/lego/v3/run_check.py module travel all
python tools/lego/v3/four_arm.py
python tools/lego/v3/verify_pressure_pads.py
LDRAW_SOFTWARE_RENDER=1 python tools/lego/v3/booklet.py
python -m http.server 8000
```

浏览器访问 `http://localhost:8000/docs/lego/v3/` 可旋转模型；静态装配图可直接打开 `index.html` 查看。
