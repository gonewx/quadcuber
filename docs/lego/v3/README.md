## 承重路径修正

公共接头两侧各用 Watt 摆杆和横梁支承，32140 支架两点固定到侧架；直推杆通过两片32449薄梁铰接驱动。转盘及固定支座后移32mm，侧架前角两点连接，后接架用十字轴段固定角度。详见[结构、静力及取舍](load_path.md)。整机1060件（不含魔方），24步。

全开时导向活动轴对驱动薄梁名义间隙约 **0.265mm**，夹紧时约1.149mm；小间隙尚未达到带载1mm目标。公共轴和侧架的实物游隙必须测量。

## 防翻折修正

实物后拉推杆曾出现下夹指突然翻折。原模型只选取对称正常解，遗漏另一装配分支。本版已加入上下独立挡轴：正常25°不接触，名义约29.8°挡住，早于41.8°汇合位置。两侧竖梁改十一孔，根轴改八号轴，支架用双片32056；详见[改装清单、原理与手动验收](open_stops.md)。实物防翻折仍须轻载确认和舵机重新标定。

## 前端孔位和装配

孔号从后端（靠转盘）数，上下相同。每个轮毂保持在主臂中面，距主转轴 40mm。

| 位置 | 连接 |
|---|---|
| 7 孔主臂第 2 孔 | 24316 带止挡轴接 32017 五孔薄输入杆，圆孔保留转动 |
| 主臂第 4 孔 | 8 号根轴，贯穿两侧十一孔梁与限位支架 |
| 主臂第 6 孔／两片薄梁第 1 十字孔 | 4519 三号轴贯穿，外侧各加 32123a 半轴套 |
| 主臂第 7 孔／两片薄梁第 2 圆孔 | 32054 挡套长销贯穿，挡套留在第一片外侧 |
| 两片薄梁第 3 圆孔 | 留空 |
| 两片薄梁第 4 十字孔 | 32062 二号轴贯穿，中间套 42610；轴两端齐平 |
| 42610 轮毂 | 套 50945 轮胎，轮毂圆孔绕固定十字轴转动 |

轮端轴向叠放为 **4mm 薄梁＋8mm 轮毂＋4mm 薄梁**，不能增加轮轴外伸或外轴套。后固定点同样是薄—粗—薄，再由两只半轴套夹住；前固定点用挡套长销。先套好轮毂和贯穿轴，再合上另一片薄梁，最后装固定轴限位和挡套销。检查轮毂没有被夹死，轮轴没有窜出。

每臂前端清单：42610 ×2、50945 ×2、32449 ×4、32062 ×2、4519 ×2、32123a ×4、32054 ×2。主臂和根轴另计。完整 BOM 中的 32062、4519、32123a 还包含其他部位的用量。

法向夹紧载荷由两片对称支承，减少旧单侧结构的 6mm 偏心；拧层时沿轮轴方向的力，保守按轮毂端面压向其中一片计算。不能据此宣称整臂刚度翻倍。轮胎侧向摩擦、轴套保持、转盘和底座刚度均须实测。

## 后部曲柄和粗连杆

旧单侧版的曲柄轴会进入旋转推杆包络，已作以下修正：

1. 舵机及曲柄后移一孔（8mm），平台垫梁的三根黑销改到图示孔位；舵机长销插垫梁第 1、5 孔。
2. 舵机连杆改为 **32524 七孔粗梁**：从靠魔方端数，第 2 孔接十字块，第 7 孔接曲柄，第 1 孔留空，两铰点相距 40mm。不能反装留空端。
3. 曲柄从夹紧端沿**远离推杆**的圆弧开合，角度约 −4.78° 到 +92.05°；总行程约 **96.83°**。旧版脉宽及运动方向不能直接沿用。
4. 十字块端三号轴及两只半轴套保留，粗连杆直接贴十字块。曲柄端二号轴外端与曲柄齐平，内端加半轴套定位粗连杆。实物检查轴与轴套的摩擦保持。

前端输入连杆、转盘、模块外移 16mm 及底座四角 7×5 框架保持当前模型中的配置。

## 验证结果和使用边界

- 单模块夹紧／松开、七个中间开度、整机夹紧的连接、插深、孔型、挡肩和同孔检查：0 问题。
- 四臂 576 个离散状态、单臂中间开度 168 个回转姿态：邻臂竖直时未检出干涉。旧体素算法会漏浅穿入，另有以下三角网格检查补充。
- 改动件附近 81 个开度的 FCL 三角网格检查：未检出非配合相交；轴孔配合和名义平面接触均记录在 JSON 中。
- 新前端对竖直邻臂及本臂固定件，另查 288 个回转姿态：网格外包盒筛选后进行4496次精细查询，无相交，全部零件对间隙下界≥2mm。
- 曲柄轴和内限位对推杆连续回转包络：最小余量约 **5.333mm**；曲柄角范围内还计算了连续开度的保守径向下界。
- 魔方连续回转间隙下界：松开头回位 **2.090mm**；夹紧头对静止另外两层 **7.772mm**；邻臂对转动单层 **1.333mm**；邻臂对整块翻转 **9.416mm**。
- 后部旋转半轴套对舵机连杆，81 个开度、各覆盖连续 360° 的包络下界最小约 **0.878mm**；固定角网格距离约 0.914mm。这一处低于原建议 1mm 带载目标，尚不能认定带载合格。

前端同属一个刚性组件的半轴套与挡套销间距 0.8mm，轮胎侧面与薄梁间距 1mm；后部曲柄轴对近似舵机壳体的网格采样间隙约 1.373mm。实物优先核对上述位置及邻臂单层端面，不把名义正距离当作公差余量认证。

**相邻机械手不能同时处于水平附近，保留 `--no-adjacent-horizontal`。** 整块翻转时 L/R 夹持回转，F/B 松开且竖直；松开回位先达到开端。整机所有零件的连续开合与连续回转联合状态尚未得到完整数学证明。

## 单臂验收

先断电手动检查全行程、轮毂自由转动和轴向保持，特别检查后部 0.878mm 与邻层 1.333mm 部位。按[舵机标定流程](../../single_arm.md#servo-calibration)脱开曲柄空载定位，在中间行程断电连接，确认开合支路方向后小步标定。

使用[审查报告](mechanical_audit.md)中的分级加载流程，测工作扭矩、夹持抗滑扭矩、轮端变形、轴套滑移及带载间隙。实物项目仍为“未执行”；单臂验收后再复制四臂。
