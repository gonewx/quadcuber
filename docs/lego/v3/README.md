这版将前端改为独立活动的平行夹块。主臂可略向内收紧，从动臂约束夹块方向，接触边在整个开合行程中保持平行。模型检查通过；夹紧力、摩擦、销孔松旷和支架刚度还需先搭单臂验证。

## 第 19 步修正：L 形夹块

原图的 2905 三角薄梁后端撞上主根轴的整轴套，不能用于这版结构。现改为 32056（3×3 L 形薄梁），每只机械手 4 片，整机 16 片。两个连接孔的位置保持不变；L 梁的拐角与朝外末端十字孔留空。从前端将 L 梁滑入红色粗主臂与蓝色薄从动臂之间，再穿两根前轴。

新增的回归检查已在原三角梁模型上复现轴套干涉，并验证替换后的夹块在 17 个开合位置与模块内全部零件的采样间隙。用户已确认至少有 4 片 32056，可先搭一只机械手；整机的 16 片需再清点。

## 第 21 步换梁：32526 输入连杆

使用已有的 3×5 L 形粗梁 32526 替换 80286，每只机械手两根，整机输入连杆共八根，另有四根用于底座，总计十二根。长边远离拐角的末孔接主臂；短边中孔接十字接头，短边拐角孔与末孔留空。两孔间距仍为 `√(80²+20²) LDU ≈ 32.98mm`，推杆行程、主臂角度和名义预压保持原值。

为避开转盘，两根连杆分别位于夹指中面两侧 8mm 处，并直接贴合接头与主臂：

- 十字接头：**4 号轴 3705**，中间 32013，两侧各一根 L 梁，最外侧各一个半轴套。
- 主臂接点：**3 号轴 4519**，L 梁与粗主臂直接贴合，两端各一个半轴套。原来的内侧半轴套及背面整轴套移除。
- 装入时先不穿轴，L 梁从两夹指之间放入，先向后移、再向对应主臂平移对孔。两处圆孔都要自由转动；半轴套贴近即可，不要挤紧活动梁。具体顺序见[分层图 E、F](img/jaw_layers.svg)。

本次完成零件替换和必要的轴向重排，不把它作为夹紧力提升的结论。

## 使用已有的 7 孔粗梁

主摆臂现已改用用户已有的 32524，无需 6 孔圆孔薄梁。每只机械手的上下主摆臂共需两根 7 孔粗梁；整机主摆臂共八根，另有四根用于舵机垫梁。

粗主臂居中，L 形夹块从两侧抱住它。主根轴两侧改用整轴套；从动前端轴的中间改用一个整轴套；输入连杆接点也重新分配了轴套。应按更新后的第 17～21 步成组调整，不能只换一根梁。

此次替换保持了原来的三个有效连接点。夹块改为两侧安装后，最大张开角由 17° 微调为 16.5°，避开相邻机械手的横梁。当前闭合设置仍为内收 0.25°、每侧约 0.14mm 垫片预压；这次物料替换没有验证更大的内收角或更高的夹紧力。

每片夹指使用：

| 从动臂 | 两根 5 孔薄梁 11478；两端十字孔，轴随梁转动 |
| 夹块 | 两片 32056 L 形薄梁从左右抱住粗主臂，中间留一孔厚空档；一边平行于推杆，另一边在后端朝夹指外侧 |
| 前端主关节 | 2 号轴 32062，固定在L 梁靠魔方一端的端部十字孔中；主臂圆孔绕轴转动 |
| 前端从动关节 | 3 号轴 4519，固定在从动臂前端十字孔中；L 梁朝外一边的中间圆孔绕轴转动，两片L 梁之间一个整轴套，外侧为从动薄梁 |
| 输入连杆 | 32526（3×5 L 形粗梁），长边末孔接主臂，短边中孔接十字接头；每只机械手两根 |
| 接触垫 | 每片L 梁贴一条 12.8×3.2mm 垫片，含胶总厚度 0.4mm；每个夹块两条，整机共 16 条，BOM 按 8 对计，为非乐高材料 |

主、从动臂的有效长度均为四孔（32mm）。从动根轴相对主根轴向后两孔、向外一孔；L 形夹块上两个活动轴也保持相同的位置差，形成平行四边形。

前端是受四连杆约束的活动夹块，能相对主臂转动并保持方向。它不提供球铰式的多轴调心；实际表面不平与小量装配误差由接触垫吸收。

### 支架和轴向限位

后架每侧有一根 9 孔竖梁、一根 11 孔竖梁和四组双层 4 孔薄横梁 32449。两根竖梁相隔一孔，横梁位于中心上下第 3、4 孔，向魔方伸出。横梁的十字端孔用轴连接，内侧圆孔用黑销连接。前端主轴座是四根 3 孔短梁。后架通过四根 2 孔粗梁 43857 接转盘安装耳，使宽支架避开齿轮轴。

- 主根轴用 **7 号轴**。一根粗红梁居中，左右各放一个整轴套，再穿过 3 孔主轴座和两片 4 孔薄横梁。轴端与横梁外侧齐平；横梁端部十字孔固定轴，两侧整轴套保持粗红梁的位置，外端不加轴套。
- 从动根轴用 **10 号轴**。中间一个整轴套，每侧依次为半轴套、蓝梁、两个整轴套、11 孔支架、外端半轴套。
- 前端 2 号轴与L 形夹块外侧齐平，3 号轴与从动薄梁外侧齐平。十字孔负责固定轴，圆孔负责转动，不能混用。

搭建时按[分层图](img/jaw_layers.svg)核对。任意加长前端轴、加外端轴套或扩大张开角，都可能占用相邻机械手的空间。

| 参数 | 当前值 |

| 魔方边长 | 56mm |
| 闭合主臂角 | 内收 0.25° |
| 张开主臂角 | 向外 16.5° |

| 舵机曲柄相对转角 | 约 70.4°，仅作几何参考 |
| 裸塑料底边间距 | 约 56.52mm |

| 56mm 魔方的名义垫片压缩量 | 每侧约 0.14mm |

这解决了旧结构在夹指平行时仍有间隙的问题：主臂可以内收，夹块仍然贴平。前端弯梁不要求与推杆垂直；后端舵机曲柄滑块在标称闭合位置接近伸直。不得把几何预压当作已经验证的夹紧力。

推杆、导向框、舵机平台、转盘、马达和底座沿用父分支的布置。舵机侧 5 孔连杆改为圆孔薄梁 32017；十字块端用内外半轴套定位，曲柄端只用一个半轴套，避免轴套碰旋转推杆。推杆两侧的限位半轴套随推杆旋转，十字块本体保持在导向框内。推杆仍为 3 号轴 + 光面轴连接器 + 12 号轴，短轴插入十字接头到底，中间露出一孔。旧版开合脉宽不适用，重新按[单臂标定](../../single_arm.md#servo-calibration)操作。

### 运动学（LDU，1 LDU = 0.4mm）

主根轴 `P = (-130, ±80)`，从动根轴 `Q = P + (-40, ±20)`。主臂输入力臂 `a = 20`，输出臂长 `r = 80`。输入 L 梁所用两孔的孔距 `L = √(80² + 20²)`。

上夹指前端为 `C = P + r(cos β, sin β)`，从动前端为 `D = Q + r(cos β, sin β)`。因此 `D − C = Q − P`，夹块的方向恒定。下夹指镜像安装。

推杆十字接头位置取工作支路：

```text
xc(β) = −130 − 20 cos β − √[L² − (80 − 20 sin β)²]
s = xc(−0.25°) − xc(β)
```

标称闭合 `xc ≈ −169.647 LDU`；开合行程 `s ≈ 15.258 LDU`。模块最后整体向魔方平移 10 LDU，与底座孔格对齐。

## 检查结果与边界

| 检查 | 结果 |
| --- | --- |
| 单模块、行程中间位置、整机连接与装配 | `run_check.py module travel all`：0 个问题 |
| 夹块与全部零件（含轴套）的干涉、孔位闭环、关节类型、预压、舵机反解及扫掠范围 | 8 项回归测试通过 |
| 四臂整圈扫描 | 0°～355°、步长 5°，夹紧/松开与相邻臂状态，同时检查本臂固定件；邻臂竖直时无报告干涉 |
| 拧一层：相邻臂夹紧、竖直 | 最近采样半径约 117.5 LDU，对魔方尖角扫掠半径 99 LDU，余量约 7.4mm |
| 整块翻转：相邻臂松开、竖直 | 最近采样半径约 102.5 LDU，余量约 1.4mm |

扫掠采用完整一层厚度 `56/3mm`，并包含实体、轴、销和轴套。转动碰撞按机械手对独立检测，扫描每个邻居状态即可覆盖混合状态组合。

**相邻机械手不能同时接近水平。** 一只机械手转动时，相邻两只保持竖直且静止。规划使用 `--no-adjacent-horizontal`。整块翻转时相对两只夹持并同步转动，相邻两只松开保持竖直。

检查基于 LDraw 几何采样及离散角度，不是连续碰撞或受力仿真。剩余间隙也需要用实物确认，尤其是轴套没有装到位、垫片实际厚度不同的情况。

## 实物验收

1. 先搭单臂；断电脱开舵机连杆，手推全行程。夹块保持平行，前端无卡滞，轴不窜动。
2. 按单臂文档先空载定位舵机，在行程中间断电连接，再以 10～20µs 小步标定。
3. 闭合时两块垫片贴平并轻微压缩；再断电调整推杆十字块，使后端曲柄与连杆接近伸直。持续嗡响、支架翘起或销退出时停止。
4. 手动拧其他层，被夹层不滑；随后低速转到水平停留 10 秒，再逐步测试翻转。实际夹紧力和摩擦须以这一步为准。
5. 四臂装好后，手动复核各方向整圈运动和松开后的魔方翻转间隙，再进行联合测试。
