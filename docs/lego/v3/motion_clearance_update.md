# 开合间隙修订：活动轴与后部连杆

本轮从提交 `0022fa7` 继续，处理已知的0.265mm前端活动轴间隙和0.878mm后部轴套包络间隙。夹紧位置、正常开角、Watt杆长、转盘位置及100g静力计算保持一致。

## 两处修改

| 部位 | 原结构 | 当前结构及结果 |
|---|---|---|
| Watt活动轴与驱动组件 | 32017横梁端部为圆孔，活动轴内外各有半轴套；全开时轴对驱动薄梁仅约0.265mm | 横梁改11478，端部十字孔固定活动轴；轴外移2mm，只保留外半轴套。轴对驱动薄梁连续轴向下界2.2mm，对驱动铰轴半轴套的连续径向下界1.9999mm，合计约2.0mm。 |
| 后部旋转轴套与舵机连杆 | 七孔连杆用第2、7孔，空余孔朝推杆；81开度中整圈包络最小约0.878mm | 用第1、6孔，空余第7孔朝曲柄；两铰点仍相距40mm，81开度中整圈包络下界增至2.577mm。 |

新活动轴在两片薄梁及外半轴套中各有4mm完整插深。摆杆的两个轴向端面分别贴横梁和外半轴套；活动轴随横梁转动，32017圆孔摆杆仍可绕轴转动。

**轴向保持依赖11478十字孔和半轴套的摩擦配合。** 这不是带卡簧或双肩的锁紧轴，必须标记轴端、测轴向迁移和拉脱。不得换回全圆孔横梁后继续省略内轴套。前端轮端仍用32449四孔薄梁，输入杆与摆杆仍用全圆孔32017。

## 连续下界如何得到

活动轴与驱动薄梁只在机构XY平面内移动，轴向区间不变：实际网格的活动轴内端到驱动薄梁外面相隔2.2mm。

活动轴中心距公共轴16mm，推杆铰轴中心距公共轴24mm。反三角不等式保证两轴中心间距至少8mm。减去两零件截面半径上界2.4mm和3.600091mm，得到1.999909mm。这一结论不依赖开度采样，也不要求活动轴保持某一自转相位。它要求真实杆长闭合、轴向位置保持，不包含公差与变形。

后部2.577mm结果覆盖每个受检开度的连续360°轴套回转，开度取81点；尚不是全部开度的连续证明。

## 剩余运动间隙

下面的部位没有因本轮两处修改而消失；它们是运动件之间或运动件对支架的名义距离，实物尚未验收。

| 部位 | 81开度采样最小间隙 |
|---|---:|
| 推杆铰轴半轴套—转盘上半 | 0.800mm |
| Watt摆杆—夹指十一孔根架 | 0.8001mm |
| 活动轴外半轴套—Watt根支架 | 0.8187mm |
| Watt横梁—夹指十一孔根架 | 0.9774mm |
| 舵机连杆—平台长销 | 1.4796mm |

另外，邻臂夹紧时对转动单层端面的连续下界仍为1.333mm。这些结果不支持“所有运动间隙均达到2mm”或“带载间隙通过”的结论。表中不足1mm的部位仍低于建议带载目标，应在完整手动行程中逐一定位，然后按[加载步骤](gravity_test.md)测量。

固定零件之间的0.8mm距离、装配端面贴合和设计轴孔配合另列于JSON；不能将它们与需要运动避让的间隙混为一项。

### 后续候选检查

进一步试验了三孔短横梁、短驱动连杆和止挡根轴组合。校正6632端孔原点后，81开度扫描仍在行程90%至100%间出现9个输入连杆—活动轴相交状态；公共轴半套—摆杆间隙降到0.763mm，支架处约0.819mm间隙仍存在。因此未将该方案并入模型。实验变换、完整输出和检查范围见[候选记录](../../../artifacts/clearance-experiments/README.md)。上表四处不足1mm的运动间隙仍未解决。

## 改装与交付

每个机械头：两根Watt横梁由32017换成11478；四根活动轴向外移动2mm；拆下四个内半轴套，外半轴套贴住摆杆。后部七孔连杆重新使用第1、6孔。开合方向和标定规则见[搭建说明](index.html)，装好后先断电手动检查。

本次间隙修订交付时整机共1044件（不含魔方），比其上一版少16个半轴套；后续[推杆缩短](rod_support_update.md)再减4个固定销，当前为1040件。新增11478需求8根，32017需求降到24根。库存未确认的零件仍按未录入处理，准确用量见[BOM](bom.csv)。实物加载、保持力和间隙记录继续保持未执行。
