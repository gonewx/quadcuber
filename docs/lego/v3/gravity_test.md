# 重力承重、下沉与控制误差

适用：Watt 承重导向与铰接推杆版。采用100g设计质量；刚体静力计算通过，实物下沉与刚度尚未测得。

## 结论

公共接头两侧的 Watt 导向把上翘反力传到侧架；输入关节改为24316带止挡轴与32017圆孔薄梁，保留必要转动。承重路径、约束秩和力平衡详见[承重结构报告](load_path.md)。必须同时测公共接头竖移、根轴／侧架位移及整头俯仰。后移转盘增加32mm悬伸，刚性约束通过不代表实际挠度合格。推杆另有两侧驱动力不等造成的弯矩，100g两臂均分的夹紧算例为3.314460N·mm；推杆缩短和支承前移见[修订报告](rod_support_update.md)。加载时还须测推杆前接头沿轮轴方向的位移。

## 1. 重力由谁承担

头部竖直时，魔方重量增加下接触处的负担；有夹紧预压时，上接触也有向下作用力。对魔方取竖直方向平衡：

`所有下接触向上力之和 − 所有上接触向下力之和 = mg`。

因此不能把每个下压头的总压力简单写成 `mg/n`。以下表格只把重量分配为附加载荷，供独立下轮端加载试验使用；原有夹紧预载另计。四个下压头不一定均匀分担，交接后可能只剩两个有效支承。

头部转到水平时，重力在该臂的轮轴方向上，承重更依赖轮胎侧向摩擦、轮毂端面与薄梁及轮轴保持；它不再是同一套“下轮托住”的工况。45° 时两种方向混合。相对两臂翻转时要覆盖这些姿态；相邻臂继续保持竖直。

机械头自身重量与线缆也会导致初始下垂，不能只测装入魔方后的增量。

## 2. 每 100g 的可缩放载荷

按用户要求采用普通三阶魔方的设计工况，本次取 **100g**，重力 **0.980665N**。这不是统一产品标准：例如 [GAN 官方规格](https://www.gancube.cn/gan356m/) 中，56mm 的不同型号列有 67–80g 等质量。若日后称得实物为 m 克，下表乘以 `m/100`；更重型号不能直接沿用100g验收。取 `g=9.80665m/s²`。原始计算值见 [计算记录](gravity_calculations.json)。

夹紧位置的几何：

- 主臂输入孔到根轴 `a=16mm`，轮轴到根轴 `r=40mm`。
- 主臂角 `β=3.841695°`；上五孔输入杆方向角 `φ=75.127638°`。
- 竖直轮端力的根轴力臂：`r cosβ=39.910119mm`。
- 对根轴取矩，输入杆轴向力幅值：`F_link=P·r cosβ/[a sin(φ−β)]=2.633618P`。
- 转盘中心平面到轮轴的纵向距离：`L=111.910119mm`，因此附加俯仰力矩约为 `PL`。

| 重量分配到的下轮数 | 每轮附加载荷 P | 对应单根输入杆轴向力增量幅值 | 对根轴力矩 | 对转盘平面力矩 |
|---:|---:|---:|---:|---:|
| 1，局部零件检查用 | 0.981N | 2.583N | 0.0391N·m | 0.1097N·m |
| 2，理想均分 | 0.490N | 1.291N | 0.0196N·m | 0.0549N·m |
| 4，理想均分 | 0.245N | 0.646N | 0.00978N·m | 0.0274N·m |

“1 个下轮”是保守的局部加载工况，不表示单臂可独立稳定夹住整个魔方。输入杆的力不是舵机推力，不能忽略另一个连杆、夹紧预载和支点反力后直接换算。表中也不含机械头自重、动态冲击或加速度。

输入铰点和 Watt 摆杆的轴孔配合仍有游隙。新结构限制公共接头的理想竖向自由运动，塑料变形和间隙引起的位移必须实测。

## 3. 小间隙如何变成位移

以下为小角度几何敏感度，不是承载能力预测。

| 假设发生的位移或转角 | 对轮端的影响 |
|---|---:|
| 单根主臂相对侧架多摆 0.1° | 竖直方向约 0.070mm |
| 单根主臂相对侧架多摆 0.2° | 约 0.139mm |
| 单根主臂相对侧架多摆 1° | 约 0.697mm |
| 整头在转盘连接处俯仰 0.1° | 纵向111.91mm悬伸贡献约0.195mm |
| 整头在转盘连接处俯仰 0.2° | 约0.391mm |
| 整头在转盘连接处俯仰 1° | 约1.953mm |
| 公共推杆退让 0.10mm，夹紧位置附近 | 每个轮端向外约 0.068mm，夹口增加约 0.135mm；理想夹口中心不移 |

夹紧端轴向敏感度由刚体闭环与独立有限差分交叉核对：`|dy_wheel/dx_rod|≈0.675962`。它只在当前夹紧位置附近适用。公共接头竖移0.1mm时，上下轮端同向反移约0.255mm；这是游隙／变形敏感度，不是正常驱动轨迹。上下轮端位移必须同时测，分别计算：

- 夹口中心位移：`Δc=(Δy上+Δy下)/2`，统一以下为正。
- 夹口变化：`Δg=Δy下−Δy上`。

轮轴中心不等于橡胶接触点；还要测魔方中心或固定在魔方上的标记，才能区分支架下沉和接触压缩／滑移。

## 4. 对控制的影响及建议指标

马达编码器不能直接观测轮端平移、转盘安装面的俯仰、橡胶压缩或魔方滑动。控制器可能显示角度到位，而魔方层面已有错位。交接和翻转改变载荷分配，空载标定不能消除这些变化。

沿用机械审查中的初始建议，并增加重力测项：

| 测项 | 初始建议 | 说明 |
|---|---|---|
| 实际工作承重下轮轴相对固定底座位移 | ≤0.20mm | 含整条结构链，不只测薄梁 |
| 同姿态夹紧后，移去外部托持引起的魔方中心竖直位移 | ≤0.20mm | 托持与放手前后保持同样夹紧指令；测魔方，不由轮轴代替 |
| 两臂／四臂交接引起的中心高度变化 | ≤0.20mm | 检查分载和重新接触，不由单臂结果推定 |
| 加载／卸载回差 | ≤0.10mm | 至少三次，记录是否出现突跳 |
| 卸载 60 秒残余位移 | ≤0.05mm | 仪器分辨率建议 ≤0.02mm |
| 运动件带载间隙 | ≥1mm | 与整体位移分别测，不能只用位移门槛代替 |

这些是待验证的工程目标。邻层名义最小间隙 1.333mm，相对原建议 1mm 只剩 0.333mm 裕量；误差与两侧变形可能共同消耗它。竖直下沉不总是沿最小间隙法向，必须实测危险姿态。活动轴对驱动组件及后部轴套已扩大至约2.0mm、2.577mm，但导向内部另有约0.800～0.977mm运动间隙，尚未达到1mm带载目标；详见[剩余间隙清单](motion_clearance_update.md)。所有带载值仍须实测。

## 5. 可执行测试

记录表：[gravity_test.csv](gravity_test.csv)。设计质量已填100g；实测质量与位移留空。可先按100g砝码对应的载荷验证结构，使用实际魔方测试时补记实测质量。

### A. 建立基准与测量点

把模块底座固定到刚性台面，在以下位置设置可见标记或表头：

- 上、下轮轴中心；下主臂根轴中心及主臂上另一标记，用于区分平移与摆角。
- 转盘旋转侧与固定侧各至少两个标记，用于区分相对倾斜和固定支架变形。
- 公共接头相对侧架的竖移、Watt 支架相对侧架的位置；推杆相对导向框位置，推杆半轴套相对轴的位置。
- 魔方中心标记及接触位置。

单个差值不是某一零件的纯弯曲量，应结合相邻基准与角度一起判断。先记录空头在 0°、45°、90°、180° 的位置，识别自重及线缆造成的姿态变化。

### B. 独立轮端加载，定位结构问题

1. **机械固定推杆位置**后做结构测试，不能断电让舵机自由退让后仍称为“固定夹口”。临时固定点设在推杆处，避免在轮端加支撑而绕过被测承重路径。转盘也固定在目标角度。
2. 从 0.25 倍设计重量（0.245N）开始，在刚性轮轴附近竖直向下施力，逐步到 0.5 倍（0.490N）、1 倍（0.981N）；先测下轮，再在对应姿态测其他受力轮。加载位置及力臂写入表中，不通过拉橡胶代替结构测量。
3. 每级保持 10 秒，卸载后等 60 秒，重复三次。记录所有基准位移、夹口变化、推杆／轴套迁移。
4. 去掉临时推杆固定，按正常供电与夹紧指令重复相同载荷。两组差异用于判断舵机、后连杆和推杆保持的贡献；不要调整脉宽掩盖位移。

### C. 用实际魔方测试接触与交接

1. 在有效的两臂／四臂夹持装置中，先用独立托台承担魔方重量，再夹到相同指令位置。
2. 缓慢移开托台，测魔方中心、上下轮端的位移及夹口变化。托台不再接触时才记承重结果；准备承接掉落。
3. 比较四臂夹持与相对两臂夹持，保持另一对竖直；记录交接前后的高度变化。
4. 静态承重通过后再低速测试相对两臂翻转 0°、45°、90°、180°，测中心漂移、轮胎侧向滑移和危险部位间隙。不要使相邻两臂同时水平。

### D. 按测量结果加固

| 实测现象 | 优先处理 |
|---|---|
| 旋转侧相对固定侧明显倾斜 | 检查转盘配合、固定面和连接销，评估支承跨度与安装刚度 |
| 固定侧也相对台面移动 | 加固竖墙—底座及底座固定 |
| 根轴随侧架移动、两侧架张开 | 检查两侧支承与横向拉结、轴套位置；不以压紧转动件消除间隙 |
| 根轴稳定，主臂相对侧架转动或弯曲 | 细查输入铰链、主臂和根轴配合；确有局部问题再评估双侧支承输入关节 |
| 推杆或半轴套发生迁移 | 优先修正轴向传力与保持，再谈控制补偿 |
| 刚性轮轴稳定，魔方仍下移 | 查轮胎压缩、侧滑、接触分载与预压 |

当前模型已新增[防翻折开限位](open_stops.md)，侧架及根轴随之更新。轮端到转盘平面的力臂已增加32mm，结构实际刚度须重新实测。先完成防翻折手动验收，再用上述测试定位下沉贡献。若测得不合格，应修正对应结构并重跑几何检查，不能用本记录的理想静力计算替代承载验收。
