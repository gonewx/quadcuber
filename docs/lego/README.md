# 乐高机械结构与搭建说明 (docs/lego)

本文档目录维护 quadcuber 魔方机器人的乐高机械结构模型、装配检查与搭建说明书。

当前机械结构已**基本定型为 v4**，下一步工作转向与树莓派 Pico / Zero 的电控软硬件联调。

### v4 核心机械特征
1. **反向连杆与一体推杆**：
   - 十字接头置于连杆前方，**往后拉夹紧、往前推张开**；
   - 连杆全程在转盘凸台前方滑动，彻底消除了推紧方案中连杆后退穿入转盘正面的干涉风险；
   - 推杆采用单根 12 号轴贯穿，省去容易松脱的轴连接器。
2. **转盘内腔 39793 一体导向**：
   - 利用 39793 连接块卡在转盘上半两个凸耳内腔，4 根蓝色长销同时穿接侧板 L 形梁、凸耳与导向块；
   - 夹紧时十字接头离导向 8.25mm，越过夹紧继续后拉时导向块兼作连杆垂直死点的刚性硬挡块。
3. **整机刚度与承重加固**：
   - **转盘固定**：转盘下半由 6 根蓝色长销从框架外侧插入固定，消除单销晃动；
   - **竖墙锁紧**：竖墙两侧各加一根 9 孔粗梁，用 6 个销将固定转盘的上框与中框锁为一体，消灭接缝铰链效应；
   - **三角形斜撑**：舵机侧利用 7 孔粗梁构建 3-4-5 三角形斜撑，将竖墙、水平平台与底座三角互锁，防止机械头前倾点头与下沉。
4. **双侧轮胎压头与开限位**：
   - 上下夹指均采用两端十字孔薄梁夹持 42610 轮毂 + 50945 橡胶小胎，贴合魔方棱面并提供稳定预压摩擦；
   - 设有独立防翻折开限位挡轴。

## 二、零件库存管理

- **用户确认库存表**：[`inventory.md`](inventory.md)
- **库存约束规则**（见 `AGENTS.md`）：
  - 用户现有薄梁均为**带十字端孔款式**，**禁止使用任何全圆孔薄梁**（如 32017）；
  - 替换连杆时必须核对关节自由度及实际孔型；
  - 整体设计优先采用常见 Technic 零件。
