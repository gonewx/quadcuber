# 旧版主结构＋可摆压块：可行性评估

## 结论

建议沿用户提出的方向继续：保留旧版底座、驱动、转盘和推杆的总体布局，由摆臂产生压紧动作，在前端设置有摆角限位的活动压块，由接触反力使压块贴平。主臂不必在夹紧时平行于魔方面。

**本次验证了传力原理和关键几何约束，尚未得到通过整机装配、碰撞和实物负载验证的新搭建方案。** 现有四连杆版的 576 状态检查不能作为这个新方案的验证结果。

基准为 `claude/pro-redesign-jp5l33` 的 `tools/lego/v3/model.py`；当前研究分支的四连杆模型用于对照。本评估没有改写现有搭建模型。

## 1. 无摩擦销不是不能传力

旧版的灰销连接连杆与夹指，米色长销连接两根连杆与推杆接头。这些关节需要允许相对转动，同时通过销与孔壁的承压传递横向力。它们不是用来依靠销的转动摩擦传递扭矩的。将关节换成摩擦销或者锁死，会增加阻力或破坏运动自由度，不能据此提高有效夹紧力。

两端铰接且不受其他外力的连杆，其力沿两连接点的连线传递。这是二力杆的静力性质，参见 [MIT《Mechanisms: Force Transmission》](https://ocw.mit.edu/courses/2-007-design-and-manufacturing-i-spring-2009/bd4ae730bb6e35b131a89fcb3ba935a6_MIT2_007s09_lec08.pdf) 第 14 页。

完整的夹紧传力路径为：

`舵机输出轴 → 曲柄 → 舵机连杆 → 滑块 → 轴向限位件 → 推杆 → 前端接头 → 两根输入连杆 → 主臂 → 压块铰轴 → 压块 → 魔方`

魔方接触反力经主臂根轴回到支架。

这里应特别核查 **6536 滑块与推杆之间的轴向限位**：滑块圆孔自身允许推杆旋转和轴向滑动，夹紧方向的轴向力需经限位半轴套传入推杆。半轴套若沿推杆滑移，就会损失有效闭合行程；这是实物待核查的受力薄弱点，不能误归因于前端铰接销没有摩擦。轴连接器、前端接头的插入与端面支承也需要检查。

## 2. 原版确实存在限制内收的几何条件

原版尺寸（mm）：根轴距中线 `H=32`，输入力臂 `a=16`，前端臂长 `r=32`，输入连杆两孔距 `L=32`。主臂平行时记 `β=0`，向内收记负角。

输入连接点到中轴的距离为：

```text
q(β) = H − a sin β
```

若连杆另一端位于中轴，连接成立必须满足 `L ≥ q`。原版在 `β=0` 时已经达到 `L=q=32`；一旦向内收，`q>32`，原连杆便够不到。把推杆继续推过该位置，不会得到所需的负角内收。

| 主臂状态 | 需要跨越的最小高度 | 原 32mm 连杆 |
| --- | ---: | --- |
| 平行 | 32.000mm | 到达极限 |
| 内收 0.25° | 32.070mm | 不可达 |
| 内收 1° | 32.279mm | 不可达 |

裸主臂的闭合间距是 **56.8mm**，比 56mm 魔方大 0.8mm；在没有其他接触材料填补该间隙时，机构到位并不代表已经夹紧。旧版图中的橡皮圈如果实际具有足够厚度，也可能提前接触并产生预压，效果须看实物，不能只依据绘图厚度。

因此，应改变闭合几何和接触结构。**平行接触面本身不会导致夹不紧，问题在于把摆臂锁在未形成预压的位置。**

## 3. 较长连杆允许内收，但主臂裸塑料会成为下一项约束

32526 的长边末孔与短边中孔距离为 `√(32²+8²)=32.985mm`。在保留旧版 16mm 输入力臂的二维模型中，它允许约 3.53° 的最大内收角。这只是孔位几何极限，不含实体碰撞和装配限制。

另一方面，原粗主臂圆头的半径为约 3.6mm，其内侧位置为：

```text
单侧裸梁内侧 y = 32 + 32 sin β − 3.6
```

裸主臂在内收约 **0.716°** 时就接触 56mm 魔方。实际 LDraw 零件顶点检查也得到：

| 角度 | 主臂与魔方的单侧间隙 |
| --- | ---: |
| 平行 | +0.400mm |
| 内收 0.25° | +0.260mm |
| 内收 0.72° | −0.002mm |
| 内收 1° | −0.158mm |

负值表示主臂实体已经进入魔方包络。所以不能宣称“换长连杆，再内收两三度就能夹紧”。活动压块必须先接触，且主臂在目标夹紧角下保有实体间隙。若需要更大倾角，就必须调整压块突出量、主臂前端位置或根轴位置，并重新核对邻臂与魔方层扫掠。

夹紧角也不必强行越过 0°：只要压块先接触并保留压紧余量，主臂仍有少量向外倾斜时也能夹紧。最终角度应由接触尺寸确定。

## 4. 前端压块怎样才能自然贴合

推荐一个主要摆动自由度：压块绕与主臂开合轴平行的轴微摆。其余方向由两侧支承约束。采用小角度机械限位，必要时用轻回位弹性件防止松开时翻倒；回位件不承担主要夹紧力。

这种靠接触面自行找正的原理已有成熟应用，例如 [Carr Lane 的 swivel pads](https://www.carrlane.com/product/work-supports-rest-buttons/swivel-pads)。该资料支持原理，不代表其产品尺寸或载荷适用于本项目。

关键是 **转轴沿接触面法线的投影，要落在有效接触区域内部，尽量接近中部**。先接触的一侧受到反力时，才会有把压块转向贴平的力矩；贴平后接触压力的合力也应能通过转轴。

计算脚本验证了一个居中压块的例子：接触半长 6mm、轴到接触面距离 4mm，初始倾斜 ±1°、±4°、±8°时，在仅有法向接触、无铰链摩擦的假设下，都产生恢复到贴平的力矩。这不是对实际材料摩擦和回位机构的验证。

**不能直接把现有四连杆的从动臂拆掉。** 现有垫片位于前端主轴后方 1.6～14.4mm，整块接触区都在轴的一侧。去掉方向约束后，法向力会使夹块转动；该接触布局无法仅靠一个自由铰点维持平衡，必须把前端铰点移到接触区中部，或重新设计压块。

此外，转轴投影应针对魔方上真正接触到的区域核对：不能把伸出魔方边缘、或跨到相邻魔方层的那段垫片也算作有效接触区。

## 5. 传力上应保留什么、改什么

优先保留旧版的 **16mm 输入力臂**。当前四连杆研究版将其缩为 8mm，是适配连杆时引入的变化，降低了相同推杆轴力下的前端力矩。

对相同 32.985mm 输入连杆、32mm 输出臂长，在内收 0.25° 的理想刚体模型中：

| 输入力臂 | 每侧法向力 / 推杆总轴向力 |
| --- | ---: |
| 当前研究版 8mm | 约 0.510 |
| 恢复旧版 16mm | 约 1.040 |

静力矩平衡、虚功公式和数值差分给出一致结果。这只比较前端这一级，而且仅在存在接触反力时适用。**它不表示实际夹紧力已提高一倍**：舵机工作角、推杆端限位是否滑移、关节摩擦、夹块实际力臂和支架变形都还会影响结果。

恢复较长输入力臂也会改变接头的前后位置及所需行程，因此 32526 只是候选孔距，不能直接沿用当前版推杆长度和舵机标定。尤其需要重新检查接头与转盘的间隙。

结构优先级：

1. 先保证闭合方向的力能经轴向限位件传入推杆，排除轴套和插接处滑移。
2. 保留合适的输入力臂与连杆角度，接触后仍有有效闭合行程；不要依赖恰好到死点的理论无穷增益。
3. 受力铰轴尽量两侧支承、连接靠近主臂中面，减小偏心扭曲。
4. 采用独立压块完成贴合，取消为了全程保持平行而增加的从动臂及其支架。
5. 在夹块接触面加入适量弹性和防滑材料，吸收尺寸公差并形成可控预压。所需厚度和刚度由实物确定。

## 6. 验证状态和下一阶段验收条件

| 项目 | 当前结论 |
| --- | --- |
| 自由铰接销能否传递本机构所需的横向力 | 原理成立 |
| 原版 32mm 连杆为何不能负角内收 | 尺寸与计算已复现 |
| 加长连杆能否解除该孔位限制 | 二维模型成立；整机实体未验证 |
| 主臂先碰魔方的风险 | 已用圆头几何及实际 LDraw 顶点复现 |
| 居中压块是否有自行贴平的趋势 | 理想法向接触模型成立 |
| 拆掉现有从动臂即可实现自由贴合 | 不成立，需要重做前端铰点位置 |
| 新结构的确切零件、装入路径、摆角限位、整圈碰撞 | 尚未验证 |
| 实际夹紧力、摩擦保持力、长期松旷 | 需要单臂实物测试 |

新结构的实物验收应确认：压块先贴平、接触后仍有小量弹性闭合、轴套不滑移、主臂和支架不先明显张开；随后用实际魔方验证拧层及翻转不打滑。接触面积增大不能直接等同于摩擦力增大，必须验证实际法向力和表面条件。
