一只机械手 + 测试架

本页是EV3 大马达版。另有EV3 中马达版, 两版的机械手、叉子和测试架大部分相同, 只有马达固定和马达与转动座的连接不同。

一个 EV3 大马达带动机械手旋转, 一个灰色 Geekservo 推拉叉子夹紧或松开魔方。测试架把马达和一个固定叉连在一起, 固定叉卡住魔方背面的中间一列, 这样机械手就可以单独拧魔方的一层。搭好后按 docs/single_arm.md 接线和测试。

23个步骤
125个乐高零件, 另加 EV3 大马达和舵机各 1 个
16.5 mm叉子行程 (要求 ≥ 13mm)
56 mm魔方尺寸 (叉齿内侧间距约 56.8mm)
请先读这里: 这份说明书是按官方 LDraw 零件的精确尺寸建模的, 程序检查过所有零件没有互相穿模、每个销和轴都插在孔里、已建模的机械手零件转一整圈不会碰到测试架。检查不包含线缆, 不代表实物可连续旋转。Geekservo 的外形按你给的图纸建模, 摩擦力、零件松紧和整体刚度只能靠实物检验。搭的过程中哪一步对不上, 拍照发给我。

检查与待验证

程序检查 (tools/lego/run_check.py)结果
零件互相穿模 (夹紧、松开两种状态)无
每个销、轴都插在孔里, 且至少连接两个零件通过
机械手每 15° 转一格, 转满一圈, 不碰测试架和马达通过
叉子松开时, 魔方整体翻转 0~90° 不碰机械手 (将来四臂时需要)通过
待实物验证怎么看
Geekservo 外形 (按图纸建模, 线缆位置未知)舵机随转动座旋转; 线缆需留活动弯并避开运动零件。断电确认实际允许转角, 不能由模型保证正反各180°
叉子在导轨上是否顺滑滑块装上导轨后, 用手推叉子, 应能轻松滑动, 不卡不晃
曲柄连杆能否把叉子推到位用 servo 命令慢慢改脉宽, 找到叉子最前和最后的位置
叉齿间距是否刚好夹住魔方最后放入魔方时应能推进去, 不松不紧; 太紧可换 55mm 魔方
整体刚度自重下马达固定端不应明显下垂; 托起再放开不应出现明显倾斜。拧面时测试架、转动座、叉子不应明显晃动。几何检查不能代替承重验证

模型文件 model.ldr 可以用 Stud.io、LeoCAD 或 LDView 打开 (需要把 tools/lego/parts/ 里的 geekservo.dat、cube56.dat 放进它们的零件目录)。
