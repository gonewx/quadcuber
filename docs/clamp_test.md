# 夹紧方式验证：搭建核对与测试步骤

日期：2026-10-04。适用：单臂，简化结构（最初 v3 骨架 + 轮胎压头，不含 Watt 导向和双导轨骨架）。

文中的角度、脉宽、压入量都是模型名义值，**实物都还没测过**，测试时以你看到的为准。

> **如果已经按 [v4](lego/v4/README.md) 改装**：开合方向相反，往后拉是夹紧，“死点”指曲柄朝后、与连杆折叠成一线的位置。下文的步骤照做，只是 T1 里“朝合拢方向”对应推杆往后拉。v4 的预期接触到死点差值没有重新估算。

## 这次要回答的问题

1. 推到死点时，轮胎能不能把魔方夹牢？
2. 压入量加大以后，夹持力增加多少？9g 舵机还推得动、会不会烫？
3. 简化结构的头部下垂有多大？

**更正我上一条回复里的一处错误**：我说过“可能出现死点夹不牢、死点之前夹得牢”。在现有实物上这不可能发生。现有几何是到死点时轮胎压得最深（名义每侧 0.32mm），停在死点之前只会压得更浅、夹得更松。舵机持续出力只有在“压入量大到舵机推不到死点”时才起作用。所以本测试用在魔方上垫卡纸的办法临时加大压入量，来模拟这种情况。卡纸只是测量手段，不是设计方案。

## 第一部分：机械结构

### 用哪一版

用“双侧薄梁轮胎压头 + 防翻折开限位”这一版，也就是加 Watt 导向之前的最后一版。它的说明书已归档：

- **[搭建说明书（21 步，含可旋转模型）](lego/archive/v3-baseline/index.html)**
- [零件清单](lego/archive/v3-baseline/bom.csv) · [防翻折限位的改装清单](lego/archive/v3-baseline/open_stops.md)

单臂只需要第 1~19 步。第 20 步（另外三个机械手）和第 21 步不做。

> **注意**：最新定型版本为 **v4 四臂整机**（见 [`docs/lego/v4/index.html`](lego/v4/index.html)）。旧版 Watt 导向版已归档至 `docs/lego/archive/v3/`。


### 对照你的实物逐项核对

你的实物是最初的骨架换了轮胎压头，大部分应该已经一致。请对照下表检查，只改不一致的地方。

| 说明书步骤 | 要核对的内容 | 一致？ |
| --- | --- | --- |
| 第 12 步 十字块和舵机连杆 | 舵机连杆是 7 孔粗梁：从靠魔方那端数，第 2 孔接十字块，第 7 孔接曲柄，第 1 孔空着。两个铰点相距 5 个孔距 | |
| 第 12 步 | 曲柄端 2 号轴、内侧半轴套齐全；十字块端 3 号轴和两侧半轴套齐全；连杆能绕轴自由转动 | |
| 第 13 步 侧板与夹指架 | 两侧竖梁是 11 孔粗梁（旧版是 9 孔） | |
| 第 15 步 夹指与防翻折限位 | 每个夹指的根轴是 8 号轴；每侧两片 3x3 L 形薄梁；上下各有一根挡轴 | |
| 第 16 步 轮胎压头 | 每个夹指：两片 4 孔薄梁夹一个 42610 轮毂加 50945 轮胎；轮毂能自由转动，没有被夹死 | |
| 第 17 步 连杆与十字接头 | 输入连杆接在 7 孔主臂从后数第 2 孔，根轴在第 4 孔 | |

**关于防翻折限位（第 13、15 步）**：如果你的实物没有装，这次测试也能做，但有两点：

- 找松开位置时不要把推杆拉得太靠后，夹指张开到能放进魔方就停。之前“继续后拉突然跳过去”就是拉过头造成的。
- 在记录表里写明“未装限位”。

### 上电前的检查

断电状态下做：

1. 手推推杆走完整个行程，夹指开合顺畅，没有卡点。
2. 轻推舵机本体，安装耳、垫梁、平台都不晃。
3. 各处半轴套贴住零件但没有压死，活动关节能自由转。
4. 舵机供电已调到 5.0V，且与 Pico 共地。

## 第二部分：准备的东西

- 一个 56mm 左右的三阶魔方；有第二个不同品牌的更好。
- 厚度 0.3mm 左右的卡纸或名片 6 小片，每片约 15mm 见方；胶带少许。有卡尺的话量一下实际厚度，没有就记“名片 1 层”。
- 一个能挂重物的袋子、一段绳子；配重用瓶装水（100ml 水约 100g）或硬币。有厨房秤最好。
- 直尺，手机（拍照和计时）。

## 第三部分：测试步骤

全程使用 `servo <脉宽>` 命令，每次只改 10~20 微秒。**出现持续嗡响且机构顶住不动、底座抬起、销退出，立即执行 `servo off` 或关闭 9V。**

### T1 找死点脉宽（不放魔方）

1. 按 [`docs/single_arm.md` 第 3 步](single_arm.md#servo-calibration) 的 A~C 完成舵机定位和连杆连接。
2. 从基准脉宽出发，朝夹指合拢的方向每次改 10~20 微秒。
3. 看舵机曲柄和 7 孔连杆：两者拉成一条直线的位置就是死点。到这里推杆不再前进，再往下走推杆会开始后退。**不要越过死点。**
4. 记下这个脉宽，称为 `US_DEAD`。再朝松开方向找到魔方能放进去的脉宽，称为 `US_OPEN`。

### T2 找接触脉宽（放魔方）

1. `servo US_OPEN`，放入魔方，位置摆正。
2. 朝合拢方向每次改 10 微秒，每改一次用手轻轻晃一下魔方。
3. 上下两个轮胎刚好都贴住魔方、魔方不再松晃时，记下脉宽，称为 `US_TOUCH`。
4. 计算 `US_DEAD` 与 `US_TOUCH` 的差值。

模型的预期是差约 130 微秒（曲柄约 18°，按 270° 对应 2000 微秒折算）。读法：

- **到了 `US_DEAD` 轮胎仍没贴住魔方**：压入量为零或为负，和 9 月 30 日是同一种情况。跳过 T3，直接做 T4。
- 差值明显小于 130：实际压入量比模型小，属于正常偏差，照常继续。

### T3 死点位置的夹持力

1. 放入魔方，`servo US_DEAD`。
2. **拧**：一只手捏住魔方的另外两层，另一只手不碰，看被夹的那一层；再反过来用手拧被夹的这一层。记录：拧不动 / 用力能拧动 / 轻松打滑。
3. **拽**：用绳子在魔方上绕一圈，下面挂袋子，机械头保持夹指上下方向。逐步加配重，每次约 50g，直到魔方滑动。记下滑动前最后一次的总重量。分别测两个方向：
   - 沿机械臂轴线往外拽（把魔方从夹指里抽出来的方向）；
   - 沿轮胎轴线横向拽（拧层时轮胎受力的方向）。
4. **保持**：重新夹好，不挂重物，保持 2 分钟。每 30 秒摸一下舵机外壳，听有没有持续的嗡嗡声。记录：不热 / 温热 / 烫手，以及有无嗡响。
5. 有第二个魔方的话，换上重复第 2、3 项。

### T4 加大压入量

在魔方上下两个被轮胎压住的位置各贴一片卡纸，用胶带固定边缘，轮胎压在卡纸上。每加一层，相当于每侧压入量增加一层卡纸的厚度。

对 1 层、2 层、3 层分别做：

1. `servo US_OPEN`，放入魔方。
2. 朝合拢方向每次改 10~20 微秒，一直走到 `US_DEAD`，或者走到舵机明显推不动为止。**推不动的判断：脉宽继续改，曲柄不再转，舵机持续嗡响。**这时退回 20 微秒，把这个脉宽记为该层数的保持位置。
3. 在保持位置重复 T3 的第 2、3、4 项（拧、拽、保持 2 分钟）。
4. 记录舵机是走到了死点，还是停在了死点之前。

如果某一层出现舵机烫手、离合器打滑（听到咔哒声、曲柄突然回弹），停止，不再加层。

注意：轮胎压在卡纸上和压在魔方塑料上，摩擦不完全相同。这一项主要看“压入量变大后舵机还推不推得动、热不热”，拽的数值只作参考。

### T5 头部下垂（顺带测）

这一项用来判断后来那些承重加固有没有必要。

**先做一个 10 秒的检查（最重要）**：夹紧魔方，夹指上下方向，用一根手指轻轻往下按魔方，力度约等于一个魔方的重量。同时盯住推杆前端的十字接头（两根黄色连杆交汇处）：

- 十字接头是否明显向上或向下偏移？推杆前段是否被掰弯？
- 上下两个轮胎是否带着魔方一起下移，而夹紧并没有松？

如果是，说明魔方的高度实际上是靠推杆的抗弯在维持。请拍一段侧面视频，并估计魔方下移了多少毫米。

原因：上下夹指共用一个十字接头，接头一旦横向偏移，两个夹指会同向摆动，魔方跟着平移而夹紧不变。十字接头的横向位置只靠推杆顶着，而推杆从最近的导向孔伸出约 64mm 才到十字接头。按理想模型估算这里很软，但销轴摩擦会抵消一部分，实际大小只能看实物。

然后做定量测量：

1. 不放魔方，夹指上下方向，`servo US_DEAD`。用直尺量下轮胎最低点到桌面的高度。
2. 放入魔方夹紧，再量同一个点的高度。
3. 用手指轻压上轮胎约等于一个魔方的重量，松手，看能否回到原位。
4. 把机械头转到夹指水平方向（断开 9V 用手转，或用 `rot` 命令），夹着魔方，量魔方中心相对空载时下沉多少。
5. 各拍一张侧面照片，直尺入镜。

## 第五部分：结果怎么读

拽的合格线我暂定为 **300g**，即魔方自重的 3 倍。这是我提的初始门槛，不是验证过的标准。

| 现象 | 结论 | 下一步 |
| --- | --- | --- |
| 无卡纸、死点位置就拧不动，拽超过 300g，舵机不热 | 死点锁定加轮胎就够用，结构不用改 | 直接做拧面测试（`single_arm.md` 第 8 步） |
| 无卡纸不合格，加 1~2 层后合格，舵机能推到死点且不热 | 仍用死点锁定，但压入量要加大 | 我改孔位，把压入量加到对应数值 |
| 加卡纸后合格，但舵机停在死点之前、温热不烫 | 舵机保持方式可行 | 我按舵机保持重定几何，并写功能检查 |
| 加卡纸后舵机烫手或离合器打滑 | 9g 舵机力量不够 | 换 2KG 版舵机，或在推杆侧增加杠杆 |
| 加到 3 层仍然能轻松拧动 | 问题在摩擦夹持本身 | 要改接触方式，与力的来源无关 |
| 下垂小于 0.5mm 且能回位 | 简化结构的承重够用 | 不做承重加固 |
| 下垂大于 1mm 或不回位 | 承重确实是问题 | 根据照片判断是转盘、根轴还是夹指在让，只加固那一处 |
