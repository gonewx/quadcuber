# 十字接头导向：两条路线的评估

日期：2026-10-04。对象：基准版（轮胎压头＋防翻折限位，已归档至 `docs/lego/archive/v3-baseline/`；后续已定型为 `docs/lego/v4/`）。


起因：实物夹住魔方后轻压明显下移，推杆导向框（7x5 框架）有被撬出的趋势。根源是上下夹指共用的十字接头没有导向，魔方重量经夹指杠杆放大后全靠推杆抗弯，推杆再把力传给导向框。

所有数字来自模型几何和均匀梁比较，**没有实物验证**；推杆挠度只比较几何系数，销孔游隙没有计入。

## 结论

| | 方案一 a | 方案一 b | 方案二（齿轮联动） |
| --- | --- | --- | --- |
| 做法 | 推杆穿过新十字块，向前伸进机械头里的前导向；连杆改接主臂第 3 孔 | 同左，但连杆仍接第 2 孔；整个后部（竖墙、马达、舵机平台）后移 1~2 孔 | 上下夹指根轴装齿轮，经惰轮联动 |
| 改动范围 | 只改机械头 | 机械头＋后部整体移位 | 机械头 |
| 模型检查 | **已通过**（见下） | 未建模 | 未建模，几何上不成立 |
| 推杆弯曲造成的下沉 | 约为基准的 1/7 | 约为基准的 1/11 | 理论上不经过推杆 |
| 导向框受力 | 约为基准的 1/8 | 约为基准的 1/10 | 不变 |
| 十字块横移到魔方的放大 | 5.1 倍（基准 2.6） | 2.6 倍（不变） | — |
| 推杆所需力（每轮 2N 夹紧） | 4.36N（基准 2.70N，+61%） | 3.16N（+17%） | 不变 |
| 推杆行程 | 6.5mm | 8.1mm | 10mm |
| 机械头加长 | 0 | 8~16mm | 0 |
| 每臂零件 | 约 +6 件 | 约 +6 件，另加后部移位 | 至少 +7 件，含非整孔位支架 |

**方案二不推荐。** 方案一的两个变体各有代价，推荐方案一 b，但它还需要建模验证。

## 方案一：给十字接头导向

### 为什么不能直接在原结构上加导向

十字接头开合时从模块坐标 x=−190 退到 −215，而转盘上半的凸台从 x=−200 开始，在半径 12~22mm 处是实心的。也就是说，十字接头松开时已经退进转盘凸台的轴向范围里。任何装在十字接头上、半径超过 12mm 的导向件都会撞上凸台。之前试过的滚子方案和转盘中心孔里的皮带轮方案，都卡在这一点上。

所以必须先腾出空间：要么让十字接头整体前移（方案一 a），要么让转盘后移（方案一 b）。

### 结构（两个变体相同的部分）

- **十字块**：原来的 32013 角度连接器换成 **32184 十字块 1x3**，竖放。推杆穿过它中间的圆孔，前后各一个半轴套固定在推杆上。两端的十字孔离推杆轴线各 8mm，各插一个 **3749 轴销**，轴的一半插十字块，销的一半穿连杆。
- **连杆**：仍用黄色 5 孔粗梁，但改用第 2、5 孔（相距 3 个孔距），第 1 孔在十字块外侧空着。
- **前导向**：第二个 **32184** 放在两根 11 孔梁中间、主臂根轴所在的平面上，中间圆孔对准推杆。两根 **8 号轴**从外侧穿过 L 梁、11 孔梁和这个十字块两端的十字孔，两端加半轴套。它们替换原来侧板上 y=±8mm 的 4 个摩擦销。
- **推杆**：前段的 3 号轴换成 **8 号轴**，穿过十字块后一直伸进前导向。连接器和后段 12 号轴不动。

受力上，推杆从“一端夹持的悬臂”变成“后端夹持、前端有支承”的梁，十字块离前支承只有 13~20mm。魔方重量大部分由前导向直接传给机械头侧板，导向框只承担很小的力偶。

### 方案一 a：连杆改接主臂第 3 孔

十字块整体前移到 x=−163~−179，完全避开转盘凸台。**只改机械头，后部不动。**

模型检查（在基准版副本上，全部用原有检查程序）：

| 检查 | 结果 |
| --- | --- |
| 连接、孔型、插深、挡环销装配顺序、同孔（夹紧、松开、7 个中间位置、四臂整机） | 0 问题。前导向需在装好转盘上半之后再装，否则两侧挡环销方向冲突 |
| 网格间隙，81 个开合位置 | 0 相交；最小 0.4mm（十字块半轴套对连杆），新增的根轴整轴套对连杆 0.81mm |
| 整圈回转对竖直邻臂及本臂固定件，288 个状态 | 0 相交，下界 ≥2mm |
| 四臂 576 个状态 | 与基准版结果完全相同 |
| 防翻折 | 两组解汇合前剩余 1.6mm 后拉，与基准版相当；开限位挡轴在约 29.8° 挡住，早于汇合 |

代价：

- 主臂力臂从 16mm 缩短到 8mm，杠杆比从 2.5 变成 5。十字块每横移 1mm，魔方平移 5.1mm，是基准的两倍。前导向孔、连杆销孔的游隙都会被放大两倍。
- 推杆所需力增加 61%。在舵机保持方式下，舵机负担相应增加；9g 舵机本来余量就不宽。
- 推杆行程缩短到 6.5mm，夹紧方向每 1mm 推杆误差对应轮端 1.09mm（基准 0.68mm），对舵机位置精度更敏感。

### 方案一 b：保留第 2 孔，后部整体后移

十字块位置为 x=−188~−208，松开端仍会伸进转盘凸台，需要把转盘连同竖墙、马达、舵机平台一起后移约 23 LDU（9mm）。后移 1 孔（8mm）时名义间隙只剩约 0.8mm，可能需要把张开角略减或后移 2 孔，要建模后才知道。

优点：杠杆比和基准相同，推杆力只增加 17%，推杆弯曲部分改善最大。

代价：后部要整体移位重装；转盘到轮端的悬伸增加 8~16mm（基准约 80mm），转盘本身的晃动会被放大 10%~20%。**尚未建模和检查。**

## 方案二：齿轮联动上下夹指

原理：两个夹指只能对称开合，魔方重量经齿轮传到两根根轴，不进推杆。

不推荐，原因如下：

1. **没有能装在整孔位上的齿轮组合。** 两根根轴相距 64mm，两个齿轮直接啮合需要齿数和 128，乐高没有。四个齿轮的组合在半孔网格上有 11 种（例如根轴 16 齿、两个惰轮 24 齿，惰轮在根轴连线上离中心 12mm 处），但**惰轮全部落在半孔位置**，11 孔梁上没有这样的孔，需要另做错位支架。
2. **齿隙直接变成魔方的晃动。** 联动链有 3 个啮合，根轴齿轮的节圆半径只有 8~12mm，而轮胎在 40mm 外，齿隙被放大 3~5 倍。乐高齿轮齿隙没有找到公开数据；即使每个啮合只有 0.1mm，三个叠加到轮端也在 1mm 以上，和现在要解决的下沉同一量级。
3. **齿轮要和夹指锁在一起。** 主臂的根轴孔是圆孔，齿轮装上去会空转，需要额外的十字孔薄梁把轴和主臂连起来。
4. **层位冲突。** 根轴两侧各有一层被连杆占用，上下夹指能放齿轮的层不在同一侧，联动链还要跨层。

## 决定与结果

1. 用户先选了方案一 b，建模后需要后移 2 孔，机械头加长 16mm。
2. 用户指出机械头应该越短越好。复核时找到第三种做法：**反向连杆**。十字接头移到连杆前方，往后拉夹紧、往前推张开，十字接头全程在转盘凸台前面；推杆导向紧贴转盘正面。机械头长度不变，底座和后部不动，翻折点也离开了工作行程。
3. 2026-10-04 用户同意，反向连杆方案已建模为 **v4**，替换了加长版。随后按用户建议，把导向框和舵机移回最初位置（前移 2 孔），推杆改为一根 12 号轴，取消连接器，导向框后孔不再使用。文档：[说明书](lego/v4/index.html)、[改装说明与检查结果](lego/v4/README.md)、模型 `tools/lego/v4/`。

本文上面的方案一 a、一 b 保留作记录，都没有采用。

夹紧测试（`docs/clamp_test.md` T1~T4）测的是轮胎与魔方的摩擦，换结构后结论仍然可用；舵机脉宽要重新标定。
