# 乐高搭建图工具

用程序定义单臂原型（机械手 + 测试架）的乐高模型，自动检查后渲染成乐高风格的搭建说明书。有两个版本：

| 版本 | 说明书 | 已发布 |
| --- | --- | --- |
| EV3 大马达 | `docs/lego/index.html`（20 步） | https://claude.ai/artifact/BWgtEpkX4PGRGnYzvNV2L4 |
| EV3 中马达 | `docs/lego/medium/index.html`（26 步，含固定支架补强） | https://claude.ai/artifact/7VtzEUtxMbezHPJQYCDWPX |

## 文件

| 文件 | 作用 |
| --- | --- |
| `model.py` | 模型定义：每个零件的位置、朝向、所属步骤，以及关键尺寸的计算 |
| `check.py` / `run_check.py` | 检查：零件干涉（体素化）、销/轴是否都插在孔里 |
| `booklet.py` | 生成步骤图、零件缩略图、`docs/lego/index.html` 和 `docs/lego/model.ldr` |
| `ldraw.py` | 读取 LDraw 零件库（带缓存）、展开几何、提取孔位 |
| `make_custom_parts.py` | 生成库里没有的零件：Geekservo（按用户提供的图纸）、56mm 魔方 |
| `render/` | 渲染：本地零件服务 + three.js LDrawLoader + 无头 Chromium |

## 使用

```bash
pip install numpy scipy pillow
cd tools/lego/render && npm install && cd ..
python make_custom_parts.py
python run_check.py                    # 两种马达都检查 (含转动扫描), 有问题时退出码非 0
python render/server.py &              # 零件服务 (端口 8765)
python booklet.py                      # 大马达版说明书
python booklet.py --medium             # 中马达版说明书
```

零件文件取自 GitHub 上的 LDraw 官方库镜像 `gkjohnson/ldraw-parts-library`，缓存在 `.cache/`（不提交）。渲染需要 Playwright 和 Chromium（云端环境已预装）。

**改了 `model.py` 之后必须先跑 `run_check.py`，零问题再生成说明书。** `run_check.py` 包括：夹紧/松开两种状态的干涉和连接检查、机械手每 15° 一格转满一圈的转动扫描、松开时魔方整体翻转 0~90° 的间隙检查。

## 坐标和单位

LDraw 单位 LDU：1 LDU = 0.4mm，1 个孔距 = 20 LDU = 8mm，-Y 向上。EV3 大马达在原点，输出盘轴线沿 +X；魔方中心在 (480, 0, 0)；桌面在 y = 150。

## 设计说明（关键尺寸怎么来的）

- **叉齿间距**：叉齿是孔沿 Z 方向的粗梁，宽度方向（Y）为 7.2mm；两根叉齿中心相距 8 个孔距（y = ±80），内侧间距 = 160 − 18 = 142 LDU ≈ 56.8mm，给 56mm 魔方留约 0.4mm 间隙。
- **叉齿宽度**：沿 Z 方向 8mm（≤ 16mm 的要求），只碰面中间一列。
- **行程**：舵机输出轴上的 3 孔细梁当曲柄（半径 20），7 孔梁当连杆（长 120），连杆推叉子框架上的立轴。曲柄中心和立轴不在同一条线上（偏置 30），两个死点之间的行程 = √(140² − 30²) − √(100² − 30²) ≈ 41.4 LDU ≈ 16.5mm（要求 ≥ 13mm）。两端都停在死点附近，理想几何下魔方的反推力不会让曲柄转动；但实物有销孔间隙、梁变形和舵机定位误差，**不能当作可靠锁定**。更可靠的做法是给两端加机械限位，并让曲柄越过死点几度后顶在限位上（过中心锁定），不要靠舵机一直顶死来保持位置。**待实物验证。**
- **插入深度**：夹紧时叉齿尖端伸过魔方表面约 25.8 LDU ≈ 10.3mm；松开后退到魔方表面以外约 6.2mm，此时魔方整体翻转，角块扫过的范围碰不到叉齿（`check` 已验证 0~90°）。
- **靠近魔方的部分都很窄**：叉子框架和连接用的 3 孔梁都在魔方表面 14mm 以外（z 方向宽的零件在 x ≤ 376），相邻层转动时不会被挡住。
- **导轨**：两根 12 号轴固定在转动座远端，叉子框架两端的孔套在轴上滑动，两个支点相距 120 LDU，叉子不易歪。
- **马达固定（大马达）**：马达尾部下方有两片耳朵（各 1 孔厚、3 个孔：第 1、3 个是圆销孔，中间是十字孔），耳朵之间是一个 1 孔宽的缝。做法取自 LEGO 官方 EV3 模型 TRACK3R（31313，LDraw 官方模型库 `31313-1_Track3r.mpd`）：把框架的一边插进这个缝，两根红色带挡套长销（32054）从同一侧插进第 1、3 孔，2 孔长的销段穿过"耳朵—框架"，挡套留在耳朵外面，不会插过头。框架被两片耳朵夹住，马达的反扭矩经框架传到后墙，都是销受剪。旧版写的"蓝色长销穿过耳朵—框架—耳朵"装不上，见下一节。
- **马达第二个固定点（大马达，后垫块）**：只靠尾部耳朵时，机械手的重量绕马达尾部往下压，力矩全压在耳朵里那两根销上。马达尾端面下排有 3 个销孔（y = −20，孔深 z −210～−190），正对横梁上排，中间正好空 3 个孔距。这里用 3 根 7 孔梁叠成后垫块，层与层之间错开插摩擦销；垫块后面用 2 个销接横梁，前面 3 个销插进马达尾端面。装马达时整体往后推，固定板套上蓝色短头，尾端面同时套上 3 个黑销。马达颈部顶上的鳍片（LEGO 教育版小车的主固定点）也看过：鳍片后面紧挨着马达方箱，箱子比鳍片高约 20mm、宽 40mm，梁没法直接往后引到立板，所以没有采用。尾端插头区域（x −20～20，y −80～−40）保持空着，线缆从立板上方往后走。**承重效果待实物确认。**
- **底部垫梁（大马达，2026-09-28 实物反馈后新增）**：用户搭出来发现马达连同固定框架整体下垂。固定框架底边（y = 90）和底座框架顶面（y = 110）之间正好空 1 个孔距，垫一根 7 孔梁，3 个摩擦销竖着插进框架底边的孔（框架边上的孔是贯通的），梁压在底座框架的前边上。它只在底座框架前边那一段（z −230～−210）受力，前端仍然悬空，**是否足够要看实物**。
- **中马达版的区别**：中马达的输出是正面一个十字孔，没有带销孔的输出盘；安装孔的方向都和输出轴垂直。所以：一根 15 孔梁贴在马达正面（两个摩擦销插正面左右两孔，输出轴从梁中间的圆孔穿过，这个孔同时托住输出轴），梁的另一头用 4 个销固定在竖立的 7×5 框架上；4 号轴插进输出孔，轴上两片 3 孔细梁（十字孔锁住轴）再用两个销带动转动座。多了这一层，机械手和固定叉一端整体前移 1 个孔距（`model.DX = 20`）。

## 已知限制

- **中马达旧版已搭建，发现固定端悬臂下垂。** 新版第9–12步补强固定支架，尚待实物安装验收。Geekservo 外形按图纸近似建模，线缆出口位置未知。
- 检查用 2 LDU 体素，贴合面不算干涉；小于约 4 LDU 的轻微干涉可能查不出来。
- 摩擦力、零件松紧、整体刚度只能靠实物检验。转动部分从马达输出盘到魔方面约 150mm，仍需检查旋转轴、联轴件和导轨的承重能力，要检查叉尖下垂和晃动（锁住马达，轻推叉尖，看位移来自输出轴、连接件、导轨还是底架）。
- 检查覆盖不全：开合只查两个端点（没扫曲柄、连杆的中间位置）；转动扫描不带魔方；碰撞只算梁、框架等实体零件，不含销、轴、轴套和线缆；没有四臂之间的干涉检查。松开的叉齿离魔方中心至少约 44mm，大于角块扫过的 39.6mm，所以叉子处于任意角度时魔方翻转都碰不到叉齿（这一项不依赖叉子是竖直的）。


## 中马达固定支架补强（2026-09-28）

新增第9–12步，其他步骤顺延；仅影响中马达版。框架位于 `(40, 40, -120)`，贴在固定梁另一侧；两根横梁位于 `y=120, z=-160/-80`，跨接原有 `x=-20/100` 两根底脚。垫梁位于 `(40, 100, -120)`，两根4号轴沿Y穿过竖框底边、垫梁和横梁，两端用半轴套限位；上方两根摩擦销沿X连接固定梁与竖框。完整销孔连接与两种马达的原有检查均需通过，不能豁免新支撑与联轴件的碰撞。

新增零件：64179×1、32524×2、40490×1、2780×6、3705×2、32123a×4，共16件。详见 `docs/lego/medium/support-fix.md`。首个更靠前的支撑位置在转动扫描中与联轴梁碰撞，最终退后一个孔距；不可按更靠近输出轴的位置自行前移。

本次验证使用LDraw官方2026-08完整库（`https://library.ldraw.org/library/updates/complete.zip`）解压到 `.cache/ldraw/complete/`，读取器优先使用本地文件。几何扫描不验证承载能力，也不包含线缆。

### 补装顺序与挡肩修正

6558的挡肩位于局部X=-10 LDU，分隔一孔长和两孔长的销段。旧版底部三层贯穿法不可从单侧完成，不能用“先横后竖”掩盖这个问题。新版第11步先连接上方横销，第12步将整套底座侧放，从底下向上穿入无挡肩4号轴，两端各套一个半轴套。轴中心为 `(40,100,-160/-80)`，上下半轴套中心Y分别65、135；下方轴套底面Y=140，桌面Y=150，名义间隙4mm。

既有connections检查只验证轴线对孔与连接数量，不检查挡肩是否能穿过孔；collisions不包括销、轴、轴套。不能据此声称装配顺序已验证。本次以无挡肩贯穿轴替代有挡肩销，按说明从底部装入，仍需实物确认孔配合与轴套固定效果。


## 蓝色长销（6558）的装法（2026-09-28 修正）

6558 的挡肩在局部 x = −10 LDU：一侧 1 孔长，另一侧 2 孔长。挡肩过不了孔，所以一根长销连三层时，挡肩必须正好落在第一层和第二层的接缝上，而且**挡肩两侧的零件必须在插销之后才连在一起**。旧模型有四类错误，`connections` 检查只看轴线对孔，查不出来：

| 位置 | 旧写法 | 问题 | 新写法 |
| --- | --- | --- | --- |
| 马达耳朵（大马达第 6 步） | 长销穿过 耳朵—框架—耳朵 | 两片耳朵是马达上的同一个零件，挡肩要穿过一片耳朵才能到位 | 按 LEGO TRACK3R 的做法，两根红色带挡套长销（32054）从同一侧穿 耳朵—框架，挡套在外 |
| 装马达 / 马达支架 / 装固定叉 | 长销穿过 固定板—横梁—立板，短头在立板 | 立板和横梁在"横梁"一步已经连住，只能从一端穿 | 长销掉头：2 孔长一段从前面插进横梁和立板，挡肩贴横梁，固定板套在 1 孔长的短头上 |
| 固定叉、叉子（两步夹心） | 第一步 3 孔梁—框架—3 孔梁 连好，第二步再往 3 孔梁—叉齿—3 孔梁 里穿长销 | 两边 3 孔梁已经连成一体 | 第一步只放一侧 3 孔梁并插好全部 8 根长销的短头，套框架；第二步套叉齿，再盖另一侧 3 孔梁 |
| 舵机耳朵 | 挡肩落在舵机耳朵孔的中间 | 耳朵厚 2 孔（16mm），销的方向反了 | 2 孔长一段插满耳朵，1 孔长短头插转动座 |

`check.long_pins` 自动检查以上规则（挡肩在接缝上、挡肩两侧不是同一个零件、两侧零件没有在更早的步骤里连住；32054 的挡套不能进孔，用 `ldraw.hole_segments` 按孔的实际长度判断），`run_check.py` 已包含。仍然查不了的：同一步里的先后顺序、摩擦销能不能推得动、2780 在马达耳朵里的夹持力。这些要实物确认。
