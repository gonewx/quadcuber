# v5（未采用，搁置）

2026-10-05 的试验：在 v4 基础上恢复“往前推夹紧”。十字接头换成 32034（两端十字盲孔），后端插推杆，前端插 5 号轴，伸进根轴平面上的 32184 前导向。这样推力靠推杆端面传递，不靠摩擦。

**未采用的原因**：推紧方向下十字接头在连杆后方，松开时往后退。推杆后退超过约 40% 行程后，连杆会顶到转盘上半正面圆盘（半径 12~24mm），全开时穿入约 5.8mm。基准版 v3（`b9aa5d5`）原模型完全一样，之前的检查没有发现：体素检查漏掉了浅穿入，网格检查又只查有用途标记的零件。

要绕开，只能把机械头加长 2 孔。最终改为 v4 的做法：推杆导向放进转盘上半凸台内腔，见 `docs/lego/v4/README.md`。

本目录的模型和检查脚本停留在发现干涉时的状态，`mesh_clearance.py` 会报出上述相交。
