承重要分开检查

① 根轴及框架支承

轮胎 → 夹指 → 双侧根轴 → 前端立架 → 左右侧框／横向连接 → 转盘 → 固定支座 → 底座。

减小根轴悬伸，减少串联连接；转盘间隙、支座刚度和机械头自重仍需检查。
② 活动接头支承

夹指输入杆 → 滑座 → 双导轨的前后接触 → 导轨端座 → 框架。

推杆输入轴向力；横向力和力矩应由滑座支承。两路载荷的分配必须联立求解，不能各自假设承担全部载荷。

三条路线，按证据选择

路线为什么值得考虑必须解决的问题当前判断
封闭框架＋直线滑座导向与框架承重分工清楚；有机会删去摆杆和短驱动连杆。四个滑动接触点的摩擦、导轨挠曲、平行度和卡滞；滑座自身也需刚性。优先做导向小样。尚不能保证更少件或更硬。
封闭框架＋重排连杆导向继续使用转动关节，避免长行程轴孔滑动。关节间隙累积、层位和侧向支承；需要重新布置，不能直接套旧内芯。滑动方案不达标时的主要对照。
