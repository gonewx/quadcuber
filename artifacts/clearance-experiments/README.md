# 短横梁候选：未采用

基准是 `c7e481e` 的搭建模型。实验只在内存中修改几何，正式说明书、BOM和模型保持该基准。

## 候选结构

- Watt横梁由五孔11478缩为三孔6632，半跨从40降到20LDU；上下固定根分别移到 `(-210,-80)`、`(-170,80)`，摆杆长度仍为80LDU。
- 推杆铰接薄梁由四孔32449缩为三孔6632，长度从60降到40LDU。前短轴加长一孔，使连接器和后12L轴在夹紧位置仍处于原位。
- 固定根轴改为24316止挡轴，并相应调整支架连接销、垫梁。
- 6632的原点在端孔，已将放置点沿梁长回移20LDU；不能直接套用11478的中心原点。

## 拒绝原因

81个开度的FCL网格检查发现：

| 检查项 | 候选结果 |
|---|---:|
| 输入薄连杆—Watt活动轴 | 行程90%至100%间，9个采样状态相交 |
| 公共轴半轴套—Watt摆杆 | 最小0.763341mm，行程97.5% |
| 活动轴外半轴套—Watt根支架 | 最小0.818707mm，仍不足1mm |
| 正常全开时上下夹指角 | 25°与24.312559° |

缩短横梁使活动轴进入输入连杆的运动区域。原有活动轴轴向位置也覆盖输入杆所在层，因此在接近全开时碰撞。支架短边与活动端的相对布局基本未变，原有约0.819mm小间隙也没有消失。

这个候选不能作为改装方案。继续解决剩余间隙，需要重新安排输入杆、横梁、摆杆和支架的轴向层次或支架形状，同时验证孔深、止挡、连接刚度和回转空间。

## 复现

在仓库根目录运行：

```bash
tools/lego/.cache/venv/bin/python artifacts/clearance-experiments/compact_watt.py
```

脚本检查基准模型的SHA256，防止把旧实验变换套到后续版本上。依赖与正式网格检查相同：NumPy和python-fcl，以及本地LDraw零件库。脚本打印失败证据；进程正常结束只表示扫描执行完毕。

完整输出见 [compact_watt.txt](compact_watt.txt)。其中包含固定部件距离和有意装配附近的距离，不能将排序列表的每一项都视为运动间隙。扫描只覆盖81个开度、机械头回转角0°，不是连续运动证明；该候选已在局部检查失败，未继续进行整机或承重验收。
